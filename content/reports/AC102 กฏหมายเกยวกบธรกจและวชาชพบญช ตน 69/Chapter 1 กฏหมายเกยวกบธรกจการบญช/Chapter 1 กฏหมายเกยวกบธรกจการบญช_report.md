# Chapter 1 กฏหมายเกี่ยวกับธุรกิจการบัญชี

## บทนำ
วิชากฎหมายเกี่ยวกับธุรกิจการบัญชี (LW911) ในบทเรียนแรกนี้จะปูพื้นฐานความรู้เกี่ยวกับกฎหมายเบื้องต้น ซึ่งเป็นส่วนสำคัญในการประกอบธุรกิจ โดยครอบคลุมตั้งแต่ความหมายของกฎหมาย ลักษณะของกฎหมายในแง่มุมต่างๆ และประเภทของกฎหมาย เพื่อให้ผู้เรียนมีความเข้าใจหลักการพื้นฐานก่อนที่จะลงลึกในรายละเอียดของกฎหมายที่เกี่ยวข้องกับธุรกิจต่อไป นอกจากนี้ยังเน้นย้ำถึงความสำคัญของการนำกฎหมายไปใช้อย่างถูกต้องและเป็นธรรมในสังคม.

## วัตถุประสงค์
วัตถุประสงค์ของบทเรียนนี้คือเพื่อให้ผู้เรียนสามารถ: 1) เข้าใจความหมายและนิยามของกฎหมาย 2) อธิบายลักษณะสำคัญของกฎหมายได้ทั้งในแง่ของเนื้อหาและกระบวนการออกกฎหมาย 3) จำแนกประเภทของกฎหมายได้แก่ กฎหมายเอกชน กฎหมายมหาชน และกฎหมายระหว่างประเทศ พร้อมยกตัวอย่างประกอบ 4) แยกแยะความแตกต่างระหว่างแนวคิด 'ความเท่าเทียม' และ 'ความยุติธรรม' ในการบังคับใช้กฎหมาย และ 5) ตระหนักถึงความสำคัญของการเคารพและปฏิบัติตามกฎหมายเพื่อธำรงไว้ซึ่งความสงบสุขและความเป็นธรรมในสังคม.

## แนวคิดสำคัญ
1. ความหมายของกฎหมาย: กฎหมายคือคำสั่งหรือข้อบังคับของรัฐาธิปัตย์ที่กำหนดขึ้นเพื่อควบคุมความประพฤติของพลเมืองในสังคม รัฐ หรือประเทศนั้นๆ เพื่อให้สังคมอยู่ร่วมกันอย่างสงบสุข และผู้ฝ่าฝืนจะต้องถูกลงโทษ 2. ลักษณะของกฎหมาย: พิจารณาได้ 2 แง่มุมหลัก: ก) ในแง่ของเนื้อหา ซึ่งกฎหมายต้องเป็นคำสั่งหรือข้อบังคับ, เป็นคำสั่งหรือข้อบังคับของรัฐาธิปัตย์, ใช้ได้ทั่วไป, ใช้ได้เสมอไป และมีสภาพบังคับ ข) ในแง่ของพิธี ซึ่งหมายถึงวิธีการออกกฎหมายที่แตกต่างกัน ได้แก่ กฎหมายที่ตราขึ้นโดยฝ่ายนิติบัญญัติ (เช่น พระราชบัญญัติ), กฎหมายที่ตราขึ้นโดยฝ่ายบริหาร (เช่น พระราชกำหนด, พระราชกฤษฎีกา, กฎกระทรวง) และกฎหมายที่ตราขึ้นโดยองค์กรปกครองส่วนท้องถิ่น (เช่น ข้อบัญญัติจังหวัด, เทศบัญญัติ, ข้อบัญญัติกรุงเทพมหานคร/เมืองพัทยา) 3. ประเภทของกฎหมาย: แบ่งออกเป็น 3 ประเภทหลัก ได้แก่ ก) กฎหมายเอกชน (ควบคุมความสัมพันธ์ระหว่างเอกชนกับเอกชน เช่น กฎหมายแพ่งและพาณิชย์) ข) กฎหมายมหาชน (ควบคุมความสัมพันธ์ระหว่างรัฐกับเอกชน หรือระหว่างหน่วยงานของรัฐด้วยกันเอง และเกี่ยวข้องกับคนหมู่มาก เช่น กฎหมายรัฐธรรมนูญ, กฎหมายปกครอง, กฎหมายอาญา) ค) กฎหมายระหว่างประเทศ (ควบคุมความสัมพันธ์ระหว่างรัฐกับรัฐ หรือบุคคลที่มีความเกี่ยวข้องกับหลายประเทศ เช่น กฎหมายระหว่างประเทศแผนกคดีบุคคล, แผนกคดีเมือง, แผนกคดีอาญา) 4. ความเท่าเทียม vs. ความยุติธรรม: ความเท่าเทียมคือการให้ทุกคนได้รับสิ่งเดียวกันเท่ากันหมด โดยไม่คำนึงถึงความแตกต่างของแต่ละบุคคล ในขณะที่ความยุติธรรมคือการให้โอกาสที่เหมาะสมกับแต่ละบุคคล เพื่อให้ทุกคนสามารถเข้าถึงผลลัพธ์ที่เท่าเทียมกันได้ กฎหมายควรถูกนำไปใช้ด้วยหลักความยุติธรรมมากกว่าความเท่าเทียม 5. ความสำคัญของการปฏิบัติตามกฎหมาย: การเคารพและปฏิบัติตามกฎหมายเป็นสิ่งสำคัญเพื่อให้สังคมสงบสุขและระบบกฎหมายมีประสิทธิภาพ หากมีการละเมิดกฎหรือใช้กฎหมายในทางที่ผิด จะนำไปสู่ความวุ่นวายและความไม่เป็นธรรม.

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| กฎหมาย | คำสั่งหรือข้อบังคับของรัฐาธิปัตย์ที่กำหนดขึ้นเพื่อควบคุมความประพฤติของพลเมืองในสังคม |
| รัฐาธิปัตย์ | อำนาจสูงสุดในการปกครองประเทศที่กำหนดกฎเกณฑ์และระเบียบต่างๆ |
| กฎหมายเอกชน | กฎหมายที่ควบคุมความสัมพันธ์ระหว่างเอกชนกับเอกชน เช่น สัญญาต่างๆ |
| กฎหมายมหาชน | กฎหมายที่ควบคุมความสัมพันธ์ระหว่างรัฐกับเอกชน หรือระหว่างหน่วยงานของรัฐด้วยกันเอง และเกี่ยวข้องกับคนหมู่มาก |
| กฎหมายระหว่างประเทศ | กฎหมายที่ควบคุมความสัมพันธ์ระหว่างรัฐกับรัฐ หรือระหว่างบุคคลที่มีความเกี่ยวข้องกับหลายประเทศ |
| พระราชบัญญัติ (พ.ร.บ.) | กฎหมายที่ตราขึ้นโดยฝ่ายนิติบัญญัติ (รัฐสภา) ผ่านกระบวนการพิจารณา |
| พระราชกำหนด (พ.ร.ก.) | กฎหมายที่ตราขึ้นโดยฝ่ายบริหารในกรณีฉุกเฉินหรือเร่งด่วน |
| พระราชกฤษฎีกา (พ.ร.ฎ.) | กฎหมายที่ตราขึ้นโดยฝ่ายบริหารเพื่อบังคับใช้ตามพระราชบัญญัติ |
| กฎกระทรวง | กฎหมายที่ตราขึ้นโดยฝ่ายบริหารเพื่อกำหนดรายละเอียดในการปฏิบัติงานของกระทรวง |
| สภาพบังคับ | การที่กฎหมายมีผลบังคับใช้และมีบทลงโทษสำหรับผู้ฝ่าฝืน |
| เท่าเทียม | การให้สิ่งเดียวกันแก่ทุกคนโดยไม่คำนึงถึงความแตกต่างของแต่ละบุคคล |
| ยุติธรรม | การให้โอกาสที่เหมาะสมแก่แต่ละบุคคลเพื่อให้สามารถเข้าถึงผลลัพธ์ที่เท่าเทียมกันได้ |
| ฝ่ายนิติบัญญัติ | ฝ่ายที่มีอำนาจในการบัญญัติกฎหมาย ซึ่งโดยหลักคือรัฐสภา |
| ฝ่ายบริหาร | ฝ่ายที่มีอำนาจในการบริหารราชการแผ่นดินและออกกฎหมายในบางกรณี ซึ่งโดยหลักคือรัฐบาล |
| องค์กรปกครองส่วนท้องถิ่น | หน่วยงานที่บริหารราชการในท้องถิ่นและมีอำนาจออกกฎหมายท้องถิ่น เช่น ข้อบัญญัติจังหวัด |

## ตัวอย่างหรือขั้นตอน
1. ตัวอย่างความหมายของกฎหมาย: กฎหมายห้ามฆ่าคนตาย เป็นข้อบังคับที่ทุกคนต้องปฏิบัติตาม หากฝ่าฝืนจะถูกดำเนินคดี มีโทษจำคุกหรือปรับ 2. ตัวอย่างลักษณะของกฎหมายในแง่เนื้อหา: การออกกฎกระทรวงหรือการกำหนดให้ต้องเข้าอบรมและทดสอบเพื่อขอใบขับขี่เป็นคำสั่งของรัฐ กฎจราจรเป็นกฎหมายที่ใช้ได้ทั่วไป กฎหมายห้ามฆ่าคนตายยังคงมีผลบังคับใช้มาหลายสิบหรือร้อยปีแสดงถึงการใช้ได้เสมอไป และผู้ที่ทำผิดกฎหมายจะต้องได้รับโทษแสดงถึงการมีสภาพบังคับ 3. ตัวอย่างลักษณะของกฎหมายในแง่พิธี: การออกพระราชบัญญัติ (พ.ร.บ.) ต้องผ่านกระบวนการพิจารณาของรัฐสภา ส่วนการออกพระราชกำหนด (พ.ร.ก.) ในสถานการณ์ฉุกเฉิน เช่น พ.ร.ก. ฉุกเฉินในช่วงโควิด-19 สามารถทำได้โดยฝ่ายบริหารโดยไม่ต้องผ่านสภาทันที นอกจากนี้ ผู้ว่าราชการจังหวัดมีอำนาจออกข้อบัญญัติจังหวัด หรือเทศบาลออกเทศบัญญัติเพื่อใช้ในท้องถิ่นนั้นๆ 4. ตัวอย่างประเภทของกฎหมาย: กฎหมายเอกชนครอบคลุมการทำสัญญาซื้อขาย สัญญาเช่าทรัพย์สิน กฎหมายครอบครัวและมรดก หรือการจัดตั้งบริษัท กฎหมายมหาชนรวมถึงกฎหมายรัฐธรรมนูญที่คุ้มครองสิทธิเสรีภาพของประชาชน กฎหมายปกครองที่จำกัดอำนาจของเจ้าหน้าที่รัฐ และกฎหมายอาญาที่ระบุความผิดและโทษ เช่น การหมิ่นประมาท การขับรถชนคนตาย หรือการทำร้ายร่างกาย กฎหมายระหว่างประเทศใช้ในกรณีข้อพิพาทระหว่างประเทศ เช่น กรณีเขาพระวิหารระหว่างไทยกับกัมพูชา ซึ่งต้องใช้กฎหมายระหว่างประเทศแผนกคดีเมืองมาตัดสิน 5. ภาพประกอบความเท่าเทียมกับความยุติธรรม: ภาพคนสามคนที่มีความสูงต่างกันยืนดูการแข่งขันกีฬาหลังรั้ว โดยในส่วนของ 'เท่าเทียม' ทุกคนได้รับกล่องไม้คนละ 1 กล่อง ทำให้คนตัวสูงเห็นได้ชัดเจน คนตัวกลางเห็นได้พอดี แต่คนตัวเตี้ยยังคงมองไม่เห็น ส่วนในส่วนของ 'ยุติธรรม' คนตัวสูงไม่จำเป็นต้องใช้กล่อง คนตัวกลางใช้ 1 กล่อง และคนตัวเตี้ยใช้ 2 กล่อง ทำให้ทุกคนสามารถมองเห็นการแข่งขันได้อย่างเท่าเทียมกัน 6. อุปมาอุปไมยสนามฟุตบอล: เปรียบเทียบสนามฟุตบอลที่มีสองทีม (เช่น แมนยูฯ และลิเวอร์พูล) และกรรมการ (ผู้ตัดสิน) กับระบบกฎหมาย กฎระเบียบของเกมเปรียบเสมือนกฎหมายที่ทุกคนต้องปฏิบัติตาม กรรมการเปรียบเสมือนผู้บังคับใช้กฎหมาย หากมีการละเมิดกฎกติกาหรือมีการใช้กฎหมายในทางที่ผิด (เช่น การติดสินบนกรรมการ) จะทำให้เกิดความไม่เป็นธรรมและความวุ่นวาย ผู้ชม (ประชาชน) จะรู้สึกไม่พอใจและระบบจะล่มสลาย.

## สรุปท้ายบท
การเรียนรู้กฎหมายเบื้องต้นทำให้เข้าใจว่ากฎหมายคือคำสั่งของรัฐาธิปัตย์ที่มีสภาพบังคับ และมีลักษณะการออกและประเภทที่แตกต่างกัน การทำความเข้าใจกฎหมายเป็นสิ่งสำคัญในการดำเนินชีวิตและประกอบธุรกิจ เพื่อให้สามารถปฏิบัติตามได้อย่างถูกต้องและใช้เป็นเครื่องมือในการปกป้องสิทธิของตนเอง สิ่งสำคัญที่สุดคือการนำกฎหมายไปใช้ด้วยหลักของ 'ความยุติธรรม' มากกว่า 'ความเท่าเทียม' เพราะความยุติธรรมคำนึงถึงความแตกต่างของแต่ละบุคคลและให้โอกาสที่เหมาะสมเพื่อให้ทุกคนสามารถเข้าถึงผลลัพธ์ที่เท่าเทียมกันได้ การเคารพกฎกติกาและไม่ใช้กฎหมายในทางที่ผิดจะนำไปสู่สังคมที่สงบสุขและเป็นธรรม หากทุกคนปฏิบัติตามกฎหมายอย่างถูกต้องและยอมรับได้ ก็จะไม่มีคำถามถึงความไม่ยุติธรรมในสังคม แต่หากผู้มีอำนาจหรือผู้ที่ได้เปรียบใช้กฎหมายในทางที่ผิด ก็จะทำให้ระบบกฎหมายขาดความน่าเชื่อถือและเกิดความวุ่นวายขึ้นได้.

## คำถามทบทวน
1. กฎหมายคืออะไร และมีลักษณะสำคัญในแง่ของเนื้อหาอย่างไรบ้าง?
2. กฎหมายที่ตราขึ้นโดยฝ่ายนิติบัญญัติและฝ่ายบริหารมีความแตกต่างกันในกระบวนการออกกฎหมายอย่างไร พร้อมยกตัวอย่างประกอบ?
