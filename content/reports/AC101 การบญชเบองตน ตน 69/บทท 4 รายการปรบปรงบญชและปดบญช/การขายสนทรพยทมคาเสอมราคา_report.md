# การขายสินทรัพย์ที่มีค่าเสื่อมราคา

## บทนำ
บทเรียนนี้อธิบายถึงหลักการและขั้นตอนการบันทึกบัญชีสำหรับการจำหน่ายสินทรัพย์ที่มีค่าเสื่อมราคา โดยเน้นย้ำถึงความสำคัญของการปรับปรุงค่าเสื่อมราคาให้เป็นปัจจุบัน ณ วันที่จำหน่ายสินทรัพย์ เพื่อให้สามารถคำนวณกำไรหรือขาดทุนจากการจำหน่ายได้อย่างถูกต้อง การทำความเข้าใจกระบวนการนี้เป็นสิ่งสำคัญสำหรับนักบัญชีในการจัดการสินทรัพย์ถาวรของกิจการ

## วัตถุประสงค์
วัตถุประสงค์ของบทเรียนนี้คือเพื่อให้ผู้เรียนสามารถ: 1. เข้าใจหลักการคิดค่าเสื่อมราคาสำหรับสินทรัพย์ที่จำหน่ายระหว่างงวดบัญชี 2. คำนวณค่าเสื่อมราคาสะสมและมูลค่าตามบัญชีของสินทรัพย์ ณ วันที่จำหน่าย 3. คำนวณกำไรหรือขาดทุนจากการจำหน่ายสินทรัพย์ 4. บันทึกรายการบัญชีที่เกี่ยวข้องกับการปรับปรุงค่าเสื่อมราคาและการจำหน่ายสินทรัพย์ได้อย่างถูกต้อง

## แนวคิดสำคัญ
แนวคิดสำคัญในการจำหน่ายสินทรัพย์ที่มีค่าเสื่อมราคาประกอบด้วย: 1. การคิดค่าเสื่อมราคา: สินทรัพย์ประเภทที่ดิน อาคาร และอุปกรณ์ (PPE) จะมีการคิดค่าเสื่อมราคาเพื่อกระจายต้นทุนของสินทรัพย์ตลอดอายุการใช้งาน 2. การปรับปรุงค่าเสื่อมราคา: หากมีการจำหน่ายสินทรัพย์ระหว่างปี กิจการจะต้องปรับปรุงค่าเสื่อมราคาสำหรับงวดปัจจุบันจนถึงวันที่จำหน่าย เพื่อให้ค่าเสื่อมราคาสะสมสะท้อนมูลค่าการใช้งานที่แท้จริงของสินทรัพย์ 3. มูลค่าตามบัญชี (Book Value): คือราคาทุนของสินทรัพย์หักด้วยค่าเสื่อมราคาสะสมทั้งหมด ณ วันที่กำหนด ซึ่งเป็นมูลค่าที่ใช้ในการเปรียบเทียบกับราคาขายเพื่อหากำไรหรือขาดทุน 4. กำไร/ขาดทุนจากการจำหน่ายสินทรัพย์: เกิดจากผลต่างระหว่างราคาขายสินทรัพย์กับมูลค่าตามบัญชีของสินทรัพย์นั้น หากราคาขายสูงกว่ามูลค่าตามบัญชี จะเป็นกำไร แต่หากราคาขายต่ำกว่า จะเป็นขาดทุน 5. การปิดบัญชี: เมื่อจำหน่ายสินทรัพย์ออกไปแล้ว บัญชีสินทรัพย์ (ราคาทุน) และบัญชีค่าเสื่อมราคาสะสมที่เกี่ยวข้องกับสินทรัพย์นั้นจะต้องถูกปิดออกจากบัญชีของกิจการ

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| สินทรัพย์ที่มีค่าเสื่อมราคา | สินทรัพย์ที่มูลค่าลดลงตามกาลเวลาหรือการใช้งาน เช่น อาคาร อุปกรณ์ เครื่องจักร |
| ค่าเสื่อมราคา | ค่าใช้จ่ายที่เกิดจากการปันส่วนต้นทุนของสินทรัพย์ถาวรตลอดอายุการใช้งาน |
| ค่าเสื่อมราคาสะสม | ยอดรวมของค่าเสื่อมราคาที่คิดสะสมมาตั้งแต่เริ่มใช้งานสินทรัพย์จนถึงปัจจุบัน |
| มูลค่าตามบัญชี (Book Value) | ราคาทุนของสินทรัพย์หักด้วยค่าเสื่อมราคาสะสม ณ วันที่กำหนด |
| มูลค่าซาก (Salvage Value) | มูลค่าประมาณการของสินทรัพย์เมื่อสิ้นสุดอายุการใช้งาน |
| กำไรจากการจำหน่ายสินทรัพย์ | ผลต่างที่เป็นบวกเมื่อราคาขายสินทรัพย์สูงกว่ามูลค่าตามบัญชี |
| ขาดทุนจากการจำหน่ายสินทรัพย์ | ผลต่างที่เป็นลบเมื่อราคาขายสินทรัพย์ต่ำกว่ามูลค่าตามบัญชี |
| ราคาทุน | ราคาที่ซื้อสินทรัพย์มา รวมถึงค่าใช้จ่ายที่จำเป็นเพื่อให้สินทรัพย์พร้อมใช้งาน |
| อายุการใช้งาน | ระยะเวลาที่คาดว่าสินทรัพย์จะสามารถใช้งานได้ |
| สมุดรายวันทั่วไป | สมุดบัญชีที่ใช้บันทึกรายการค้าต่างๆ ตามลำดับวันที่เกิดรายการ |
| เดบิต (Dr.) | ด้านซ้ายของบัญชี ใช้บันทึกการเพิ่มขึ้นของสินทรัพย์และค่าใช้จ่าย หรือการลดลงของหนี้สิน ส่วนของเจ้าของ และรายได้ |
| เครดิต (Cr.) | ด้านขวาของบัญชี ใช้บันทึกการลดลงของสินทรัพย์และค่าใช้จ่าย หรือการเพิ่มขึ้นของหนี้สิน ส่วนของเจ้าของ และรายได้ |

## ตัวอย่างหรือขั้นตอน
ตัวอย่างการบันทึกบัญชีการจำหน่ายเครื่องจักร:

**ข้อมูลสถานการณ์:**
*   กิจการซื้อเครื่องจักร 1 เครื่อง เมื่อวันที่ 1 มกราคม 25X4
*   ราคาทุนเครื่องจักร: 250,000 บาท
*   ค่าติดตั้ง: 20,000 บาท
*   ราคาทุนรวม: 250,000 + 20,000 = 270,000 บาท
*   คาดว่าจะอายุใช้งาน: 5 ปี
*   มูลค่าซาก: 10,000 บาท
*   ต่อมาวันที่ 1 กรกฎาคม 25X7 กิจการได้จำหน่ายเครื่องจักรดังกล่าวออกไปในราคา 110,000 บาท เนื่องจากมีการซื้อเครื่องจักรใหม่เข้ามาแทน

**ขั้นตอนการบันทึกบัญชี ณ วันที่จำหน่ายเครื่องจักร (1 กรกฎาคม 25X7):**

**1. คำนวณค่าเสื่อมราคาต่อปี:**
*   ค่าเสื่อมราคาต่อปี = (ราคาทุน - มูลค่าซาก) / อายุการใช้งาน
*   ค่าเสื่อมราคาต่อปี = (270,000 บาท - 10,000 บาท) / 5 ปี = 260,000 บาท / 5 ปี = 52,000 บาทต่อปี

**2. ปรับปรุงค่าเสื่อมราคาสำหรับงวดปัจจุบัน (1 มกราคม 25X7 - 1 กรกฎาคม 25X7):**
*   เนื่องจากมีการจำหน่ายสินทรัพย์ระหว่างปี (วันที่ 1 กรกฎาคม) และค่าเสื่อมราคาครั้งสุดท้ายถูกคิดเมื่อวันที่ 31 ธันวาคม 25X6 จึงต้องคิดค่าเสื่อมราคาเพิ่มสำหรับระยะเวลา 6 เดือนของปี 25X7
*   ค่าเสื่อมราคาสำหรับ 6 เดือน = 52,000 บาท/ปี * (6/12) = 26,000 บาท
*   **บันทึกรายการปรับปรุงค่าเสื่อมราคา:**
    *   เดบิต (Dr.) ค่าเสื่อมราคาเครื่องจักร 26,000 บาท
    *   เครดิต (Cr.) ค่าเสื่อมราคาสะสม-เครื่องจักร 26,000 บาท

**3. คำนวณค่าเสื่อมราคาสะสมทั้งหมด ณ วันที่จำหน่าย:**
*   ระยะเวลาการใช้งานเครื่องจักร: 
    *   ปี 25X4: 1 ปี
    *   ปี 25X5: 1 ปี
    *   ปี 25X6: 1 ปี
    *   ปี 25X7: 0.5 ปี (6 เดือน)
    *   รวมระยะเวลาใช้งาน: 3.5 ปี
*   ค่าเสื่อมราคาสะสมทั้งหมด = ค่าเสื่อมราคาต่อปี * ระยะเวลาใช้งาน
*   ค่าเสื่อมราคาสะสมทั้งหมด = 52,000 บาท/ปี * 3.5 ปี = 182,000 บาท

**4. คำนวณมูลค่าตามบัญชี (Book Value) ณ วันที่จำหน่าย:**
*   มูลค่าตามบัญชี = ราคาทุน - ค่าเสื่อมราคาสะสมทั้งหมด
*   มูลค่าตามบัญชี = 270,000 บาท - 182,000 บาท = 88,000 บาท

**5. คำนวณกำไรหรือขาดทุนจากการจำหน่ายสินทรัพย์:**
*   กำไร/ขาดทุน = ราคาขาย - มูลค่าตามบัญชี
*   กำไรจากการจำหน่าย = 110,000 บาท - 88,000 บาท = 22,000 บาท (เป็นกำไร เนื่องจากราคาขายสูงกว่ามูลค่าตามบัญชี)

**6. บันทึกรายการจำหน่ายเครื่องจักร:**
*   **บันทึกรายการ:**
    *   เดบิต (Dr.) เงินสด (ราคาขาย) 110,000 บาท
    *   เดบิต (Dr.) ค่าเสื่อมราคาสะสม-เครื่องจักร (ยอดรวมทั้งหมด) 182,000 บาท
    *   เครดิต (Cr.) เครื่องจักร (ราคาทุนเดิม) 270,000 บาท
    *   เครดิต (Cr.) กำไรจากการจำหน่ายเครื่องจักร 22,000 บาท
*   **ตรวจสอบความสมดุล:**
    *   รวมเดบิต: 110,000 + 182,000 = 292,000 บาท
    *   รวมเครดิต: 270,000 + 22,000 = 292,000 บาท
    *   (เดบิตเท่ากับเครดิต แสดงว่าบันทึกถูกต้อง)

## สรุปท้ายบท
การจำหน่ายสินทรัพย์ที่มีค่าเสื่อมราคาต้องดำเนินการอย่างรอบคอบ โดยมีประเด็นสำคัญที่ต้องจดจำคือ: 1. ต้องปรับปรุงค่าเสื่อมราคาให้เป็นปัจจุบันเสมอจนถึงวันที่จำหน่ายสินทรัพย์ โดยเฉพาะอย่างยิ่งหากการจำหน่ายเกิดขึ้นระหว่างงวดบัญชี 2. การคำนวณกำไรหรือขาดทุนจากการจำหน่ายสินทรัพย์ต้องเปรียบเทียบราคาขายกับมูลค่าตามบัญชีของสินทรัพย์ ไม่ใช่ราคาทุนเดิม 3. มูลค่าตามบัญชีคือราคาทุนหักด้วยค่าเสื่อมราคาสะสมทั้งหมดที่เกิดขึ้น 4. เมื่อมีการจำหน่ายสินทรัพย์ บัญชีสินทรัพย์ (ราคาทุน) และบัญชีค่าเสื่อมราคาสะสมที่เกี่ยวข้องจะต้องถูกล้างออกจากระบบบัญชี เพื่อสะท้อนสถานะที่แท้จริงของสินทรัพย์ในกิจการ

## คำถามทบทวน
1. เหตุใดจึงต้องมีการปรับปรุงค่าเสื่อมราคาของสินทรัพย์ ณ วันที่จำหน่าย หากการจำหน่ายเกิดขึ้นระหว่างงวดบัญชี?
2. สูตรในการคำนวณค่าเสื่อมราคาต่อปีแบบเส้นตรงคืออะไร และมีองค์ประกอบใดบ้าง?
3. มูลค่าตามบัญชี (Book Value) ของสินทรัพย์คำนวณได้อย่างไร และมีความสำคัญอย่างไรในการจำหน่ายสินทรัพย์?
4. หากกิจการจำหน่ายเครื่องจักรในราคา 150,000 บาท โดยมีราคาทุน 300,000 บาท และค่าเสื่อมราคาสะสม 180,000 บาท กิจการจะได้กำไรหรือขาดทุนจากการจำหน่ายเท่าใด?
5. เมื่อบันทึกบัญชีการจำหน่ายสินทรัพย์ รายการบัญชีใดบ้างที่ต้องเดบิตและเครดิต เพื่อให้บัญชีแสดงผลที่ถูกต้อง?
