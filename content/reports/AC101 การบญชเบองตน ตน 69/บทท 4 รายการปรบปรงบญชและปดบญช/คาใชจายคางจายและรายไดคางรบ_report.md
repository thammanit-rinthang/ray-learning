# ค่าใช้จ่ายค้างจ่ายและรายได้ค้างรับ

## บทนำ
บทเรียนนี้จะอธิบายถึงแนวคิดสำคัญในระบบบัญชีเกณฑ์คงค้าง (Accrual Basis) ซึ่งเป็นหลักการพื้นฐานในการจัดทำบัญชีที่ใช้กันโดยทั่วไป โดยเฉพาะอย่างยิ่งในเรื่องของ 'ค่าใช้จ่ายค้างจ่าย' และ 'รายได้ค้างรับ' ซึ่งเป็นรายการปรับปรุงที่จำเป็นต้องทำ ณ วันสิ้นงวดบัญชี เพื่อให้งบการเงินแสดงผลการดำเนินงานและฐานะการเงินที่ถูกต้องตามความเป็นจริง การบันทึกบัญชีตามเกณฑ์คงค้างจะรับรู้รายได้และค่าใช้จ่ายเมื่อเกิดเหตุการณ์ขึ้น ไม่ใช่เมื่อมีการรับหรือจ่ายเงินสด ทำให้เกิดรายการที่ยังไม่ครบถ้วนสมบูรณ์ ณ วันสิ้นงวด ซึ่งต้องมีการปรับปรุงก่อนการปิดงบการเงิน

## วัตถุประสงค์
1. เพื่อให้เข้าใจถึงความจำเป็นและเหตุผลในการทำรายการปรับปรุงบัญชีตามเกณฑ์คงค้าง 2. เพื่อให้สามารถระบุและบันทึกรายการค่าใช้จ่ายค้างจ่ายได้อย่างถูกต้อง 3. เพื่อให้สามารถระบุและบันทึกรายการรายได้ค้างรับได้อย่างถูกต้อง 4. เพื่อให้เข้าใจผลกระทบของรายการปรับปรุงต่อการแสดงผลการดำเนินงานและฐานะการเงินของกิจการ

## แนวคิดสำคัญ
แนวคิดสำคัญของบทเรียนนี้คือการบันทึกบัญชีตาม 'เกณฑ์เงินค้าง' หรือ 'เกณฑ์สิทธิ์' (Accrual Basis) ซึ่งหมายถึงการรับรู้รายได้เมื่อกิจการได้ให้ประโยชน์แก่ผู้อื่นแล้ว และรับรู้ค่าใช้จ่ายเมื่อกิจการได้รับประโยชน์จากผู้อื่นแล้ว โดยไม่จำเป็นต้องมีการรับหรือจ่ายเงินสดเกิดขึ้นจริง ณ ขณะนั้น ซึ่งแตกต่างจากเกณฑ์เงินสดที่รับรู้รายได้และค่าใช้จ่ายเมื่อมีการรับหรือจ่ายเงินสดเท่านั้น ด้วยเหตุนี้ ณ วันสิ้นงวดบัญชี จึงมักจะมีรายการรายได้และค่าใช้จ่ายที่เกิดขึ้นแล้วแต่ยังไม่ครบถ้วนสมบูรณ์ตามงวดบัญชี ทำให้ต้องมีการทำ 'รายการปรับปรุง' (Adjusting Entries) เพื่อให้ข้อมูลทางการเงินถูกต้องและเป็นปัจจุบัน รายการปรับปรุงที่สำคัญในบัญชีเบื้องต้นมีทั้งหมด 7 ประเภท ได้แก่ ค่าใช้จ่ายค้างจ่าย, รายได้ค้างรับ, ค่าใช้จ่ายจ่ายล่วงหน้า, รายได้รับล่วงหน้า, วัสดุสิ้นเปลืองใช้ไป, ค่าเสื่อมราคา และหนี้สงสัยจะสูญ โดยในบทเรียนนี้จะเน้นที่ค่าใช้จ่ายค้างจ่ายและรายได้ค้างรับเป็นหลัก การปรับปรุงบัญชีไม่เพียงทำให้รายได้และค่าใช้จ่ายถูกต้องเท่านั้น แต่ยังส่งผลให้ฐานะการเงินของกิจการถูกต้องด้วยการรับรู้สินทรัพย์และหนี้สินที่เกิดขึ้นจริง

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| เกณฑ์เงินค้าง (Accrual Basis) | หลักการบัญชีที่รับรู้รายได้เมื่อเกิดสิทธิ์ในการได้รับ และรับรู้ค่าใช้จ่ายเมื่อเกิดภาระที่ต้องจ่าย โดยไม่คำนึงถึงการรับหรือจ่ายเงินสด |
| เกณฑ์สิทธิ์ | คำเรียกอีกอย่างหนึ่งของเกณฑ์เงินค้าง ซึ่งเน้นการรับรู้รายการเมื่อเกิดสิทธิ์หรือภาระ |
| รายการปรับปรุง (Adjusting Entries) | รายการที่ทำขึ้น ณ วันสิ้นงวดบัญชี เพื่อปรับปรุงบัญชีรายได้และค่าใช้จ่ายให้ถูกต้องตามงวดบัญชี และปรับปรุงบัญชีสินทรัพย์และหนี้สินให้แสดงมูลค่าที่แท้จริง |
| ค่าใช้จ่ายค้างจ่าย (Accrued Expenses) | ค่าใช้จ่ายที่กิจการได้รับประโยชน์หรือใช้บริการไปแล้วในงวดบัญชีปัจจุบัน แต่ยังไม่ได้จ่ายชำระเงิน และยังไม่ถึงกำหนดชำระ |
| รายได้ค้างรับ (Accrued Income) | รายได้ที่กิจการได้ให้ประโยชน์หรือบริการไปแล้วในงวดบัญชีปัจจุบัน แต่ยังไม่ได้รับชำระเงิน และยังไม่ถึงกำหนดรับ |
| หนี้สิน (Liability) | ภาระผูกพันของกิจการที่ต้องชำระคืนในอนาคต |
| สินทรัพย์ (Asset) | ทรัพยากรที่กิจการควบคุมได้และคาดว่าจะได้รับประโยชน์เชิงเศรษฐกิจในอนาคต |
| ดอกเบี้ยจ่าย (Interest Expense) | ค่าใช้จ่ายที่เกิดจากการกู้ยืมเงิน |
| ดอกเบี้ยรับ (Interest Income) | รายได้ที่เกิดจากการให้กู้ยืมเงินหรือการลงทุน |
| งบการเงิน (Financial Statements) | รายงานทางการเงินที่แสดงฐานะการเงินและผลการดำเนินงานของกิจการ |
| งบกำไรขาดทุน (Income Statement) | งบการเงินที่แสดงผลการดำเนินงานของกิจการในช่วงระยะเวลาหนึ่ง |
| งบแสดงฐานะการเงิน (Balance Sheet) | งบการเงินที่แสดงฐานะการเงินของกิจการ ณ วันใดวันหนึ่ง |
| ลูกหนี้การค้า (Accounts Receivable) | เงินที่กิจการมีสิทธิ์เรียกเก็บจากลูกค้าจากการขายสินค้าหรือบริการตามปกติ |
| เจ้าหนี้อื่น (Other Payables) | หนี้สินที่ไม่ได้เกิดจากการซื้อสินค้าหรือบริการตามปกติ |

## ตัวอย่างหรือขั้นตอน
การบันทึกรายการปรับปรุงสำหรับค่าใช้จ่ายค้างจ่ายและรายได้ค้างรับมีขั้นตอนและตัวอย่างดังนี้:

**1. ค่าใช้จ่ายค้างจ่าย (Accrued Expenses)**
   *   **ความหมาย**: ค่าใช้จ่ายที่กิจการได้รับประโยชน์หรือใช้บริการไปแล้วในงวดบัญชีปัจจุบัน แต่ยังไม่ได้จ่ายชำระเงิน และยังไม่ถึงกำหนดชำระ เช่น ค่าน้ำ ค่าไฟ ค่าโทรศัพท์ หรือค่าโฆษณาที่ได้รับบิลแล้วแต่ยังไม่จ่ายเงิน ณ วันสิ้นงวดบัญชี ค่าใช้จ่ายเหล่านี้ถือเป็นหนี้สินของกิจการ
   *   **หลักการบันทึก**: ณ วันสิ้นงวดบัญชี (เช่น 31 ธันวาคม) ต้องบันทึกค่าใช้จ่ายที่เกิดขึ้นแล้วแต่ยังไม่ได้จ่ายเงิน เพื่อให้ค่าใช้จ่ายครบถ้วนและรับรู้หนี้สินที่เกิดขึ้น
   *   **รูปแบบการบันทึกบัญชี**: 
        เดบิต (Dr.) ค่าใช้จ่าย (ชื่อค่าใช้จ่ายนั้นๆ) XX
        เครดิต (Cr.) ค่าใช้จ่ายค้างจ่าย XX
   *   **ตัวอย่างที่ 1.1: ค่าโฆษณาค้างจ่าย**
        *   **สถานการณ์**: ณ วันที่ 31 ธันวาคม 25x9 กิจการได้ตรวจพบค่าโฆษณาที่ยังไม่ได้จ่ายเงินจำนวน 8,000 บาท ซึ่งกิจการได้ใช้ประโยชน์จากการโฆษณาไปแล้ว (ได้รับบิลแจ้งหนี้แล้ว แต่กำหนดชำระคือ 18 มกราคม)
        *   **การคำนวณ**: ค่าโฆษณาที่ค้างจ่ายคือ 8,000 บาท
        *   **การบันทึกบัญชี ณ 31 ธันวาคม 25x9**:
            เดบิต ค่าโฆษณา 8,000
            เครดิต ค่าใช้จ่ายค้างจ่าย 8,000
            (ปรับปรุงค่าโฆษณา)
   *   **ตัวอย่างที่ 1.2: ดอกเบี้ยค้างจ่าย**
        *   **สถานการณ์**: เมื่อวันที่ 1 ตุลาคม 25x9 กิจการได้กู้เงินจากธนาคารจำนวน 100,000 บาท อัตราดอกเบี้ย 18% ต่อปี กำหนดจ่ายดอกเบี้ยปีละครั้งทุกวันที่ 1 ตุลาคม (กิจการปิดบัญชีทุกวันที่ 31 ธันวาคม)
        *   **การคำนวณ**: ดอกเบี้ยที่ค้างจ่ายสำหรับงวด 3 เดือน (ตุลาคม, พฤศจิกายน, ธันวาคม) คือ:
            เงินต้น x อัตราดอกเบี้ย x ระยะเวลา = 100,000 บาท x 18% x (3/12) = 4,500 บาท
        *   **การบันทึกบัญชี ณ 31 ธันวาคม 25x9**:
            เดบิต ดอกเบี้ยจ่าย 4,500
            เครดิต ดอกเบี้ยค้างจ่าย 4,500
            (ปรับปรุงดอกเบี้ยจ่าย)

**2. รายได้ค้างรับ (Accrued Income)**
   *   **ความหมาย**: รายได้ที่กิจการได้ให้ประโยชน์หรือบริการไปแล้วในงวดบัญชีปัจจุบัน แต่ยังไม่ได้รับชำระเงิน และยังไม่ถึงกำหนดรับ รายได้ค้างรับนี้ใช้สำหรับ 'รายได้อื่น' เท่านั้น หากเป็นรายได้หลักจากการขายสินค้าหรือบริการ จะใช้การส่งบิลแจ้งหนี้และบันทึกเป็นลูกหนี้การค้า
   *   **หลักการบันทึก**: ณ วันสิ้นงวดบัญชี ต้องบันทึกรายได้ที่เกิดขึ้นแล้วแต่ยังไม่ได้รับเงิน เพื่อให้รายได้ครบถ้วนและรับรู้สินทรัพย์ที่กิจการมีสิทธิ์จะได้รับ
   *   **รูปแบบการบันทึกบัญชี**: 
        เดบิต (Dr.) รายได้ค้างรับ (ชื่อรายได้นั้นๆ) XX
        เครดิต (Cr.) รายได้ (ชื่อรายได้นั้นๆ) XX
   *   **ตัวอย่างที่ 2: ดอกเบี้ยค้างรับ**
        *   **สถานการณ์**: เมื่อวันที่ 1 ตุลาคม 25x9 กิจการได้ซื้อพันธบัตรรัฐบาลมูลค่า 100,000 บาท อัตราดอกเบี้ย 12% ต่อปี กำหนดจ่ายดอกเบี้ยปีละครั้งทุกวันที่ 1 ตุลาคม (กิจการปิดบัญชีทุกวันที่ 31 ธันวาคม)
        *   **การคำนวณ**: ดอกเบี้ยที่ค้างรับสำหรับงวด 3 เดือน (ตุลาคม, พฤศจิกายน, ธันวาคม) คือ:
            เงินต้น x อัตราดอกเบี้ย x ระยะเวลา = 100,000 บาท x 12% x (3/12) = 3,000 บาท
        *   **การบันทึกบัญชี ณ 31 ธันวาคม 25x9**:
            เดบิต ดอกเบี้ยค้างรับ 3,000
            เครดิต ดอกเบี้ยรับ 3,000
            (ปรับปรุงดอกเบี้ยรับ)

## สรุปท้ายบท
การทำรายการปรับปรุงสำหรับค่าใช้จ่ายค้างจ่ายและรายได้ค้างรับเป็นสิ่งจำเป็นอย่างยิ่งในการจัดทำบัญชีตามเกณฑ์เงินค้าง เพื่อให้งบการเงินแสดงข้อมูลที่ถูกต้องและน่าเชื่อถือ การไม่ทำรายการปรับปรุงจะส่งผลให้:
1.  **งบกำไรขาดทุนไม่ถูกต้อง**: รายได้หรือค่าใช้จ่ายของงวดบัญชีนั้นๆ จะไม่ครบถ้วน ทำให้กำไรสุทธิหรือขาดทุนสุทธิผิดเพี้ยนไปจากความเป็นจริง
2.  **งบแสดงฐานะการเงินไม่ถูกต้อง**: กิจการจะไม่รับรู้หนี้สินที่เกิดขึ้นจริง (ค่าใช้จ่ายค้างจ่าย) หรือไม่รับรู้สินทรัพย์ที่ควรได้รับ (รายได้ค้างรับ) ทำให้ฐานะการเงินไม่สะท้อนความจริง
ดังนั้น การปรับปรุงบัญชีจึงมีความสำคัญต่อทั้งผลการดำเนินงานและฐานะการเงินของกิจการ ทำให้ผู้ใช้งบการเงินสามารถตัดสินใจได้อย่างมีประสิทธิภาพบนพื้นฐานของข้อมูลที่ถูกต้อง

## คำถามทบทวน
1. เหตุใดกิจการที่ใช้เกณฑ์เงินค้างในการบันทึกบัญชีจึงจำเป็นต้องทำรายการปรับปรุงค่าใช้จ่ายค้างจ่ายและรายได้ค้างรับ ณ วันสิ้นงวดบัญชี
2. ค่าใช้จ่ายค้างจ่ายคืออะไร และมีผลกระทบต่อสมการบัญชี (สินทรัพย์ = หนี้สิน + ส่วนของเจ้าของ) อย่างไรบ้าง
3. รายได้ค้างรับแตกต่างจากลูกหนี้การค้าอย่างไร และกิจการควรบันทึกรายได้ค้างรับเมื่อใด
4. จงแสดงการคำนวณและบันทึกรายการปรับปรุงสำหรับดอกเบี้ยจ่ายค้างจ่าย หากกิจการกู้เงิน 200,000 บาท อัตราดอกเบี้ย 10% ต่อปี เมื่อวันที่ 1 พฤศจิกายน และปิดบัญชีวันที่ 31 ธันวาคม
5. การไม่ทำรายการปรับปรุงค่าใช้จ่ายค้างจ่ายและรายได้ค้างรับจะส่งผลเสียต่อการวิเคราะห์งบการเงินของกิจการอย่างไร
