# บทที่1.4

## บทนำ
บทเรียนนี้จะแนะนำให้รู้จักกับการแบ่งประเภทของวิชาชีพบัญชีออกเป็นสองประเภทหลัก ได้แก่ การบัญชีการเงินและการบัญชีบริหาร พร้อมทั้งอธิบายถึงความแตกต่างในด้านวัตถุประสงค์ ผู้ใช้งาน และหลักเกณฑ์ที่ใช้ในการจัดทำ นอกจากนี้ยังเน้นย้ำถึงความสำคัญของจรรยาบรรณวิชาชีพบัญชีและกรอบกฎหมายที่กำกับดูแลวิชาชีพนี้ในประเทศไทย โดยเฉพาะพระราชบัญญัติวิชาชีพบัญชี พ.ศ. 2547 ซึ่งกำหนดคุณสมบัติและบทบาทหน้าที่ของนักบัญชี รวมถึงบทลงโทษสำหรับการไม่ปฏิบัติตามกฎหมายและจรรยาบรรณ

## วัตถุประสงค์
1. เพื่อให้ผู้เรียนเข้าใจถึงความแตกต่างระหว่างการบัญชีการเงินและการบัญชีบริหารในด้านวัตถุประสงค์ ผู้ใช้งาน และหลักเกณฑ์การจัดทำ 2. เพื่อให้ผู้เรียนตระหนักถึงความสำคัญของจรรยาบรรณวิชาชีพบัญชีและคุณสมบัติที่จำเป็นสำหรับผู้ประกอบวิชาชีพบัญชี 3. เพื่อให้ผู้เรียนทราบถึงบทบาทและอำนาจหน้าที่ของสภาวิชาชีพบัญชีในการกำกับดูแลและพัฒนาวิชาชีพบัญชีในประเทศไทย 4. เพื่อให้ผู้เรียนเข้าใจถึงกรอบกฎหมายที่เกี่ยวข้องกับวิชาชีพบัญชี โดยเฉพาะพระราชบัญญัติวิชาชีพบัญชี พ.ศ. 2547 และผลกระทบของการไม่ปฏิบัติตาม

## แนวคิดสำคัญ
วิชาชีพบัญชีแบ่งออกเป็น 2 ประเภทหลัก ได้แก่ การบัญชีการเงิน (Financial Accounting) และการบัญชีบริหาร (Managerial Accounting) การบัญชีการเงินเป็นการจัดทำบัญชีตามหลักการบัญชีที่รับรองทั่วไป (GAAP) มาตรฐานการบัญชี และมาตรฐานการรายงานทางการเงินที่กำหนดโดยหน่วยงานกำกับดูแล เช่น สภาวิชาชีพบัญชีฯ ตลาดหลักทรัพย์แห่งประเทศไทย และกรมพัฒนาธุรกิจการค้า เพื่อนำเสนอข้อมูลผลการดำเนินงานและฐานะการเงินแก่บุคคลภายนอก เช่น นักลงทุน เจ้าหนี้ และหน่วยงานราชการ รูปแบบการรายงานข้อมูลจะมีความแน่นอนและเป็นมาตรฐาน ในทางตรงกันข้าม การบัญชีบริหารเป็นการจัดทำบัญชีเพื่อวัตถุประสงค์ของผู้ใช้ข้อมูลภายในกิจการ เช่น ฝ่ายบริหารหรือเจ้าของกิจการ เพื่อช่วยในการวางแผน ควบคุม และตัดสินใจเกี่ยวกับการดำเนินงานของกิจการ โดยทั่วไปรูปแบบการรายงานข้อมูลทางการบัญชีบริหารจะไม่มีรูปแบบที่แน่นอนและไม่จำเป็นต้องจัดทำตามหลักการบัญชีที่รับรองทั่วไป แต่จะคำนึงถึงความต้องการของผู้ใช้ข้อมูลเป็นหลัก ข้อมูลทางการบัญชีบริหารมักเป็นข้อมูลชั้นความลับ เช่น โครงสร้างต้นทุนสินค้า เพื่อใช้ในการเพิ่มกำไรและลดค่าใช้จ่าย

นอกจากนี้ นักบัญชียังต้องยึดมั่นในจรรยาบรรณวิชาชีพ ซึ่งรวมถึงความโปร่งใส อิสระ เที่ยงธรรม ซื่อสัตย์ และมีความรู้ความสามารถในการปฏิบัติงานตามมาตรฐานที่กำหนด สิ่งที่สำคัญและเป็นความรับผิดชอบเฉพาะของนักบัญชีคือ การรักษาความลับ โดยห้ามนำข้อมูลของกิจการไปเปิดเผย การไม่ปฏิบัติตามจรรยาบรรณอาจนำไปสู่บทลงโทษทางกฎหมายได้

วิชาชีพบัญชีในประเทศไทยอยู่ภายใต้การกำกับดูแลของพระราชบัญญัติวิชาชีพบัญชี พ.ศ. 2547 ซึ่งเป็นกฎหมายที่กำหนดบทบาทหน้าที่ของสภาวิชาชีพบัญชีในการกำหนดมาตรฐานการบัญชี จรรยาบรรณวิชาชีพ รับรองหลักสูตร และควบคุมความประพฤติของสมาชิก ผู้ทำบัญชีตามกฎหมายนี้จะต้องมีคุณสมบัติเฉพาะ ได้แก่ มีภูมิลำเนาหรือถิ่นที่อยู่ในราชอาณาจักร มีความรู้ภาษาไทยเพียงพอ ไม่เคยต้องโทษจำคุกในความผิดตามกฎหมายบัญชีหรือกฎหมายสอบบัญชี (เว้นแต่พ้นโทษมาแล้วไม่น้อยกว่า 3 ปี) และมีคุณวุฒิการศึกษาไม่ต่ำกว่าปริญญาตรีหรือเทียบเท่าในสาขาวิชาบัญชีเท่านั้น ผู้ที่จบสาขาอื่น เช่น เศรษฐศาสตร์ วิศวกรรมศาสตร์ แพทยศาสตร์ พยาบาล หรือบริหารธุรกิจ จะไม่สามารถทำบัญชีตามกฎหมายได้ การฝ่าฝืนกฎหมายนี้มีบทลงโทษทางอาญา รวมถึงการจำคุกสำหรับผู้รับผิดชอบโดยตรงในการทำบัญชี

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| การบัญชีการเงิน (Financial Accounting) | การบัญชีที่จัดทำขึ้นตามหลักการบัญชีที่รับรองทั่วไปและมาตรฐานที่กำหนด เพื่อนำเสนอข้อมูลทางการเงินแก่บุคคลภายนอก |
| การบัญชีบริหาร (Managerial Accounting) | การบัญชีที่จัดทำขึ้นเพื่อวัตถุประสงค์ของผู้ใช้ข้อมูลภายในกิจการ เพื่อช่วยในการวางแผน ควบคุม และตัดสินใจ |
| หลักการบัญชีที่รับรองทั่วไป (Generally Accepted Accounting Principle: GAAP) | หลักเกณฑ์และแนวปฏิบัติที่เป็นที่ยอมรับโดยทั่วไปในการจัดทำและนำเสนอรายงานทางการเงิน |
| มาตรฐานการบัญชี (Accounting Standards) | ข้อกำหนดและแนวปฏิบัติที่ใช้ในการบันทึกบัญชีและการรายงานทางการเงิน |
| มาตรฐานการรายงานทางการเงิน (Financial Reporting Standards) | ข้อกำหนดที่ใช้ในการจัดทำและนำเสนอรายงานทางการเงินเพื่อให้ข้อมูลที่เป็นประโยชน์แก่ผู้ใช้งบการเงิน |
| สภาวิชาชีพบัญชีในพระบรมราชูปถัมภ์ (Federation of Accounting Professions under Royal Patronage) | องค์กรที่ทำหน้าที่กำกับดูแลและพัฒนาวิชาชีพบัญชีในประเทศไทย |
| จรรยาบรรณวิชาชีพบัญชี (Professional Accounting Ethics) | หลักความประพฤติและคุณธรรมที่นักบัญชีพึงยึดถือในการปฏิบัติงาน |
| พระราชบัญญัติวิชาชีพบัญชี พ.ศ. 2547 (Professional Accounting Act B.E. 2547) | กฎหมายที่กำหนดกรอบการดำเนินงาน คุณสมบัติ และบทบาทหน้าที่ของนักบัญชีในประเทศไทย |
| ผู้ทำบัญชี (Accountant/Bookkeeper) | บุคคลที่ทำหน้าที่จัดทำบัญชีตามกฎหมายและมาตรฐานที่กำหนด |
| โปร่งใส (Transparent) | การเปิดเผยข้อมูลอย่างชัดเจน ตรงไปตรงมา และตรวจสอบได้ |
| อิสระ (Independent) | การปราศจากอิทธิพลหรือการควบคุมจากบุคคลหรือหน่วยงานอื่น เพื่อให้สามารถปฏิบัติหน้าที่ได้อย่างเป็นกลาง |
| เที่ยงธรรม (Fair) | การปฏิบัติหน้าที่ด้วยความยุติธรรม ไม่ลำเอียง และให้ความเท่าเทียมกัน |
| ซื่อสัตย์ (Honest) | การประพฤติตนด้วยความจริงใจ ไม่คดโกง และยึดมั่นในความถูกต้อง |
| การรักษาความลับ (Confidentiality) | การไม่เปิดเผยข้อมูลที่เป็นความลับของกิจการหรือลูกค้าที่ได้รับจากการปฏิบัติหน้าที่ |
| คุณวุฒิ (Qualification) | ระดับการศึกษาหรือความสามารถที่ได้รับการรับรอง ซึ่งเป็นข้อกำหนดในการประกอบวิชาชีพ |

## ตัวอย่างหรือขั้นตอน
1.  **การบัญชีการเงิน:** หากกิจการมีการดำเนินงานที่เกี่ยวข้องกับการก่อสร้าง จะต้องลงบัญชีตามหลักเกณฑ์ที่กฎหมายกำหนดอย่างเคร่งครัด ไม่สามารถละเลยได้ เนื่องจากข้อมูลจะถูกนำเสนอต่อบุคคลภายนอกและหน่วยงานกำกับดูแล
2.  **การบัญชีบริหาร:** ตัวอย่างเช่น การคำนวณต้นทุนของน้ำดื่มที่ขายขวดละ 7 บาท โดยมีต้นทุนการผลิต 1 บาท และค่าโฆษณา 3 บาท การบัญชีบริหารจะช่วยวิเคราะห์โครงสร้างต้นทุนนี้ เพื่อหาแนวทางลดค่าใช้จ่าย เช่น การจ้างพรีเซนเตอร์ที่มีค่าตัวถูกลง เพื่อเพิ่มกำไรของกิจการ
3.  **จรรยาบรรณวิชาชีพ:** นักบัญชีมีหน้าที่รักษาความลับของข้อมูลกิจการ การนำข้อมูลไปเปิดเผยถือเป็นการผิดจรรยาบรรณ
4.  **บทลงโทษทางกฎหมาย:** หากนักบัญชีผู้รับผิดชอบโดยตรงในการเซ็นงบการเงินกระทำความผิด อาจต้องรับโทษถึงขั้นจำคุก หรือถูกตักเตือน พักใบอนุญาต หรือเพิกถอนใบอนุญาตจากสภาวิชาชีพบัญชี
5.  **คุณสมบัติของผู้ทำบัญชีตามพระราชบัญญัติวิชาชีพบัญชี พ.ศ. 2547:**
    *   มีภูมิลำเนาหรือถิ่นที่อยู่ในราชอาณาจักร
    *   มีความรู้ภาษาไทยเพียงพอที่จะทำหน้าที่เป็นผู้ทำบัญชี
    *   ไม่เคยต้องโทษจำคุกในความผิดตามกฎหมายบัญชี กฎหมายสอบบัญชี เว้นแต่พ้นโทษมาแล้วไม่น้อยกว่า 3 ปี
    *   มีคุณวุฒิการศึกษาไม่ต่ำกว่าปริญญาตรีหรือเทียบเท่าในสาขาวิชาบัญชีเท่านั้น ผู้ที่จบสาขาอื่น เช่น เศรษฐศาสตร์ วิศวกรรมศาสตร์ แพทยศาสตร์ พยาบาล หรือบริหารธุรกิจ ไม่สามารถทำบัญชีตามกฎหมายได้

## สรุปท้ายบท
วิชาชีพบัญชีแบ่งออกเป็นสองสาขาหลักคือ การบัญชีการเงินที่เน้นการรายงานต่อภายนอกตามมาตรฐานที่เข้มงวด และการบัญชีบริหารที่เน้นการสนับสนุนการตัดสินใจภายในองค์กรด้วยความยืดหยุ่น นักบัญชีต้องยึดมั่นในจรรยาบรรณวิชาชีพอย่างเคร่งครัด โดยเฉพาะอย่างยิ่งเรื่องความโปร่งใส ความเป็นอิสระ ความเที่ยงธรรม ความซื่อสัตย์ และการรักษาความลับ ซึ่งเป็นหัวใจสำคัญของวิชาชีพนี้ พระราชบัญญัติวิชาชีพบัญชี พ.ศ. 2547 เป็นกฎหมายสำคัญที่กำกับดูแลวิชาชีพนี้ กำหนดคุณสมบัติที่ชัดเจนสำหรับผู้ทำบัญชี โดยผู้ที่จะประกอบวิชาชีพนี้ได้ต้องจบการศึกษาด้านบัญชีโดยเฉพาะ และการฝ่าฝืนกฎหมายหรือจรรยาบรรณอาจนำไปสู่บทลงโทษที่รุนแรง รวมถึงการจำคุก แสดงให้เห็นว่าวิชาชีพบัญชีเป็นอาชีพที่มีความรับผิดชอบสูงและอยู่ภายใต้การควบคุมอย่างเข้มงวด

## คำถามทบทวน
1. การบัญชีการเงินและการบัญชีบริหารมีความแตกต่างกันอย่างไรในด้านวัตถุประสงค์หลักและกลุ่มผู้ใช้งานข้อมูล?
2. สภาวิชาชีพบัญชีมีบทบาทสำคัญอย่างไรในการกำกับดูแลและพัฒนาวิชาชีพบัญชีในประเทศไทย?
3. จรรยาบรรณวิชาชีพบัญชีที่สำคัญสำหรับนักบัญชีมีอะไรบ้าง และเหตุใดการรักษาความลับจึงเป็นสิ่งสำคัญอย่างยิ่งในวิชาชีพนี้?
4. ตามพระราชบัญญัติวิชาชีพบัญชี พ.ศ. 2547 ผู้ที่จะเป็นผู้ทำบัญชีได้ต้องมีคุณสมบัติอย่างไรบ้าง และทำไมผู้ที่จบสาขาอื่นจึงไม่สามารถทำบัญชีได้?
5. การไม่ปฏิบัติตามกฎหมายหรือจรรยาบรรณวิชาชีพที่กำหนดโดยสภาวิชาชีพบัญชีอาจส่งผลกระทบอย่างไรต่อนักบัญชีและองค์กร?
