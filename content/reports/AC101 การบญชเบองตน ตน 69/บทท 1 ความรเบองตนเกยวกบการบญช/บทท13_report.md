# บทที่1.3

## บทนำ
บทเรียนนี้จะอธิบายถึงความสำคัญและประโยชน์ของการบัญชีต่อกิจการและผู้มีส่วนได้ส่วนเสียต่างๆ รวมถึงบทบาทและโอกาสทางอาชีพของนักบัญชี โดยเน้นย้ำว่าข้อมูลทางการบัญชีเป็นสิ่งจำเป็นสำหรับการดำเนินธุรกิจ การตัดสินใจ และการปฏิบัติตามกฎหมาย นอกจากนี้ยังชี้ให้เห็นถึงความแตกต่างระหว่างผู้บันทึกบัญชีและนักบัญชี และแนะนำเส้นทางอาชีพที่หลากหลายสำหรับผู้ที่จบการศึกษาด้านบัญชี

## วัตถุประสงค์
เมื่อจบบทเรียนนี้ ผู้เรียนจะสามารถ: 1. อธิบายประโยชน์ของการบัญชีต่อการดำเนินงานของกิจการได้ 2. ระบุและจำแนกประเภทของผู้ใช้ข้อมูลทางการบัญชีทั้งภายในและภายนอกองค์กร พร้อมทั้งอธิบายวัตถุประสงค์ในการใช้ข้อมูลของแต่ละกลุ่มได้ 3. เข้าใจความแตกต่างระหว่างบทบาทของผู้บันทึกบัญชีและนักบัญชี 4. ทราบถึงโอกาสและเส้นทางอาชีพที่หลากหลายสำหรับผู้ที่จบการศึกษาด้านบัญชี

## แนวคิดสำคัญ
ประโยชน์ของการบัญชี: ช่วยในการควบคุมดูแลสินทรัพย์ไม่ให้สูญหาย, ช่วยให้ทราบผลการดำเนินงาน (กำไร/ขาดทุน) และฐานะทางการเงินของกิจการ, เป็นข้อมูลสำคัญในการตัดสินใจของผู้บริหาร (เช่น การทำงบประมาณ การกำหนดราคาขาย), ช่วยในการตรวจสอบความผิดปกติและป้องกันการทุจริต, และเป็นการปฏิบัติตามข้อกำหนดทางกฎหมายที่บังคับให้กิจการต้องจัดทำและส่งงบการเงิน ผู้ใช้ข้อมูลทางการบัญชี: แบ่งเป็นผู้ใช้ภายใน (เจ้าของ, ผู้บริหาร, พนักงาน) และผู้ใช้นอก (นักลงทุน, ลูกค้า, เจ้าหนี้, หน่วยราชการ) ซึ่งแต่ละกลุ่มมีวัตถุประสงค์ในการใช้ข้อมูลที่แตกต่างกัน บทบาทของนักบัญชี: นักบัญชีมีบทบาทที่กว้างกว่าผู้บันทึกบัญชี โดยนักบัญชีจะเกี่ยวข้องกับการวางระบบบัญชี การตรวจสอบบัญชี การจัดทำงบการเงิน และการวิเคราะห์ข้อมูลเพื่อการตัดสินใจ ในขณะที่ผู้บันทึกบัญชีมีหน้าที่หลักในการบันทึกรายการค้าตามเอกสาร อาชีพนักบัญชี: มีความหลากหลายและมั่นคง สามารถทำงานได้ทั้งในภาคเอกชน (Private Accounting), ภาคสาธารณะ (Public Accounting เช่น ผู้สอบบัญชี), ภาครัฐ (Governmental Accounting เช่น สรรพากร, สตง., ตำรวจ, ทหาร) และภาคการศึกษา (Education Accounting) รวมถึงสามารถเป็นผู้ประกอบการหรือนักวิเคราะห์ทางการเงินได้

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| สินทรัพย์ | ทรัพยากรที่กิจการเป็นเจ้าของและควบคุมได้ ซึ่งเกิดจากเหตุการณ์ในอดีตและคาดว่าจะให้ประโยชน์เชิงเศรษฐกิจในอนาคต |
| หนี้สิน | ภาระผูกพันในปัจจุบันของกิจการที่เกิดจากเหตุการณ์ในอดีต ซึ่งคาดว่าจะส่งผลให้กิจการต้องจ่ายชำระทรัพยากรที่มีประโยชน์เชิงเศรษฐกิจออกไป |
| ผลการดำเนินงาน | ผลลัพธ์จากการดำเนินงานของกิจการในช่วงเวลาหนึ่ง ซึ่งแสดงในรูปของกำไรหรือขาดทุน |
| กำไร | ส่วนที่เหลือจากการนำรายได้หักด้วยค่าใช้จ่ายทั้งหมดของกิจการ |
| ขาดทุน | ส่วนที่ค่าใช้จ่ายทั้งหมดของกิจการสูงกว่ารายได้ |
| ฐานะทางการเงิน | สถานะทางการเงินของกิจการ ณ วันใดวันหนึ่ง ซึ่งแสดงถึงสินทรัพย์ หนี้สิน และส่วนของเจ้าของ |
| งบประมาณ | แผนการใช้จ่ายเงินและทรัพยากรที่กำหนดไว้ล่วงหน้าสำหรับช่วงเวลาหนึ่ง |
| ผู้บริหาร | บุคคลที่รับผิดชอบในการวางแผน จัดการ และควบคุมการดำเนินงานขององค์กร |
| นักลงทุน | บุคคลหรือองค์กรที่นำเงินไปลงทุนในกิจการโดยคาดหวังผลตอบแทน |
| ลูกค้า | บุคคลหรือองค์กรที่ซื้อสินค้าหรือบริการจากกิจการ |
| เจ้าหนี้ | บุคคลหรือองค์กรที่ให้สินเชื่อหรือเงินกู้แก่กิจการ |
| หน่วยราชการ | องค์กรของรัฐบาลที่ทำหน้าที่กำกับดูแลและจัดเก็บภาษี |
| ผู้บันทึกบัญชี (Bookkeeper) | ผู้มีหน้าที่หลักในการรวบรวมเอกสารและบันทึกรายการค้าต่างๆ |
| นักบัญชี (Accountant) | ผู้มีหน้าที่ครอบคลุมทั้งการวางระบบบัญชี การตรวจสอบบัญชี การจัดทำงบการเงิน และการวิเคราะห์ข้อมูลเพื่อการตัดสินใจ |
| ผู้สอบบัญชีรับอนุญาต (CPA) | นักบัญชีที่ได้รับใบอนุญาตให้ทำการตรวจสอบและรับรองงบการเงินของกิจการ |

## ตัวอย่างหรือขั้นตอน
1.  **การควบคุมดูแลสินทรัพย์:** หากกิจการมีการทำบัญชี สินทรัพย์ทุกอย่างจะถูกบันทึกไว้ ทำให้สามารถตรวจสอบได้ว่าสินทรัพย์ใดหายไป เช่น คอมพิวเตอร์ที่ถูกบันทึกไว้ หรือสินค้าในสต็อกที่หายไป ระบบบัญชีจะช่วยให้ทราบได้ทันที 2.  **การทราบผลการดำเนินงาน:** การทำบัญชีช่วยให้กิจการรู้ว่ามีกำไรหรือขาดทุนเท่าไหร่ ซึ่งส่งผลต่อฐานะทางการเงินและความมั่นคงของกิจการ 3.  **การตัดสินใจของผู้บริหาร:** ข้อมูลบัญชีเป็นประโยชน์ในการทำงบประมาณสำหรับปีถัดไป การควบคุมการทำงานของพนักงาน การกำหนดราคาขายสินค้า (เช่น การกำหนดราคาน้ำดื่ม 7 บาทต่อขวด โดยพิจารณาจากต้นทุนและกำไรที่ต้องการ) 4.  **การตรวจสอบ:** ข้อมูลบัญชีช่วยในการตรวจสอบข้อผิดพลาดหรือความผิดปกติในการดำเนินงาน ทั้งการตรวจสอบภายในและภายนอก (เช่น การตรวจสอบบัญชีโดยผู้สอบบัญชี) 5.  **การปฏิบัติตามกฎหมาย:** กิจการต้องส่งงบการเงินให้หน่วยงานราชการ เช่น กรมพัฒนาธุรกิจการค้า หรือสำนักงานคณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์ (ก.ล.ต.) ตามข้อบังคับ 6.  **การพิจารณาของเจ้าหนี้:** ธนาคารจะเรียกดูงบการเงินเพื่อประกอบการพิจารณาให้สินเชื่อ หากกิจการมีสินทรัพย์ 100% แต่มีหนี้สิน 80% อาจไม่น่าปล่อยกู้ แต่ถ้ามีหนี้สินเพียง 10-20% ก็ยังน่าปล่อยกู้ 7.  **เส้นทางอาชีพ:** นักบัญชีสามารถทำงานเป็นพนักงานประจำในองค์กรธุรกิจ (Private Accounting) เช่น ผู้อำนวยการบัญชี, ผู้ตรวจสอบภายใน หรือเปิดสำนักงานรับทำบัญชี/ตรวจสอบบัญชีเอง (Public Accounting) หากสอบได้ CPA ก็สามารถเซ็นรับรองงบการเงินได้ นอกจากนี้ยังสามารถทำงานในหน่วยงานราชการ (Governmental Accounting) เช่น สรรพากร, สตง., ตำรวจ, ทหาร หรือเป็นอาจารย์/วิทยากรด้านบัญชี (Education Accounting) หรือเป็นผู้ประกอบการ/นักวิเคราะห์หลักทรัพย์ได้

## สรุปท้ายบท
การบัญชีมีความสำคัญอย่างยิ่งต่อการดำเนินธุรกิจและผู้มีส่วนได้ส่วนเสียทุกฝ่าย ทั้งในด้านการควบคุมสินทรัพย์ การประเมินผลการดำเนินงาน การตัดสินใจ การตรวจสอบ และการปฏิบัติตามกฎหมาย นักบัญชีมีบทบาทที่กว้างขวางและแตกต่างจากผู้บันทึกบัญชี โดยต้องมีความรู้ความสามารถในการวิเคราะห์และวางระบบ อาชีพนักบัญชีเป็นอาชีพที่มีความมั่นคงสูงและมีโอกาสเติบโตในหลากหลายสายงาน ทั้งในภาคเอกชน ภาครัฐ และภาคสาธารณะ เนื่องจากจำนวนธุรกิจที่มีมากกว่าจำนวนนักบัญชีที่จบใหม่ ทำให้ความต้องการนักบัญชีมีอยู่เสมอ แม้จะต้องใช้ความขยันในการเรียนรู้มากกว่าสาขาอื่นเล็กน้อย แต่ก็เป็นอาชีพที่รับประกันความมั่นคงและมีทางเลือกในการประกอบอาชีพที่หลากหลาย

## คำถามทบทวน
1. ประโยชน์หลักของการทำบัญชีต่อกิจการมีอะไรบ้าง จงอธิบายอย่างน้อย 3 ข้อพร้อมยกตัวอย่างประกอบ
2. ผู้ใช้ข้อมูลทางการบัญชีแบ่งออกเป็นกี่กลุ่มหลักๆ และแต่ละกลุ่ม (เช่น เจ้าของ, ลูกค้า, เจ้าหนี้, หน่วยราชการ) ใช้ข้อมูลทางการบัญชีเพื่อวัตถุประสงค์ใด?
3. จงอธิบายความแตกต่างระหว่างบทบาทและความรับผิดชอบของ 'ผู้บันทึกบัญชี' และ 'นักบัญชี' รวมถึงคุณสมบัติทางการศึกษาที่จำเป็นสำหรับแต่ละบทบาท
4. อาชีพของนักบัญชีสามารถแบ่งออกเป็นกี่ประเภทหลักๆ และจงยกตัวอย่างอาชีพในแต่ละประเภทมาอย่างน้อย 1 ตัวอย่าง
5. เหตุใดจึงกล่าวได้ว่าอาชีพนักบัญชีเป็นอาชีพที่มีความมั่นคงและไม่ตกงานในระยะยาว?
