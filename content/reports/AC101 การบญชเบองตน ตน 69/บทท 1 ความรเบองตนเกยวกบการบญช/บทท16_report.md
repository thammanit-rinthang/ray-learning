# บทที่1.6

## บทนำ
บทเรียนนี้กล่าวถึงกรอบแนวคิดสำหรับมาตรฐานการรายงานทางการเงิน ซึ่งเปรียบเสมือนรัฐธรรมนูญของวิชาชีพบัญชี เป็นหลักการพื้นฐานที่ใช้เป็นแนวทางในการจัดทำงบการเงินเมื่อไม่มีมาตรฐานบัญชีเฉพาะเจาะจงที่เกี่ยวข้องกำหนดไว้ โดยมีวัตถุประสงค์เพื่อให้ข้อมูลทางการเงินเป็นประโยชน์ต่อผู้ใช้งบการเงินในการตัดสินใจทางเศรษฐกิจ

## วัตถุประสงค์
วัตถุประสงค์หลักของการจัดทำงบการเงินคือการให้ข้อมูลที่เกี่ยวข้องกับฐานะการเงิน ผลการดำเนินงาน และการเปลี่ยนแปลงฐานะการเงินของกิจการ เพื่อประโยชน์ในการตัดสินใจของผู้ใช้งบการเงินทุกประเภท

## แนวคิดสำคัญ
1.  **เกณฑ์คงค้าง (Accrual Basis):** เป็นหลักการสำคัญในการบันทึกบัญชีที่เน้นการรับรู้รายได้เมื่อกิจการได้ให้บริการหรือส่งมอบสินค้าแล้ว และรับรู้ค่าใช้จ่ายเมื่อเกิดภาระผูกพันขึ้นแล้วในงวดบัญชีนั้น ๆ โดยไม่คำนึงถึงการรับหรือจ่ายเงินสดจริง การใช้เกณฑ์คงค้างช่วยให้การวัดผลการดำเนินงานของกิจการมีความถูกต้องและครบถ้วนในแต่ละงวด
2.  **การดำเนินงานอย่างต่อเนื่อง (Going Concern or Continuity):** เป็นข้อสมมติฐานในการจัดทำงบการเงินที่ถือว่ากิจการมีเจตนาที่จะดำเนินงานต่อไปในอนาคตอย่างต่อเนื่อง โดยไม่มีเจตนาหรือความจำเป็นที่จะเลิกกิจการหรือลดขนาดการดำเนินงานอย่างมีนัยสำคัญในระยะเวลาอันใกล้
3.  **ความสม่ำเสมอ (Consistency) และการเปรียบเทียบกันได้ (Comparability):** งบการเงินควรจัดทำขึ้นโดยใช้หลักการและนโยบายการบัญชีที่สม่ำเสมอในแต่ละงวด เพื่อให้ผู้ใช้งบการเงินสามารถเปรียบเทียบข้อมูลทางการเงินระหว่างงวดบัญชีของกิจการเดียวกัน และเปรียบเทียบกับกิจการอื่นได้ ทำให้ข้อมูลมีประโยชน์ในการวิเคราะห์และตัดสินใจ
4.  **ความทันเวลา (Timeliness):** งบการเงินต้องจัดทำและนำเสนอให้ทันเวลาตามที่กฎหมายหรือข้อกำหนดกำหนด เพื่อให้ข้อมูลยังคงมีความเกี่ยวข้องและเป็นประโยชน์ต่อการตัดสินใจของผู้ใช้งบการเงิน
5.  **ข้อจำกัดด้านต้นทุนต่อผลประโยชน์ (Cost-Benefit Constraint):** การจัดทำและนำเสนอข้อมูลทางการเงินควรคำนึงถึงความคุ้มค่า โดยประโยชน์ที่ได้รับจากข้อมูลนั้นควรมากกว่าต้นทุนที่ใช้ในการจัดทำและนำเสนอข้อมูลนั้น ๆ

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| กรอบแนวคิดสำหรับมาตรฐานการรายงานทางการเงิน | หลักการพื้นฐานที่ใช้เป็นแนวทางในการจัดทำงบการเงิน |
| รัฐธรรมนูญของวิชาชีพบัญชี | คำเปรียบเปรยถึงความสำคัญของกรอบแนวคิดฯ |
| งบฐานะการเงิน | งบที่แสดงสินทรัพย์ หนี้สิน และส่วนของเจ้าของ ณ วันใดวันหนึ่ง |
| งบผลการดำเนินงาน | งบที่แสดงรายได้ ค่าใช้จ่าย และผลกำไรหรือขาดทุนของกิจการในรอบระยะเวลาหนึ่ง |
| งบแสดงการเปลี่ยนแปลงส่วนของเจ้าของ | งบที่แสดงการเปลี่ยนแปลงในส่วนของเจ้าของในรอบระยะเวลาหนึ่ง |
| เกณฑ์คงค้าง (Accrual Basis) | หลักการบันทึกบัญชีที่รับรู้รายได้และค่าใช้จ่ายเมื่อเกิดขึ้น ไม่ใช่เมื่อรับหรือจ่ายเงินสด |
| เกณฑ์เงินสด (Cash Basis) | หลักการบันทึกบัญชีที่รับรู้รายได้และค่าใช้จ่ายเมื่อมีการรับหรือจ่ายเงินสดจริง |
| ค่าใช้จ่ายค้างจ่าย (Accrued Expenses) | ค่าใช้จ่ายที่เกิดขึ้นแล้วแต่ยังไม่ได้จ่ายเงิน |
| รายได้รับล่วงหน้า (Unearned Revenue) | เงินที่ได้รับมาแล้วแต่ยังไม่ได้ให้บริการหรือส่งมอบสินค้า |
| ค่าเสื่อมราคา (Depreciation) | การปันส่วนต้นทุนของสินทรัพย์ถาวรตลอดอายุการใช้งาน |
| การดำเนินงานอย่างต่อเนื่อง (Going Concern) | ข้อสมมติฐานว่ากิจการจะดำเนินงานต่อไปในอนาคต |
| ความสม่ำเสมอ (Consistency) | การใช้นโยบายการบัญชีเดียวกันอย่างต่อเนื่อง |
| การเปรียบเทียบกันได้ (Comparability) | คุณสมบัติของข้อมูลที่ช่วยให้ผู้ใช้งบการเงินเปรียบเทียบข้อมูลได้ |
| ความทันเวลา (Timeliness) | การนำเสนอข้อมูลทางการเงินให้ทันต่อความต้องการของผู้ใช้ |
| ข้อจำกัดด้านต้นทุนต่อผลประโยชน์ (Cost-Benefit Constraint) | การพิจารณาว่าประโยชน์ของข้อมูลคุ้มค่ากับต้นทุนการจัดทำหรือไม่ |

## ตัวอย่างหรือขั้นตอน
1.  **การบันทึกรายได้และค่าใช้จ่ายตามเกณฑ์คงค้าง:**
    *   **การขายสินค้าเป็นเงินเชื่อ:** เมื่อมีการส่งมอบสินค้าและลูกค้าเซ็นรับสินค้าแล้ว ถือว่าเกิดรายได้และภาระผูกพันทางกฎหมายแล้ว แม้จะยังไม่ได้รับเงินสด ก็สามารถบันทึกเป็นรายได้และลูกหนี้การค้าได้ทันที ไม่ต้องรอการเก็บเงิน
    *   **การปรับปรุงรายการ ณ สิ้นงวด:**
        *   **ค่าใช้จ่ายค้างจ่าย:** เช่น ค่าไฟฟ้า ค่าน้ำ ที่ใช้ไปแล้วในงวดปัจจุบัน แต่ยังไม่ได้รับใบแจ้งหนี้หรือยังไม่ได้ชำระเงิน จะต้องปรับปรุงบันทึกเป็นค่าใช้จ่ายของงวดนั้น ๆ เพื่อให้ค่าใช้จ่ายครบถ้วน
        *   **รายได้รับล่วงหน้า:** เช่น ได้รับเงินค่าเช่าล่วงหน้า แต่ยังไม่ได้ให้บริการเช่าครบตามระยะเวลาที่ได้รับเงินมา จะต้องปรับปรุงบันทึกเป็นรายได้รับล่วงหน้า เพื่อให้รายได้ที่แท้จริงของงวดนั้นถูกต้อง
        *   **ค่าเสื่อมราคา:** การใช้เครื่องจักรในการผลิตสินค้าในระหว่างงวด จะต้องมีการตัดค่าเสื่อมราคาของเครื่องจักรนั้นเป็นค่าใช้จ่ายในงวดนั้น ๆ เพื่อสะท้อนการใช้ประโยชน์จากสินทรัพย์
2.  **ความสม่ำเสมอของนโยบายการบัญชี:**
    *   **วิธีการคิดค่าเสื่อมราคา:** หากปีนี้เลือกใช้วิธีเส้นตรงในการคิดค่าเสื่อมราคา ปีถัดไปก็ควรใช้วิธีเส้นตรงต่อไปอย่างสม่ำเสมอ ไม่ควรเปลี่ยนไปใช้วิธีอื่น เช่น วิธีสองเท่าของยอดลดลง หรือวิธีผลรวมจำนวนปี เพียงเพื่อต้องการปรับตัวเลขกำไรให้มากหรือน้อยตามต้องการ เพราะจะทำให้งบการเงินไม่สามารถเปรียบเทียบกันได้และสร้างความสับสนให้ผู้ใช้งบการเงิน

## สรุปท้ายบท
วิชาชีพบัญชีมีความสำคัญในการจัดทำงบการเงิน ซึ่งเป็นเครื่องมือสำคัญในการแสดงผลการดำเนินงานและฐานะทางการเงินของทุกธุรกิจ โดยมีสภาวิชาชีพบัญชีเป็นหน่วยงานกำกับดูแล หลักการพื้นฐานในการจัดทำงบการเงินที่สำคัญประกอบด้วย การแสดงผลการดำเนินงาน ฐานะการเงิน และการเปลี่ยนแปลงฐานะการเงินภายใต้เกณฑ์คงค้าง การดำเนินงานอย่างต่อเนื่อง และการเปรียบเทียบกันได้ นอกจากนี้ยังต้องคำนึงถึงความทันเวลาและข้อจำกัดด้านต้นทุนต่อผลประโยชน์ในการนำเสนอข้อมูลทางการเงิน

## คำถามทบทวน
1. กรอบแนวคิดสำหรับมาตรฐานการรายงานทางการเงินมีความสำคัญอย่างไรต่อวิชาชีพบัญชี?
2. อธิบายความแตกต่างระหว่าง "เกณฑ์คงค้าง" และ "เกณฑ์เงินสด" พร้อมยกตัวอย่างประกอบ
3. เหตุใดการดำเนินงานอย่างต่อเนื่อง (Going Concern) จึงเป็นข้อสมมติฐานสำคัญในการจัดทำงบการเงิน?
4. การที่กิจการเปลี่ยนวิธีการคิดค่าเสื่อมราคาบ่อยครั้งจะส่งผลกระทบต่องบการเงินอย่างไร?
5. "ข้อจำกัดด้านต้นทุนต่อผลประโยชน์" มีความหมายและบทบาทอย่างไรในการจัดทำงบการเงิน?
