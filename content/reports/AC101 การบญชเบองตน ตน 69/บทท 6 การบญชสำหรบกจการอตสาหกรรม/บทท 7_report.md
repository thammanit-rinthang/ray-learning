# บทที่ 7

## บทนำ
บทที่ 7 นี้จะกล่าวถึง 'รายการปิดบัญชีของกิจการอุตสาหกรรม' ซึ่งมีความซับซ้อนและมีขั้นตอนที่เพิ่มขึ้นจากกิจการซื้อมาขายไป เนื่องจากกิจการอุตสาหกรรมมีกระบวนการผลิตสินค้า ทำให้ต้องมีการบันทึกบัญชีเกี่ยวกับวัตถุดิบ สินค้าระหว่างผลิต และสินค้าสำเร็จรูป การปิดบัญชีจึงต้องสะท้อนถึงต้นทุนการผลิตที่เกิดขึ้นในงวดนั้นๆ เพื่อให้ได้ 'ต้นทุนสินค้าที่ผลิตเสร็จ' ก่อนที่จะนำไปคำนวณกำไรขาดทุนต่อไป การปิดบัญชีจะเริ่มต้นหลังจากที่ได้มีการปรับปรุงรายการต่างๆ เรียบร้อยแล้ว เพื่อให้ตัวเลขในบัญชีมีความถูกต้องและเป็นปัจจุบัน

## วัตถุประสงค์
ผู้เรียนควรจะสามารถเข้าใจและอธิบายถึงความแตกต่างของขั้นตอนการปิดบัญชีในกิจการอุตสาหกรรมเมื่อเทียบกับกิจการซื้อมาขายไปได้ สามารถคำนวณและบันทึกรายการปิดบัญชีที่เกี่ยวข้องกับ 'ต้นทุนสินค้าที่ผลิตเสร็จ' ได้อย่างถูกต้อง และสามารถเลือกใช้วิธีการปิดบัญชีที่เหมาะสมกับกิจการอุตสาหกรรมได้ ไม่ว่าจะเป็นแบบผ่านต้นทุนขายหรือไม่ผ่านต้นทุนขาย เพื่อให้ได้ผลลัพธ์กำไรขาดทุนที่ถูกต้อง

## แนวคิดสำคัญ
แนวคิดสำคัญในการปิดบัญชีของกิจการอุตสาหกรรมคือการคำนวณ 'ต้นทุนสินค้าที่ผลิตเสร็จ' (Cost of Goods Manufactured - COGM) ซึ่งเป็นหัวใจสำคัญที่เพิ่มเข้ามา โดย COGM ประกอบด้วยองค์ประกอบหลัก 3 ส่วน ได้แก่ วัตถุดิบทางตรงใช้ไป (Direct Materials Used), ค่าแรงงานทางตรง (Direct Labor), และค่าใช้จ่ายการผลิต (Manufacturing Overhead) รวมถึงการพิจารณาสินค้าระหว่างผลิตต้นงวดและปลายงวด

การคำนวณวัตถุดิบทางตรงใช้ไป: วัตถุดิบทางตรงต้นงวด + ซื้อวัตถุดิบสุทธิ - วัตถุดิบทางตรงปลายงวด
ซื้อวัตถุดิบสุทธิ = ซื้อวัตถุดิบ + ค่าขนส่งเข้า - ส่งคืนและส่วนลด - ส่วนลดรับ

สูตรการคำนวณต้นทุนสินค้าที่ผลิตเสร็จ (COGM) คือ:
COGM = สินค้าระหว่างผลิตต้นงวด + วัตถุดิบทางตรงใช้ไป + ค่าแรงงานทางตรง + ค่าใช้จ่ายการผลิต - สินค้าระหว่างผลิตปลายงวด

นอกจากนี้ ยังมีวิธีการปิดบัญชีหลัก 2 แบบ ได้แก่:
1.  **การปิดบัญชีแบบผ่านต้นทุนขาย (Closing through Cost of Goods Sold):** วิธีนี้จะมีการคำนวณต้นทุนสินค้าที่ผลิตเสร็จก่อน แล้วจึงนำไปคำนวณต้นทุนขาย และปิดบัญชีรายได้ ค่าใช้จ่าย และเงินปันผล โดยมีขั้นตอนรวม 8 ขั้นตอน
2.  **การปิดบัญชีแบบไม่ผ่านต้นทุนขาย (Closing not through Cost of Goods Sold):** วิธีนี้จะปิดบัญชีต้นทุนสินค้าที่ผลิตเสร็จ สินค้าสำเร็จรูปต้นงวดและปลายงวด รวมถึงค่าใช้จ่ายอื่นๆ เข้าบัญชีกำไรขาดทุนโดยตรง โดยไม่ต้องแสดงต้นทุนขายแยกต่างหาก มีขั้นตอนรวม 6 ขั้นตอน

ไม่ว่าจะเลือกวิธีใด ผลลัพธ์ของกำไรขาดทุนสุทธิจะเท่ากัน แต่ขั้นตอนการบันทึกจะแตกต่างกัน

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| ปิดบัญชี | กระบวนการโอนยอดคงเหลือของบัญชีรายได้และค่าใช้จ่ายไปยังบัญชีกำไรขาดทุน และโอนกำไรขาดทุนสุทธิไปยังบัญชีกำไรสะสม เพื่อเตรียมบัญชีสำหรับงวดถัดไป |
| กิจการอุตสาหกรรม | ธุรกิจที่มีกระบวนการผลิตสินค้า โดยมีการใช้วัตถุดิบ แรงงาน และค่าใช้จ่ายการผลิต |
| ต้นทุนสินค้าที่ผลิตเสร็จ (COGM) | ต้นทุนรวมของสินค้าที่ผลิตเสร็จสมบูรณ์ในช่วงเวลาหนึ่ง ซึ่งพร้อมสำหรับการขายหรือโอนไปยังสินค้าสำเร็จรูป |
| วัตถุดิบทางตรง (DM) | วัสดุหลักที่ใช้ในการผลิตสินค้า และสามารถระบุต้นทุนได้โดยตรงกับผลิตภัณฑ์ |
| ค่าแรงงานทางตรง (DL) | ค่าจ้างที่จ่ายให้กับพนักงานที่เกี่ยวข้องโดยตรงกับการผลิตสินค้า |
| ค่าใช้จ่ายการผลิต (MO) | ค่าใช้จ่ายทั้งหมดที่เกี่ยวข้องกับการผลิตสินค้ายกเว้นวัตถุดิบทางตรงและค่าแรงงานทางตรง เช่น ค่าแรงงานทางอ้อม ค่าเสื่อมราคาโรงงาน |
| สินค้าระหว่างผลิต (WIP) | สินค้าที่อยู่ในกระบวนการผลิต แต่ยังไม่เสร็จสมบูรณ์ ณ วันสิ้นงวด |
| สินค้าสำเร็จรูป (FG) | สินค้าที่ผลิตเสร็จสมบูรณ์และพร้อมสำหรับการขาย |
| งบทดลอง | รายการสรุปยอดคงเหลือของบัญชีแยกประเภททั้งหมด ณ วันใดวันหนึ่ง เพื่อตรวจสอบความสมดุลของเดบิตและเครดิต |
| รายการปรับปรุง | รายการที่บันทึก ณ วันสิ้นงวดบัญชี เพื่อให้รายได้และค่าใช้จ่ายรับรู้ในงวดที่ถูกต้อง และเพื่อให้สินทรัพย์และหนี้สินแสดงมูลค่าที่แท้จริง |
| งบต้นทุนผลิต | รายงานที่แสดงรายละเอียดการคำนวณต้นทุนสินค้าที่ผลิตเสร็จในช่วงเวลาหนึ่ง |
| ต้นทุนขาย (COGS) | ต้นทุนของสินค้าที่ขายไปในช่วงเวลาหนึ่ง |
| กำไรขาดทุน | บัญชีชั่วคราวที่ใช้ในการรวบรวมรายได้และค่าใช้จ่ายทั้งหมด เพื่อคำนวณกำไรสุทธิหรือขาดทุนสุทธิของงวด |
| กำไรสะสม | ส่วนของกำไรที่กิจการเก็บสะสมไว้และยังไม่ได้จ่ายเป็นเงินปันผล |
| เงินปันผล | ส่วนแบ่งกำไรที่จ่ายให้กับผู้ถือหุ้น |

## ตัวอย่างหรือขั้นตอน
ก่อนการปิดบัญชี ต้องมีการปรับปรุงรายการต่างๆ ให้ถูกต้องก่อน เช่น ค่าเผื่อหนี้สงสัยจะสูญ ค่าเสื่อมราคาเครื่องจักร ค่าตัดจำหน่ายสิทธิบัตร ค่าวัสดุใช้ไป และค่าใช้จ่ายค้างจ่ายต่างๆ

**ตัวอย่างการคำนวณต้นทุนสินค้าที่ผลิตเสร็จ (COGM) จากข้อมูลที่ให้มา:**

**1. คำนวณวัตถุดิบทางตรงใช้ไป (Direct Materials Used):**
*   วัตถุดิบทางตรงต้นงวด: 40,000 บาท
*   ซื้อวัตถุดิบ: 543,960 บาท
*   ค่าขนส่งเข้า: 2,050 บาท
*   ส่งคืนและส่วนลด (ซื้อ): 4,400 บาท
*   ส่วนลดรับ: 1,500 บาท
*   วัตถุดิบทางตรงปลายงวด: 40,000 บาท

    ซื้อวัตถุดิบสุทธิ = 543,960 (ซื้อ) + 2,050 (ค่าขนส่งเข้า) - 4,400 (ส่งคืน) - 1,500 (ส่วนลดรับ) = 540,110 บาท
    วัตถุดิบทางตรงใช้ไป = 40,000 (ต้นงวด) + 540,110 (ซื้อสุทธิ) - 40,000 (ปลายงวด) = 540,110 บาท

**2. ค่าแรงงานทางตรง (Direct Labor):**
*   ค่าแรงงานทางตรง: 300,000 บาท

**3. ค่าใช้จ่ายการผลิต (Manufacturing Overhead - MO):**
*   ค่าแรงงานทางอ้อม: 115,000 บาท
*   ค่าเสื่อมราคา-เครื่องจักร: 22,500 บาท (จากการปรับปรุง)
*   ค่าตัดจำหน่าย-สิทธิบัตร: 20,000 บาท (จากการปรับปรุง)
*   ค่าใช้ไป-เครื่องมือ: 22,000 บาท (จากการปรับปรุง)
*   ค่าสาธารณูปโภค-โรงงาน: 53,250 บาท (จากการปรับปรุง)

    รวมค่าใช้จ่ายการผลิต = 115,000 + 22,500 + 20,000 + 22,000 + 53,250 = 232,750 บาท

**4. สินค้าระหว่างผลิต (Work-in-Process - WIP):**
*   สินค้าระหว่างผลิตต้นงวด: 30,500 บาท
*   สินค้าระหว่างผลิตปลายงวด: 47,800 บาท

**5. คำนวณต้นทุนสินค้าที่ผลิตเสร็จ (COGM):**
    COGM = 30,500 (WIP ต้นงวด) + 540,110 (DM ใช้ไป) + 300,000 (DL) + 232,750 (MO) - 47,800 (WIP ปลายงวด) = 1,055,560 บาท

**ขั้นตอนการปิดบัญชี (โดยสรุปตามแนวคิดในเสียง):**

**วิธีที่ 1: ปิดบัญชีแบบผ่านต้นทุนขาย (8 ขั้นตอน)**
1.  **ปิดบัญชีต้นทุนการผลิตที่มี ยอดเดบิต เข้าบัญชีต้นทุนสินค้าที่ผลิตเสร็จ:** โอนยอดคงเหลือของวัตถุดิบทางตรงต้นงวด, ซื้อวัตถุดิบ, ค่าขนส่งเข้า, ค่าแรงงานทางตรง, ค่าใช้จ่ายการผลิต (MO), และสินค้าระหว่างผลิตต้นงวด ไปยังบัญชี 'ต้นทุนสินค้าที่ผลิตเสร็จ' (โดยเดบิตบัญชีต้นทุนสินค้าที่ผลิตเสร็จ และเครดิตบัญชีเหล่านี้)
2.  **ปิดบัญชีต้นทุนการผลิตที่มี ยอดเครดิต และสินค้าคงเหลือปลายงวด เข้าบัญชีต้นทุนสินค้าที่ผลิตเสร็จ:** โอนยอดคงเหลือของส่งคืนและส่วนลด (ซื้อ), ส่วนลดรับ, วัตถุดิบทางตรงปลายงวด, และสินค้าระหว่างผลิตปลายงวด ไปยังบัญชี 'ต้นทุนสินค้าที่ผลิตเสร็จ' (โดยเดบิตบัญชีเหล่านี้ และเครดิตบัญชีต้นทุนสินค้าที่ผลิตเสร็จ) ยอดคงเหลือในบัญชี 'ต้นทุนสินค้าที่ผลิตเสร็จ' คือ COGM
3.  **ปิดบัญชีสินค้าสำเร็จรูปต้นงวดและต้นทุนสินค้าที่ผลิตเสร็จ เข้าบัญชีต้นทุนขาย:** โอนยอดคงเหลือของสินค้าสำเร็จรูปต้นงวด และ COGM ไปยังบัญชี 'ต้นทุนขาย'
4.  **ปิดบัญชีสินค้าสำเร็จรูปปลายงวด เข้าบัญชีต้นทุนขาย:** โอนยอดคงเหลือของสินค้าสำเร็จรูปปลายงวด เพื่อลดต้นทุนขาย
5.  **ปิดบัญชีรายได้ เข้าบัญชีกำไรขาดทุน:** โอนยอดขายสุทธิไปยังบัญชีกำไรขาดทุน
6.  **ปิดบัญชีค่าใช้จ่าย (รวมถึงต้นทุนขาย) เข้าบัญชีกำไรขาดทุน:** โอนยอดต้นทุนขาย, รับคืนและส่วนลด (ขาย), ส่วนลดจ่าย, และค่าใช้จ่ายดำเนินงานอื่นๆ ไปยังบัญชีกำไรขาดทุน
7.  **ปิดบัญชีกำไรขาดทุน เข้าบัญชีกำไรสะสม:** โอนกำไรสุทธิหรือขาดทุนสุทธิไปยังบัญชีกำไรสะสม
8.  **ปิดบัญชีเงินปันผล เข้าบัญชีกำไรสะสม:** โอนยอดเงินปันผลไปยังบัญชีกำไรสะสม

**วิธีที่ 2: ปิดบัญชีแบบไม่ผ่านต้นทุนขาย (6 ขั้นตอน)**
1.  **ปิดบัญชีต้นทุนการผลิตที่มี ยอดเดบิต เข้าบัญชีต้นทุนสินค้าที่ผลิตเสร็จ:** (เหมือนขั้นตอนที่ 1 ของวิธีผ่านต้นทุนขาย)
2.  **ปิดบัญชีต้นทุนการผลิตที่มี ยอดเครดิต และสินค้าคงเหลือปลายงวด เข้าบัญชีต้นทุนสินค้าที่ผลิตเสร็จ:** (เหมือนขั้นตอนที่ 2 ของวิธีผ่านต้นทุนขาย)
3.  **ปิดบัญชีรายได้ เข้าบัญชีกำไรขาดทุน:** โอนยอดขายสุทธิไปยังบัญชีกำไรขาดทุน
4.  **ปิดบัญชีสินค้าสำเร็จรูปต้นงวด, ต้นทุนสินค้าที่ผลิตเสร็จ, และค่าใช้จ่ายอื่นๆ เข้าบัญชีกำไรขาดทุน:** โอนยอดสินค้าสำเร็จรูปต้นงวด, COGM, รับคืนและส่วนลด (ขาย), ส่วนลดจ่าย, และค่าใช้จ่ายดำเนินงานอื่นๆ ไปยังบัญชีกำไรขาดทุน
5.  **ปิดบัญชีสินค้าสำเร็จรูปปลายงวด เข้าบัญชีกำไรขาดทุน:** โอนยอดสินค้าสำเร็จรูปปลายงวด เพื่อลดต้นทุนที่เข้าบัญชีกำไรขาดทุน
6.  **ปิดบัญชีกำไรขาดทุน เข้าบัญชีกำไรสะสม:** โอนกำไรสุทธิหรือขาดทุนสุทธิไปยังบัญชีกำไรสะสม
7.  **ปิดบัญชีเงินปันผล เข้าบัญชีกำไรสะสม:** โอนยอดเงินปันผลไปยังบัญชีกำไรสะสม

*หมายเหตุ: ตัวอย่างการบันทึกรายการปิดบัญชีในเอกสารประกอบอาจมีการรวมขั้นตอนหรือแสดงในรูปแบบที่แตกต่างจากคำอธิบายทั่วไป แต่ผลลัพธ์กำไรขาดทุนสุทธิที่ได้ (213,000 บาท) ยังคงสอดคล้องกันตามการคำนวณที่ถูกต้อง*

## สรุปท้ายบท
การปิดบัญชีสำหรับกิจการอุตสาหกรรมมีความซับซ้อนกว่ากิจการซื้อมาขายไป เนื่องจากต้องมีการคำนวณ 'ต้นทุนสินค้าที่ผลิตเสร็จ' ซึ่งเป็นขั้นตอนสำคัญที่เพิ่มเข้ามา การคำนวณ COGM ต้องพิจารณาทั้งวัตถุดิบทางตรง ค่าแรงงานทางตรง ค่าใช้จ่ายการผลิต และสินค้าระหว่างผลิตทั้งต้นงวดและปลายงวด การเลือกใช้วิธีการปิดบัญชีแบบผ่านต้นทุนขาย (8 ขั้นตอน) หรือไม่ผ่านต้นทุนขาย (6 ขั้นตอน) ขึ้นอยู่กับความต้องการในการแสดงข้อมูล แต่ผลลัพธ์กำไรขาดทุนสุทธิจะเท่ากัน การทำความเข้าใจขั้นตอนเหล่านี้เป็นสิ่งจำเป็นเพื่อให้มั่นใจว่างบการเงินสะท้อนผลการดำเนินงานที่แท้จริงของกิจการผลิต

## คำถามทบทวน
1. อะไรคือความแตกต่างหลักในการปิดบัญชีระหว่างกิจการซื้อมาขายไปและกิจการอุตสาหกรรม?
2. องค์ประกอบหลักในการคำนวณ 'ต้นทุนสินค้าที่ผลิตเสร็จ' มีอะไรบ้าง และแต่ละองค์ประกอบคำนวณอย่างไร?
3. อธิบายขั้นตอนการปิดบัญชีที่เกี่ยวข้องกับการคำนวณ 'ต้นทุนสินค้าที่ผลิตเสร็จ' โดยสรุป
4. มีวิธีการปิดบัญชีสำหรับกิจการอุตสาหกรรมกี่วิธี และแต่ละวิธีแตกต่างกันอย่างไรในแง่ของขั้นตอน?
5. เหตุใดจึงต้องมีการปรับปรุงรายการก่อนการปิดบัญชีในกิจการอุตสาหกรรม และรายการปรับปรุงใดบ้างที่เกี่ยวข้องกับต้นทุนการผลิต?
