# บทที่ 3

## บทนำ
บทเรียนนี้มุ่งเน้นการคำนวณต้นทุนในกิจการอุตสาหกรรม ซึ่งมีความซับซ้อนกว่ากิจการซื้อมาขายไป เนื่องจากต้องมีการผลิตสินค้าเอง โดยจะอธิบายถึง 5 ขั้นตอนสำคัญในการคำนวณต้นทุน ได้แก่ การคำนวณซื้อวัตถุดิบสุทธิ, วัตถุดิบทางตรงใช้ไป, ต้นทุนการผลิต, ต้นทุนสินค้าที่ผลิตเสร็จ และต้นทุนขาย พร้อมทั้งแสดงให้เห็นว่าการคำนวณเหล่านี้เป็นพื้นฐานในการจัดทำงบต้นทุนสินค้าที่ผลิต โดยใช้ตัวอย่างจากโจทย์ 6-2 เป็นกรณีศึกษา

## วัตถุประสงค์
เมื่อจบบทเรียนนี้ ผู้เรียนจะสามารถ: 1. เข้าใจความแตกต่างของการคำนวณต้นทุนระหว่างกิจการอุตสาหกรรมและกิจการซื้อมาขายไป 2. คำนวณยอดซื้อวัตถุดิบสุทธิได้อย่างถูกต้อง 3. คำนวณวัตถุดิบทางตรงที่ใช้ไปในการผลิต 4. ระบุและคำนวณองค์ประกอบของต้นทุนการผลิต (DM, DL, MO) 5. คำนวณต้นทุนสินค้าที่ผลิตเสร็จ 6. คำนวณต้นทุนขายของกิจการอุตสาหกรรม 7. เข้าใจโครงสร้างและจัดทำงบต้นทุนสินค้าที่ผลิตได้

## แนวคิดสำคัญ
บทเรียนนี้ครอบคลุมแนวคิดหลักเกี่ยวกับการบัญชีต้นทุนในกิจการอุตสาหกรรม โดยเน้นที่การคำนวณต้นทุนในแต่ละขั้นตอนของการผลิต ซึ่งประกอบด้วยการคำนวณซื้อวัตถุดิบสุทธิ, วัตถุดิบทางตรงใช้ไป, ต้นทุนการผลิต (ซึ่งรวมถึงวัตถุดิบทางตรง ค่าแรงงานทางตรง และค่าใช้จ่ายการผลิต), ต้นทุนสินค้าที่ผลิตเสร็จ และต้นทุนขาย นอกจากนี้ยังได้อธิบายถึงการจัดทำงบต้นทุนสินค้าที่ผลิต ซึ่งเป็นงบการเงินสำคัญที่แสดงรายละเอียดต้นทุนการผลิตทั้งหมดของกิจการ

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| ซื้อวัตถุดิบสุทธิ | ยอดรวมของวัตถุดิบที่ซื้อมาสุทธิหลังจากหักส่งคืนและส่วนลด รวมถึงส่วนลดรับ และบวกค่าขนส่งเข้า |
| วัตถุดิบทางตรงใช้ไป | มูลค่าของวัตถุดิบทางตรงที่ถูกนำไปใช้ในกระบวนการผลิตในช่วงเวลาหนึ่ง คำนวณจากวัตถุดิบต้นงวดบวกซื้อวัตถุดิบสุทธิหักวัตถุดิบปลายงวด |
| ต้นทุนการผลิต | ต้นทุนรวมทั้งหมดที่เกิดขึ้นในการผลิตสินค้าในช่วงเวลาหนึ่ง ประกอบด้วยวัตถุดิบทางตรงใช้ไป ค่าแรงงานทางตรง และค่าใช้จ่ายการผลิต |
| ต้นทุนสินค้าที่ผลิตเสร็จ | ต้นทุนรวมของสินค้าที่ผลิตเสร็จสมบูรณ์และพร้อมสำหรับการขายในช่วงเวลาหนึ่ง คำนวณจากสินค้าระหว่างผลิตต้นงวดบวกต้นทุนการผลิตหักสินค้าระหว่างผลิตปลายงวด |
| ต้นทุนขาย | ต้นทุนของสินค้าสำเร็จรูปที่ขายไปในช่วงเวลาหนึ่ง คำนวณจากสินค้าสำเร็จรูปต้นงวดบวกต้นทุนสินค้าที่ผลิตเสร็จหักสินค้าสำเร็จรูปปลายงวด |
| วัตถุดิบทางตรง | วัสดุหลักที่ใช้ในการผลิตสินค้าและสามารถระบุต้นทุนได้อย่างชัดเจนกับผลิตภัณฑ์ |
| สินค้าคงเหลือระหว่างผลิต | สินค้าที่อยู่ในกระบวนการผลิตแต่ยังไม่เสร็จสมบูรณ์ ณ วันสิ้นงวด |
| สินค้าสำเร็จรูป | สินค้าที่ผลิตเสร็จสมบูรณ์และพร้อมสำหรับการขาย |
| ค่าแรงงานทางตรง | ค่าแรงที่จ่ายให้กับพนักงานที่เกี่ยวข้องโดยตรงกับการผลิตสินค้า |
| ค่าใช้จ่ายการผลิต | ต้นทุนการผลิตอื่น ๆ นอกเหนือจากวัตถุดิบทางตรงและค่าแรงงานทางตรง เช่น ค่าแรงงานทางอ้อม วัสดุโรงงานใช้ไป ค่าเสื่อมราคาเครื่องจักร |
| ค่าแรงงานทางอ้อม | ค่าแรงที่จ่ายให้กับพนักงานที่ไม่เกี่ยวข้องโดยตรงกับการผลิตสินค้า แต่สนับสนุนกระบวนการผลิต เช่น หัวหน้างานโรงงาน |
| วัสดุโรงงานใช้ไป | วัสดุสิ้นเปลืองที่ใช้ในโรงงานแต่ไม่สามารถระบุต้นทุนได้อย่างชัดเจนกับผลิตภัณฑ์แต่ละหน่วย |
| ค่าขนส่งเข้า | ค่าใช้จ่ายในการขนส่งวัตถุดิบที่ซื้อเข้ามายังโรงงาน |
| ส่งคืนและส่วนลด | มูลค่าของวัตถุดิบที่ส่งคืนผู้ขายหรือส่วนลดที่ได้รับจากการซื้อ |
| ส่วนลดรับ | ส่วนลดที่ได้รับจากการชำระหนี้ค่าซื้อวัตถุดิบภายในเงื่อนไขที่กำหนด |

## ตัวอย่างหรือขั้นตอน
ตัวอย่างการคำนวณต้นทุนในกิจการอุตสาหกรรม (จากตัวอย่าง 6-2):

**ข้อมูลสินค้าคงเหลือ:**
*   วัตถุดิบทางตรง: ต้นงวด 50,000 บาท, ปลายงวด 33,000 บาท
*   สินค้าระหว่างผลิต: ต้นงวด 24,000 บาท, ปลายงวด 37,500 บาท
*   สินค้าสำเร็จรูป: ต้นงวด 45,000 บาท, ปลายงวด 35,700 บาท

**ข้อมูลการดำเนินงาน:**
*   ซื้อวัตถุดิบ: 363,000 บาท
*   ค่าขนส่งเข้า: 1,800 บาท
*   ส่งคืนและส่วนลด: 1,000 บาท
*   ส่วนลดรับ: 1,500 บาท
*   ค่าแรงงานทางตรง: 200,000 บาท
*   วัสดุโรงงานใช้ไป (วัตถุดิบทางอ้อม): 24,000 บาท
*   ค่าแรงงานทางอ้อม: 55,000 บาท
*   ค่าเครื่องมือ: 32,000 บาท
*   ค่าเสื่อมราคาเครื่องจักร: 18,000 บาท
*   เงินเดือนผู้ควบคุมโรงงาน: 35,000 บาท

**ขั้นตอนการคำนวณ:**

1.  **คำนวณซื้อวัตถุดิบสุทธิ:**
    *   ซื้อวัตถุดิบ + ค่าขนส่งเข้า - ส่งคืนและส่วนลด - ส่วนลดรับ
    *   363,000 + 1,800 - 1,000 - 1,500 = 362,300 บาท

2.  **คำนวณวัตถุดิบทางตรงใช้ไป:**
    *   วัตถุดิบต้นงวด + ซื้อวัตถุดิบสุทธิ - วัตถุดิบปลายงวด
    *   50,000 + 362,300 - 33,000 = 379,300 บาท

3.  **คำนวณต้นทุนการผลิต (Total Manufacturing Costs):**
    *   วัตถุดิบทางตรงใช้ไป + ค่าแรงงานทางตรง + ค่าใช้จ่ายการผลิต
    *   **ค่าใช้จ่ายการผลิต (Manufacturing Overhead - MO) ประกอบด้วย:**
        *   วัสดุโรงงานใช้ไป (วัตถุดิบทางอ้อม): 24,000 บาท
        *   ค่าแรงงานทางอ้อม: 55,000 บาท
        *   ค่าเครื่องมือ: 32,000 บาท
        *   ค่าเสื่อมราคาเครื่องจักร: 18,000 บาท
        *   เงินเดือนผู้ควบคุมโรงงาน: 35,000 บาท
        *   รวมค่าใช้จ่ายการผลิต = 24,000 + 55,000 + 32,000 + 18,000 + 35,000 = 164,000 บาท
    *   **ต้นทุนการผลิตรวม:** 379,300 (DM) + 200,000 (DL) + 164,000 (MO) = 743,300 บาท

4.  **คำนวณต้นทุนสินค้าที่ผลิตเสร็จ (Cost of Goods Manufactured):**
    *   สินค้าระหว่างผลิตต้นงวด + ต้นทุนการผลิต - สินค้าระหว่างผลิตปลายงวด
    *   24,000 + 743,300 - 37,500 = 729,800 บาท

5.  **คำนวณต้นทุนขาย (Cost of Goods Sold):**
    *   สินค้าสำเร็จรูปต้นงวด + ต้นทุนสินค้าที่ผลิตเสร็จ - สินค้าสำเร็จรูปปลายงวด
    *   45,000 + 729,800 - 35,700 = 739,100 บาท

**งบต้นทุนสินค้าที่ผลิต (Statement of Cost of Goods Manufactured):**
การคำนวณทั้ง 5 ขั้นตอนข้างต้นสามารถนำมาจัดทำเป็นงบต้นทุนสินค้าที่ผลิตได้ ดังนี้:
*   วัตถุดิบต้นงวด: 50,000 บาท
*   บวก ซื้อวัตถุดิบสุทธิ: 362,300 บาท
*   วัตถุดิบที่มีเพื่อใช้ทั้งสิ้น: 412,300 บาท
*   หัก วัตถุดิบปลายงวด: 33,000 บาท
*   วัตถุดิบทางตรงใช้ไป: 379,300 บาท
*   บวก ค่าแรงงานทางตรง: 200,000 บาท
*   บวก ค่าใช้จ่ายการผลิต: 164,000 บาท
*   ต้นทุนการผลิต: 743,300 บาท
*   บวก สินค้าระหว่างผลิตต้นงวด: 24,000 บาท
*   ต้นทุนที่ต้องผลิตทั้งสิ้น: 767,300 บาท
*   หัก สินค้าระหว่างผลิตปลายงวด: 37,500 บาท
*   ต้นทุนสินค้าที่ผลิตเสร็จ: 729,800 บาท

## สรุปท้ายบท
กิจการอุตสาหกรรมมีความจำเป็นต้องคำนวณต้นทุนการผลิตด้วยตนเอง ซึ่งแตกต่างจากกิจการซื้อมาขายไปที่เพียงแค่ซื้อมาขายไป การคำนวณต้นทุนในกิจการอุตสาหกรรมเป็นกระบวนการที่ต้องทำอย่างเป็นขั้นตอน เริ่มตั้งแต่การคำนวณซื้อวัตถุดิบสุทธิ, วัตถุดิบทางตรงใช้ไป, ต้นทุนการผลิต (DM, DL, MO), ต้นทุนสินค้าที่ผลิตเสร็จ และต้นทุนขาย โดยผลลัพธ์จากการคำนวณเหล่านี้จะนำไปจัดทำเป็น 'งบต้นทุนสินค้าที่ผลิต' ซึ่งเป็นงบการเงินสำคัญที่สะท้อนถึงต้นทุนที่เกิดขึ้นในกระบวนการผลิตทั้งหมด

## คำถามทบทวน
1. กิจการอุตสาหกรรมแตกต่างจากกิจการซื้อมาขายไปในการคำนวณต้นทุนอย่างไร?
2. จงอธิบายองค์ประกอบของการคำนวณ 'ซื้อวัตถุดิบสุทธิ' พร้อมยกตัวอย่างตัวเลขจากบทเรียน
3. 'ต้นทุนการผลิต' ประกอบด้วยต้นทุนหลักกี่ประเภท อะไรบ้าง และแต่ละประเภทมีองค์ประกอบย่อยอะไรบ้าง?
4. งบต้นทุนสินค้าที่ผลิต (Statement of Cost of Goods Manufactured) มีโครงสร้างหลักอย่างไร?
5. จากข้อมูลในบทเรียน จงคำนวณ 'ต้นทุนขาย' ของกิจการอุตสาหกรรมนี้
