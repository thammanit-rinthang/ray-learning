# บทที่ 4

## บทนำ
บทที่ 4 นี้จะอธิบายถึงการจัดทำงบต้นทุนสินค้าที่ผลิต ซึ่งเป็นงบการเงินสำคัญสำหรับกิจการอุตสาหกรรมที่ผลิตสินค้าเพื่อจำหน่ายเอง โดยจะเน้นการคำนวณต้นทุนการผลิตสำหรับงวด 1 ปี สิ้นสุดวันที่ 31 ธันวาคม X8 ของบริษัท เอ แอนด์ วี จำกัด ซึ่งเป็นผู้ผลิตและจำหน่ายสินค้า การเรียนรู้ในบทนี้จะช่วยให้เข้าใจถึงการจำแนกประเภทต้นทุนต่างๆ ที่เกิดขึ้นในกระบวนการผลิต และการจัดทำรายงานต้นทุนอย่างเป็นระบบ เพื่อให้สามารถคำนวณต้นทุนสินค้าที่ผลิตเสร็จในแต่ละงวดได้อย่างถูกต้องและแม่นยำ ซึ่งแตกต่างจากกิจการซื้อมาขายไปที่ไม่มีงบประเภทนี้

## วัตถุประสงค์
1. เพื่อให้ผู้เรียนสามารถจัดทำงบต้นทุนสินค้าที่ผลิตได้อย่างถูกต้องและครบถ้วนตามหลักการบัญชีต้นทุน 2. เพื่อให้ผู้เรียนสามารถจำแนกประเภทของต้นทุนการผลิตออกจากค่าใช้จ่ายในการดำเนินงานอื่นๆ ได้อย่างชัดเจน 3. เพื่อให้ผู้เรียนเข้าใจและสามารถคำนวณวัตถุดิบใช้ไป ค่าแรงงานทางตรง และค่าใช้จ่ายการผลิตได้อย่างละเอียด 4. เพื่อให้ผู้เรียนสามารถคำนวณต้นทุนการผลิตรวมและต้นทุนสินค้าที่ผลิตเสร็จสำหรับงวดบัญชีที่กำหนดได้

## แนวคิดสำคัญ
งบต้นทุนสินค้าที่ผลิต (Cost of Goods Manufactured Statement) เป็นงบที่แสดงต้นทุนทั้งหมดที่เกิดขึ้นในการผลิตสินค้าที่สำเร็จรูปพร้อมขายในระหว่างงวดบัญชี ประกอบด้วย 3 องค์ประกอบหลัก ได้แก่ วัตถุดิบทางตรง (Direct Materials - DM) ค่าแรงงานทางตรง (Direct Labor - DL) และค่าใช้จ่ายการผลิต (Manufacturing Overhead - MO) การคำนวณจะเริ่มต้นจากการหามูลค่าวัตถุดิบที่ใช้ไป โดยนำวัตถุดิบต้นงวดมารวมกับซื้อวัตถุดิบสุทธิ แล้วหักด้วยวัตถุดิบปลายงวด จากนั้นจึงแยกส่วนที่เป็นวัตถุดิบทางอ้อม (วัสดุโรงงานใช้ไป) ออกไปเป็นค่าใช้จ่ายการผลิต เพื่อให้ได้วัตถุดิบทางตรงที่ใช้ไป เมื่อได้ DM, DL และ MO แล้ว จะนำมารวมกันเป็นต้นทุนการผลิตรวม (Total Manufacturing Costs) และสุดท้ายจะนำต้นทุนการผลิตรวมไปปรับปรุงด้วยสินค้าคงเหลือระหว่างผลิตต้นงวดและปลายงวด เพื่อให้ได้ต้นทุนสินค้าที่ผลิตเสร็จ (Cost of Goods Manufactured) ซึ่งเป็นต้นทุนของสินค้าที่ผลิตเสร็จสมบูรณ์พร้อมจำหน่ายในงวดนั้นๆ สิ่งสำคัญคือการแยกค่าใช้จ่ายที่เกี่ยวข้องกับการผลิตในโรงงานออกจากค่าใช้จ่ายสำนักงาน ค่าใช้จ่ายในการขาย และค่าใช้จ่ายในการบริหาร ซึ่งจะไปปรากฏในงบกำไรขาดทุนแทน

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| งบต้นทุนสินค้าที่ผลิต | งบการเงินที่แสดงต้นทุนทั้งหมดที่เกิดขึ้นในการผลิตสินค้าที่สำเร็จรูปพร้อมขายในระหว่างงวดบัญชี |
| วัตถุดิบทางตรง (DM) | วัสดุหลักที่ใช้ในการผลิตสินค้าและสามารถระบุต้นทุนได้โดยตรงกับผลิตภัณฑ์ |
| ค่าแรงงานทางตรง (DL) | ค่าจ้างแรงงานที่เกี่ยวข้องโดยตรงกับการผลิตสินค้า |
| ค่าใช้จ่ายการผลิต (MO) | ต้นทุนการผลิตทั้งหมดที่ไม่ใช่วัตถุดิบทางตรงและค่าแรงงานทางตรง รวมถึงวัตถุดิบทางอ้อม ค่าแรงงานทางอ้อม และค่าใช้จ่ายอื่นๆ ในโรงงาน |
| วัตถุดิบใช้ไป | มูลค่าของวัตถุดิบที่ถูกนำไปใช้ในกระบวนการผลิตในระหว่างงวดบัญชี |
| ซื้อวัตถุดิบสุทธิ | ยอดรวมของการซื้อวัตถุดิบหลังจากหักส่วนลดรับและส่งคืนวัตถุดิบแล้ว |
| วัตถุดิบที่มีเพื่อใช้ทั้งสิ้น | มูลค่าของวัตถุดิบต้นงวดรวมกับซื้อวัตถุดิบสุทธิ |
| วัสดุโรงงาน | วัสดุที่ใช้ในโรงงานแต่ไม่สามารถระบุได้โดยตรงกับผลิตภัณฑ์สำเร็จรูป ถือเป็นวัตถุดิบทางอ้อมและเป็นส่วนหนึ่งของค่าใช้จ่ายการผลิต |
| ค่าแรงงานทางอ้อม | ค่าจ้างแรงงานที่ไม่เกี่ยวข้องโดยตรงกับการผลิตสินค้า เช่น ผู้ควบคุมงาน หรือพนักงานซ่อมบำรุงในโรงงาน ถือเป็นส่วนหนึ่งของค่าใช้จ่ายการผลิต |
| เครื่องมือใช้ไป | มูลค่าของเครื่องมือที่ใช้ไปในกระบวนการผลิต ถือเป็นส่วนหนึ่งของค่าใช้จ่ายการผลิต |
| ค่าตัดจำหน่ายสิทธิบัตร | ค่าใช้จ่ายที่เกิดจากการทยอยรับรู้ต้นทุนของสิทธิบัตรที่นำมาใช้ในการผลิต ถือเป็นส่วนหนึ่งของค่าใช้จ่ายการผลิต |
| ต้นทุนการผลิตรวม | ผลรวมของวัตถุดิบทางตรงใช้ไป ค่าแรงงานทางตรง และค่าใช้จ่ายการผลิต |
| สินค้าระหว่างผลิต (WIP) | สินค้าที่อยู่ระหว่างกระบวนการผลิต ยังไม่สำเร็จรูป |
| ต้นทุนสินค้าที่ผลิตเสร็จ (COGM) | ต้นทุนของสินค้าที่ผลิตเสร็จสมบูรณ์พร้อมจำหน่ายในระหว่างงวดบัญชี |
| ค่าขนส่งเข้า | ค่าใช้จ่ายในการขนส่งวัตถุดิบที่ซื้อเข้ามายังโรงงาน ถือเป็นส่วนหนึ่งของต้นทุนวัตถุดิบ |

## ตัวอย่างหรือขั้นตอน
การจัดทำงบต้นทุนสินค้าที่ผลิตสำหรับบริษัท เอ แอนด์ วี จำกัด สำหรับงวด 1 ปี สิ้นสุดวันที่ 31 ธันวาคม 25X8 มีขั้นตอนและรายละเอียดการคำนวณดังนี้:

**บริษัท เอ แอนด์ วี จำกัด**
**งบต้นทุนสินค้าที่ผลิต**
**สำหรับงวด 1 ปี สิ้นสุดวันที่ 31 ธันวาคม 25X8**
**หน่วย : บาท**

**1. วัตถุดิบใช้ไป**
   *   วัตถุดิบต้นงวด (1 ม.ค. X8): 78,500
   *   วัสดุโรงงานต้นงวด (1 ม.ค. X8): 9,400
   *   **รวมวัตถุดิบต้นงวด:** 78,500 + 9,400 = **87,900**
   *   ซื้อวัตถุดิบ: 1,425,980
   *   บวก ค่าขนส่งเข้า: 4,150
   *   **ซื้อวัตถุดิบทั้งสิ้น:** 1,425,980 + 4,150 = **1,430,130**
   *   หัก ส่งคืนและส่วนลด: 1,340
   *   หัก ส่วนลดรับ: 4,130
   *   **รวมหัก:** 1,340 + 4,130 = **5,470**
   *   **ซื้อวัตถุดิบสุทธิ:** 1,430,130 - 5,470 = **1,424,660**
   *   **วัตถุดิบที่มีเพื่อใช้ทั้งสิ้น:** 87,900 (วัตถุดิบต้นงวด) + 1,424,660 (ซื้อวัตถุดิบสุทธิ) = **1,512,560**
   *   หัก วัตถุดิบปลายงวด (31 ธ.ค. X8): 90,450
   *   หัก วัสดุโรงงานปลายงวด (31 ธ.ค. X8): 0 (หมด)
   *   **รวมวัตถุดิบปลายงวด:** 90,450 + 0 = **90,450**
   *   **วัตถุดิบใช้ไป (รวม):** 1,512,560 - 90,450 = **1,422,110**
   *   หัก วัสดุโรงงานใช้ไป (MO1): 15,400
   *   **วัตถุดิบทางตรงใช้ไป (DM):** 1,422,110 - 15,400 = **1,406,710**

**2. ค่าแรงงานทางตรง (DL)**
   *   ค่าแรงงานทางตรง: **308,440**

**3. ค่าใช้จ่ายการผลิต (MO)**
   *   วัสดุโรงงานใช้ไป (MO1): 15,400
   *   ค่าแรงงานทางอ้อม (MO2): 87,530
   *   เครื่องมือใช้ไป (MO3): 9,750
   *   ค่าตัดจำหน่ายสิทธิบัตร (MO4): 5,000
   *   ค่าเบี้ยประกันภัยโรงงาน (MO5): 5,000
   *   ค่าเสื่อมราคาอาคารโรงงาน (MO5): 20,000
   *   ค่าเสื่อมราคาเครื่องจักร (MO5): 15,000
   *   ค่าไฟฟ้าโรงงาน (MO5): 58,370
   *   **รวมค่าใช้จ่ายการผลิต (MO):** 15,400 + 87,530 + 9,750 + 5,000 + 5,000 + 20,000 + 15,000 + 58,370 = **216,050**

**4. ต้นทุนการผลิต (Total Manufacturing Costs)**
   *   DM + DL + MO = 1,406,710 + 308,440 + 216,050 = **1,931,200**

**5. ต้นทุนสินค้าที่ผลิตเสร็จ (Cost of Goods Manufactured - COGM)**
   *   ต้นทุนการผลิต: 1,931,200
   *   บวก สินค้าระหว่างผลิตต้นงวด (1 ม.ค. X8): 88,400
   *   **ต้นทุนสินค้าที่ต้องผลิตทั้งสิ้น:** 1,931,200 + 88,400 = **2,019,600**
   *   หัก สินค้าระหว่างผลิตปลายงวด (31 ธ.ค. X8): 97,800 (ตามที่ผู้สอนแก้ไขในเสียงและข้อมูลในภาพ)
   *   **ต้นทุนสินค้าที่ผลิตเสร็จ:** 2,019,600 - 97,800 = **1,921,800**

## สรุปท้ายบท
งบต้นทุนสินค้าที่ผลิตเป็นเครื่องมือสำคัญในการบริหารจัดการต้นทุนของกิจการอุตสาหกรรม ช่วยให้ผู้บริหารเข้าใจโครงสร้างต้นทุนการผลิตและสามารถตัดสินใจได้อย่างมีประสิทธิภาพ การจัดทำงบนี้ต้องอาศัยความเข้าใจในการจำแนกต้นทุนอย่างละเอียด โดยเฉพาะการแยกวัตถุดิบทางตรง ค่าแรงงานทางตรง และค่าใช้จ่ายการผลิตออกจากกันอย่างชัดเจน รวมถึงการพิจารณาสินค้าคงเหลือต้นงวดและปลายงวดของวัตถุดิบและงานระหว่างผลิต การคำนวณที่ถูกต้องจะนำไปสู่การกำหนดราคาขายที่เหมาะสมและการประเมินผลกำไรของกิจการได้อย่างแม่นยำ

## คำถามทบทวน
1. งบต้นทุนสินค้าที่ผลิตมีความสำคัญอย่างไรต่อกิจการอุตสาหกรรม และแตกต่างจากงบการเงินของกิจการซื้อมาขายไปอย่างไร?
2. องค์ประกอบหลัก 3 ประการของต้นทุนการผลิตมีอะไรบ้าง จงอธิบายความหมายและยกตัวอย่างประกอบ?
3. จงอธิบายขั้นตอนการคำนวณ 'วัตถุดิบใช้ไป' โดยละเอียด พร้อมระบุรายการที่เกี่ยวข้องในการคำนวณ 'ซื้อวัตถุดิบสุทธิ'?
4. ค่าใช้จ่ายใดบ้างที่จัดอยู่ในหมวด 'ค่าใช้จ่ายการผลิต' (Manufacturing Overhead) และมีหลักเกณฑ์ในการจำแนกอย่างไร?
5. จงอธิบายความแตกต่างระหว่าง 'ต้นทุนการผลิตรวม' และ 'ต้นทุนสินค้าที่ผลิตเสร็จ' พร้อมระบุรายการที่ใช้ในการปรับปรุงจากต้นทุนหนึ่งไปอีกต้นทุนหนึ่ง?
