# บทที่ 6

## บทนำ
บทเรียนนี้จะต่อยอดจากการทำความเข้าใจกิจการอุตสาหกรรม การคำนวณต้นทุนสินค้าที่ผลิต ซึ่งประกอบด้วยวัตถุดิบทางตรง (DM) ค่าแรงงานทางตรง (DL) และค่าใช้จ่ายการผลิต (MO) โดยจะเน้นไปที่ความแตกต่างของรายการปรับปรุงในกิจการอุตสาหกรรม เมื่อเทียบกับกิจการซื้อมาขายไปและกิจการให้บริการ ซึ่งมีรายการปรับปรุงพื้นฐาน 7 รายการอยู่แล้ว แต่กิจการอุตสาหกรรมจะมีรายการปรับปรุงที่เกี่ยวข้องกับการคำนวณต้นทุนสินค้าเพิ่มขึ้นอีก 4 รายการ

## วัตถุประสงค์
เพื่อทำความเข้าใจและสามารถบันทึกรายการปรับปรุงที่เพิ่มขึ้นมา 4 รายการในกิจการอุตสาหกรรมได้อย่างถูกต้อง ซึ่งรายการเหล่านี้มีความสำคัญต่อการคำนวณต้นทุนสินค้าที่ผลิตและต้นทุนขาย รวมถึงการแสดงผลในงบการเงินให้สะท้อนความเป็นจริงของกิจการอุตสาหกรรม

## แนวคิดสำคัญ
กิจการอุตสาหกรรมมีรายการปรับปรุงที่เกี่ยวข้องกับการคำนวณต้นทุนสินค้าเพิ่มขึ้น 4 รายการ นอกเหนือจาก 7 รายการพื้นฐานที่มีอยู่แล้วในกิจการประเภทอื่น ได้แก่: 1. วัตถุดิบโรงงานใช้ไป (หรือวัตถุดิบทางอ้อมใช้ไป): เป็นสินทรัพย์หมุนเวียนที่ใช้ในการผลิตสินค้า แต่ไม่ใช่ส่วนประกอบหลักของสินค้า เช่น ด้าย ตะปู น้ำมันปรุงอาหาร หรือกระดาษทราย การคำนวณหาจำนวนที่ใช้ไปจะใช้วิธีเดียวกับการคำนวณวัสดุสำนักงานใช้ไป คือ (วัตถุดิบต้นงวด + ซื้อเพิ่ม) - วัตถุดิบปลายงวด และถือเป็นส่วนหนึ่งของค่าใช้จ่ายการผลิต (MO) 2. ค่าเครื่องมือ หรือ เครื่องมือใช้ไป: เป็นเครื่องมือที่มีลักษณะคงทนถาวร แต่เมื่อนำมาใช้ในโรงงานอุตสาหกรรมจะมีการใช้งานหนักและบ่อยครั้ง ทำให้มีอายุการใช้งานสั้นลงและมักถูกเปลี่ยนใหม่เพื่อความปลอดภัยและคุณภาพสินค้า จึงไม่คิดค่าเสื่อมราคา แต่จะบันทึกเป็นค่าเครื่องมือใช้ไป โดยคำนวณจาก (เครื่องมือต้นงวด + ซื้อเพิ่ม) - เครื่องมือปลายงวด และถือเป็นส่วนหนึ่งของค่าใช้จ่ายการผลิต (MO) 3. ค่าตัดจำหน่ายสิทธิบัตร หรือ ลิขสิทธิ์: เป็นสินทรัพย์ไม่มีตัวตนที่กิจการได้มาเพื่อสิทธิในการผลิตสินค้าอย่างถูกกฎหมาย เช่น ใบอนุญาตหรือเครื่องหมายการค้า การบันทึกบัญชีจะใช้วิธีการตัดจำหน่ายคล้ายกับการคิดค่าเสื่อมราคาแบบเส้นตรง คือ (ราคาทุน / อายุการใช้งาน) คูณด้วยระยะเวลาที่ใช้ไปในงวด และถือเป็นส่วนหนึ่งของค่าใช้จ่ายการผลิต (MO) 4. การปันส่วนค่าใช้จ่าย: เป็นรายการปรับปรุงที่ใหม่จริง ๆ สำหรับกิจการอุตสาหกรรม เกิดขึ้นเมื่อมีค่าใช้จ่ายที่บันทึกรวมกัน แต่มีการใช้งานทั้งในส่วนของสำนักงานและโรงงาน เช่น ค่าสาธารณูปโภคของอาคารที่มีทั้งส่วนออฟฟิศและโรงงาน จำเป็นต้องมีการปันส่วนค่าใช้จ่ายตามเกณฑ์ที่เหมาะสม (เช่น พื้นที่ หรือจำนวนอุปกรณ์) เพื่อแยกส่วนที่เป็นของโรงงานให้เป็นค่าใช้จ่ายการผลิต (MO) และส่วนที่เป็นของสำนักงานให้เป็นค่าใช้จ่ายในการดำเนินงาน

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| กิจการอุตสาหกรรม | ธุรกิจที่เกี่ยวข้องกับการผลิตสินค้า |
| ต้นทุนสินค้าที่ผลิต | ต้นทุนทั้งหมดที่เกิดขึ้นในการผลิตสินค้าสำเร็จรูป |
| ค่าใช้จ่ายการผลิต (MO) | ต้นทุนการผลิตทางอ้อมที่ไม่ใช่ทั้งวัตถุดิบทางตรงและค่าแรงงานทางตรง |
| รายการปรับปรุง | รายการที่บันทึก ณ วันสิ้นงวดบัญชี เพื่อให้บัญชีแสดงฐานะการเงินและผลการดำเนินงานที่ถูกต้อง |
| วัตถุดิบโรงงานใช้ไป | วัตถุดิบทางอ้อมหรือวัสดุสิ้นเปลืองที่ใช้ในกระบวนการผลิตของโรงงาน |
| วัตถุดิบทางอ้อม | วัสดุที่ใช้ในการผลิตแต่ไม่ใช่ส่วนประกอบหลักของผลิตภัณฑ์ หรือมีมูลค่าน้อยจนไม่คุ้มค่าที่จะติดตาม |
| ค่าเครื่องมือ | ค่าใช้จ่ายที่เกิดจากการใช้เครื่องมือในโรงงานซึ่งมีอายุการใช้งานสั้นในสภาพแวดล้อมการผลิต |
| เครื่องมือใช้ไป | มูลค่าของเครื่องมือที่ถูกใช้หมดไปหรือเสื่อมสภาพจนต้องทิ้งในระหว่างงวดบัญชี |
| สิทธิบัตร | สิทธิพิเศษที่รัฐออกให้แก่ผู้ประดิษฐ์คิดค้น เพื่อคุ้มครองการประดิษฐ์หรือการออกแบบผลิตภัณฑ์ |
| ลิขสิทธิ์ | สิทธิแต่เพียงผู้เดียวที่จะกระทำการใดๆ เกี่ยวกับงานที่ผู้สร้างสรรค์ได้ทำขึ้น |
| ค่าตัดจำหน่าย | การปันส่วนต้นทุนของสินทรัพย์ไม่มีตัวตนให้เป็นค่าใช้จ่ายตลอดอายุการใช้งาน |
| สินทรัพย์ไม่มีตัวตน | สินทรัพย์ที่ไม่มีรูปร่างกายภาพ แต่มีมูลค่าทางเศรษฐกิจ เช่น สิทธิบัตร ลิขสิทธิ์ |
| การปันส่วนค่าใช้จ่าย | การแบ่งค่าใช้จ่ายที่เกิดขึ้นร่วมกันระหว่างหลายหน่วยงานหรือหลายวัตถุประสงค์ |
| ค่าสาธารณูปโภค | ค่าใช้จ่ายสำหรับบริการพื้นฐาน เช่น ค่าน้ำ ค่าไฟ ค่าโทรศัพท์ |
| วัสดุใช้ไป | มูลค่าของวัสดุสิ้นเปลืองที่ถูกใช้หมดไปในระหว่างงวดบัญชี |

## ตัวอย่างหรือขั้นตอน
1.  **วัตถุดิบโรงงานใช้ไป:**
    *   **โจทย์:** กิจการอุตสาหกรรมแห่งหนึ่งมีวัตถุดิบโรงงานเหลือ ณ วันที่ 1 มกราคม 25X1 จำนวน 20,000 บาท ระหว่างงวดซื้อวัตถุดิบโรงงานเพิ่ม 240,000 บาท และในวันที่ 31 ธันวาคม 25X1 ตรวจนับพบว่าเหลือ 15,000 บาท
    *   **การคำนวณ:**
        *   วัตถุดิบโรงงานที่มีไว้ใช้ทั้งหมด = วัตถุดิบต้นงวด + ซื้อเพิ่ม = 20,000 + 240,000 = 260,000 บาท
        *   วัตถุดิบโรงงานใช้ไป = วัตถุดิบที่มีไว้ใช้ทั้งหมด - วัตถุดิบปลายงวด = 260,000 - 15,000 = 245,000 บาท
    *   **รายการปรับปรุง:**
        *   เดบิต วัตถุดิบโรงงานใช้ไป 245,000
        *   เครดิต วัตถุดิบโรงงาน 245,000
2.  **ค่าเครื่องมือ หรือ เครื่องมือใช้ไป:**
    *   **โจทย์:** กิจการอุตสาหกรรมแห่งหนึ่งมีเครื่องมือ ณ วันที่ 1 มกราคม 25X1 จำนวน 30,000 บาท ระหว่างปีซื้อเครื่องมือเพิ่ม 150,000 บาท และในวันที่ 31 ธันวาคม 25X1 ตรวจนับได้เครื่องมือเหลือ 10,000 บาท
    *   **การคำนวณ:**
        *   เครื่องมือที่มีไว้ใช้ทั้งหมด = เครื่องมือต้นงวด + ซื้อเพิ่ม = 30,000 + 150,000 = 180,000 บาท
        *   ค่าเครื่องมือใช้ไป = เครื่องมือที่มีไว้ใช้ทั้งหมด - เครื่องมือปลายงวด = 180,000 - 10,000 = 170,000 บาท
    *   **รายการปรับปรุง:**
        *   เดบิต ค่าเครื่องมือ 170,000
        *   เครดิต เครื่องมือ 170,000
3.  **ค่าตัดจำหน่ายสิทธิบัตร หรือ ลิขสิทธิ์:**
    *   **โจทย์:** กิจการซื้อสิทธิบัตรมาในราคา 200,000 บาท เมื่อวันที่ 1 กรกฎาคม 25X1 มีอายุการใช้งาน 10 ปี
    *   **การคำนวณ:**
        *   ค่าตัดจำหน่ายต่อปี = 200,000 บาท / 10 ปี = 20,000 บาทต่อปี
        *   ค่าตัดจำหน่ายสำหรับงวด (6 เดือน) = 20,000 บาท * (6/12) = 10,000 บาท
    *   **รายการปรับปรุง:**
        *   เดบิต ค่าตัดจำหน่ายสิทธิบัตร 10,000
        *   เครดิต ค่าตัดจำหน่ายสะสม-สิทธิบัตร 10,000
4.  **การปันส่วนค่าใช้จ่าย:**
    *   **โจทย์:** กิจการอุตสาหกรรมแห่งหนึ่งบันทึกบัญชีค่าสาธารณูปโภค ณ วันที่ 31 ธันวาคม 25X1 จำนวน 48,000 บาท ซึ่งจากการตรวจสอบพบว่าเป็นค่าใช้จ่ายในส่วนของสำนักงาน 20% และโรงงาน 80%
    *   **การคำนวณ:**
        *   ส่วนของสำนักงาน = 48,000 บาท * 20% = 9,600 บาท
        *   ส่วนของโรงงาน = 48,000 บาท * 80% = 38,400 บาท
    *   **รายการปรับปรุง:**
        *   เดบิต ค่าสาธารณูปโภค-สำนักงาน 9,600
        *   เดบิต ค่าสาธารณูปโภค-โรงงาน 38,400
        *   เครดิต ค่าสาธารณูปโภค 48,000

## สรุปท้ายบท
กิจการอุตสาหกรรมมีความซับซ้อนในการบันทึกบัญชีมากกว่ากิจการประเภทอื่น โดยเฉพาะอย่างยิ่งในส่วนของรายการปรับปรุงที่เกี่ยวข้องกับต้นทุนการผลิต ซึ่งมี 4 รายการเพิ่มเติมจากรายการปรับปรุงทั่วไป 7 รายการ สามในสี่รายการนี้ (วัตถุดิบโรงงานใช้ไป, ค่าเครื่องมือใช้ไป, ค่าตัดจำหน่ายสิทธิบัตร) มีหลักการคำนวณคล้ายกับรายการปรับปรุงเดิม (วัสดุใช้ไป, ค่าเสื่อมราคา) แต่มีชื่อบัญชีที่แตกต่างกันและถูกจัดประเภทเป็นค่าใช้จ่ายการผลิต (MO) ส่วนรายการที่สี่ (การปันส่วนค่าใช้จ่าย) เป็นแนวคิดใหม่ที่ต้องมีการวิเคราะห์และแบ่งค่าใช้จ่ายที่เกิดขึ้นร่วมกันระหว่างสำนักงานและโรงงาน เพื่อให้การบันทึกบัญชีสะท้อนต้นทุนการผลิตที่แท้จริงได้อย่างถูกต้อง การทำความเข้าใจรายการปรับปรุงเหล่านี้จึงเป็นสิ่งสำคัญในการจัดทำงบการเงินของกิจการอุตสาหกรรม

## คำถามทบทวน
1. กิจการอุตสาหกรรมมีรายการปรับปรุงที่แตกต่างจากกิจการซื้อมาขายไปและให้บริการอย่างไร?
2. อธิบายความแตกต่างระหว่าง 'วัตถุดิบโรงงานใช้ไป' และ 'วัสดุสำนักงานใช้ไป' พร้อมยกตัวอย่างประกอบ
3. เหตุใดเครื่องมือที่ใช้ในโรงงานจึงถูกบันทึกเป็น 'ค่าเครื่องมือใช้ไป' แทนที่จะคิดค่าเสื่อมราคาเหมือนสินทรัพย์ถาวรทั่วไป?
4. 'ค่าตัดจำหน่ายสิทธิบัตร' มีความสำคัญอย่างไรต่อกิจการอุตสาหกรรม และแตกต่างจาก 'ค่าเสื่อมราคา' อย่างไร?
5. จงอธิบายแนวคิดและวิธีการปันส่วนค่าใช้จ่ายในกิจการอุตสาหกรรม พร้อมยกตัวอย่างค่าใช้จ่ายที่ต้องปันส่วน
