# การผ่านรายการไปสมุดขั้นปลาย

## บทนำ
การผ่านรายการไปสมุดขั้นปลาย (Posting to the Ledger) เป็นขั้นตอนสำคัญในกระบวนการทางบัญชีที่ต่อเนื่องจากการบันทึกรายการค้าในสมุดรายวันทั่วไป โดยมีวัตถุประสงค์เพื่อรวบรวมและจัดหมวดหมู่รายการค้าที่เกิดขึ้นทั้งหมดของแต่ละบัญชีแยกประเภท เพื่อให้สามารถหายอดคงเหลือของแต่ละบัญชีได้ ซึ่งยอดคงเหลือเหล่านี้จะถูกนำไปใช้ในการจัดทำงบทดลองและงบการเงินต่อไป การผ่านรายการนี้ช่วยให้ผู้ใช้งบการเงินสามารถทราบสถานะของแต่ละบัญชีได้อย่างรวดเร็วและถูกต้อง โดยเฉพาะอย่างยิ่งในปัจจุบันที่โปรแกรมบัญชีสำเร็จรูปส่วนใหญ่จะแสดงยอดคงเหลือให้เห็นทันทีหลังการบันทึกรายการ

## วัตถุประสงค์
ผู้เรียนจะสามารถเข้าใจถึงความสำคัญและวัตถุประสงค์ของการผ่านรายการไปสมุดบัญชีแยกประเภท สามารถจำแนกรูปแบบของสมุดบัญชีแยกประเภทได้แก่ แบบตัว T และแบบ 3 ช่อง และสามารถบันทึกรายการจากสมุดรายวันทั่วไปไปยังสมุดบัญชีแยกประเภทได้อย่างถูกต้อง รวมถึงเข้าใจหลักการใช้ชื่อบัญชีตรงข้ามในการบันทึกรายการเพื่ออธิบายที่มาของการเปลี่ยนแปลงยอดคงเหลือของบัญชีนั้นๆ

## แนวคิดสำคัญ
1. สมุดบัญชีแยกประเภททั่วไป (General Ledger): เป็นสมุดบัญชีที่ใช้รวบรวมและจัดหมวดหมู่รายการค้าที่บันทึกในสมุดรายวันทั่วไป โดยแยกตามชื่อบัญชีต่างๆ เพื่อหายอดคงเหลือของแต่ละบัญชี
2. รูปแบบของสมุดบัญชีแยกประเภท: มี 2 รูปแบบหลัก ได้แก่
    - แบบตัว T (T-Account Form): เป็นรูปแบบมาตรฐานหรือแบบดั้งเดิมที่ใช้ในการเรียนการสอนและฝึกฝนการคำนวณ มีลักษณะเป็นรูปตัว T โดยแบ่งเป็นด้านซ้ายสำหรับรายการเดบิต และด้านขวาสำหรับรายการเครดิต ไม่แสดงยอดคงเหลือทันที ต้องคำนวณเอง
    - แบบ 3 ช่อง (Three-Column Form): เป็นรูปแบบที่นิยมใช้ในโปรแกรมบัญชีสำเร็จรูปในปัจจุบัน มีช่องสำหรับรายการเดบิต รายการเครดิต และช่องแสดงยอดคงเหลือ (Balance) ซึ่งจะปรับปรุงยอดให้เห็นทันทีหลังการบันทึกรายการ ทำให้สะดวกและดูง่ายกว่า
3. การใช้ชื่อบัญชีตรงข้าม: ในการบันทึกรายการในสมุดบัญชีแยกประเภท ช่อง 'รายการ' จะระบุชื่อบัญชีตรงข้ามของรายการนั้นๆ (เช่น หากเดบิตเงินสดและเครดิตทุน ในบัญชีเงินสดจะระบุ 'ทุน' และในบัญชีทุนจะระบุ 'เงินสด') เพื่ออธิบายที่มาของการเพิ่มขึ้นหรือลดลงของบัญชีนั้นๆ โดยไม่ต้องย้อนกลับไปดูสมุดรายวันทั่วไป
4. ความสัมพันธ์กับงบการเงิน: ยอดคงเหลือจากสมุดบัญชีแยกประเภททั่วไปจะถูกนำไปจัดทำงบทดลอง (Trial Balance) และจากงบทดลองจะนำไปจัดทำงบการเงินต่างๆ เช่น งบกำไรขาดทุน (Income Statement) และงบแสดงฐานะการเงิน (Statement of Financial Position) ซึ่งเป็นผลลัพธ์สุดท้ายของกระบวนการทางบัญชี

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| สมุดขั้นต้น | สมุดบัญชีที่ใช้บันทึกรายการค้าที่เกิดขึ้นเป็นอันดับแรกตามลำดับเหตุการณ์ เช่น สมุดรายวันทั่วไป |
| สมุดขั้นปลาย | สมุดบัญชีที่ใช้รวบรวมและจัดหมวดหมู่รายการค้าจากสมุดขั้นต้น เพื่อหายอดคงเหลือของแต่ละบัญชี เช่น สมุดบัญชีแยกประเภททั่วไป |
| สมุดบัญชีแยกประเภททั่วไป | สมุดบัญชีที่ใช้บันทึกสรุปรายการค้าของแต่ละบัญชีแยกประเภท เพื่อหายอดคงเหลือ |
| แบบตัว T | รูปแบบของสมุดบัญชีแยกประเภทที่มีลักษณะคล้ายตัว T แบ่งเป็นด้านเดบิตและเครดิต |
| แบบ 3 ช่อง | รูปแบบของสมุดบัญชีแยกประเภทที่มีช่องสำหรับเดบิต เครดิต และยอดคงเหลือที่ปรับปรุงทันที |
| เดบิต | ด้านซ้ายของบัญชีแยกประเภท ใช้บันทึกการเพิ่มขึ้นของสินทรัพย์และค่าใช้จ่าย หรือการลดลงของหนี้สิน ส่วนของเจ้าของ และรายได้ |
| เครดิต | ด้านขวาของบัญชีแยกประเภท ใช้บันทึกการเพิ่มขึ้นของหนี้สิน ส่วนของเจ้าของ และรายได้ หรือการลดลงของสินทรัพย์และค่าใช้จ่าย |
| ยอดคงเหลือ | ผลรวมสุทธิของรายการเดบิตและเครดิตในบัญชีแยกประเภท ณ เวลาใดเวลาหนึ่ง |
| ชื่อบัญชีตรงข้าม | ชื่อบัญชีที่ใช้ระบุในช่อง 'รายการ' ของสมุดบัญชีแยกประเภท เพื่อแสดงถึงบัญชีคู่ที่ทำให้เกิดรายการนั้นๆ |
| สมุดรายวันทั่วไป | สมุดบัญชีขั้นต้นที่ใช้บันทึกรายการค้าตามลำดับเหตุการณ์ที่เกิดขึ้น |
| งบทดลอง | รายงานที่แสดงยอดคงเหลือของทุกบัญชีแยกประเภท เพื่อพิสูจน์ความสมดุลของเดบิตและเครดิตก่อนจัดทำงบการเงิน |
| งบการเงิน | รายงานทางการเงินที่แสดงฐานะการเงินและผลการดำเนินงานของกิจการ |
| งบกำไรขาดทุน | งบการเงินที่แสดงผลการดำเนินงานของกิจการในช่วงเวลาหนึ่ง โดยเปรียบเทียบรายได้กับค่าใช้จ่าย |
| งบแสดงฐานะการเงิน | งบการเงินที่แสดงฐานะทางการเงินของกิจการ ณ วันใดวันหนึ่ง ประกอบด้วย สินทรัพย์ หนี้สิน และส่วนของเจ้าของ |

## ตัวอย่างหรือขั้นตอน
การผ่านรายการจากสมุดรายวันทั่วไปไปยังสมุดบัญชีแยกประเภททั่วไป มีขั้นตอนดังนี้:

**ตัวอย่างการบันทึกรายการในสมุดรายวันทั่วไป:**
สมมติว่ามีการนำเงินสดมาลงทุนในกิจการในวันที่ 1 มีนาคม 25x1 จำนวน 300,000 บาท

**สมุดรายวันทั่วไป:**
| วัน | เดือน ปี | รายการ | หน้าบัญชี | เดบิต | เครดิต |
|---|---|---|---|---|---|
| 1 | มี.ค. 25x1 | เงินสด | 11 | 300,000 | - |
|   |   | ทุน | 31 | - | 300,000 |
|   |   | (เจ้าของกิจการนำเงินสดมาลงทุน) | | | |

**ขั้นตอนการผ่านรายการไปสมุดบัญชีแยกประเภททั่วไป (แบบตัว T):**
1.  **ระบุชื่อบัญชีแยกประเภท:** เลือกบัญชีแยกประเภทที่เกี่ยวข้องกับรายการนั้นๆ ในที่นี้คือ บัญชี 'เงินสด' และ บัญชี 'ทุน'
2.  **บันทึกรายการในบัญชี 'เงินสด' (เลขที่ 11):**
    *   เนื่องจากเงินสดเพิ่มขึ้นทางด้านเดบิต ให้บันทึกรายการทางด้านเดบิตของบัญชีเงินสด
    *   **วัน เดือน ปี:** 1 มี.ค. 25x1
    *   **รายการ:** ระบุชื่อบัญชีตรงข้าม คือ 'ทุน' (เพื่ออธิบายว่าเงินสดเพิ่มขึ้นเพราะเจ้าของนำเงินมาลงทุน)
    *   **หน้าบัญชี:** ระบุเลขหน้าสมุดรายวันทั่วไปที่มาของรายการ (เช่น ร.ว.1)
    *   **เดบิต:** 300,000 บาท

    | วัน เดือน ปี | รายการ | หน้าบัญชี | เดบิต | วัน เดือน ปี | รายการ | หน้าบัญชี | เครดิต |
    |---|---|---|---|---|---|---|---|
    | 1 มี.ค. 25x1 | ทุน | ร.ว.1 | 300,000 | | | | |

3.  **บันทึกรายการในบัญชี 'ทุน' (เลขที่ 31):**
    *   เนื่องจากทุนเพิ่มขึ้นทางด้านเครดิต ให้บันทึกรายการทางด้านเครดิตของบัญชีทุน
    *   **วัน เดือน ปี:** 1 มี.ค. 25x1
    *   **รายการ:** ระบุชื่อบัญชีตรงข้าม คือ 'เงินสด' (เพื่ออธิบายว่าทุนเพิ่มขึ้นเพราะนำเงินสดมาลงทุน)
    *   **หน้าบัญชี:** ระบุเลขหน้าสมุดรายวันทั่วไปที่มาของรายการ (เช่น ร.ว.1)
    *   **เครดิต:** 300,000 บาท

    |---|---|---|---|---|---|---|---|
    | | | | 1 มี.ค. 25x1 | เงินสด | ร.ว.1 | 300,000 |

**ข้อสังเกตสำหรับแบบ 3 ช่อง:**
สำหรับสมุดบัญชีแยกประเภทแบบ 3 ช่อง การบันทึกจะคล้ายกัน แต่จะมีช่อง 'ยอดคงเหลือ' เพิ่มเข้ามา ซึ่งจะแสดงยอดคงเหลือของบัญชีนั้นๆ ให้เห็นทันทีหลังการบันทึกแต่ละรายการ ทำให้ไม่ต้องคำนวณยอดคงเหลือเองเหมือนแบบตัว T

## สรุปท้ายบท
1.  การผ่านรายการไปสมุดบัญชีแยกประเภทเป็นขั้นตอนสำคัญที่เปลี่ยนข้อมูลจากรายการค้าตามลำดับเหตุการณ์ในสมุดรายวันทั่วไป ให้เป็นข้อมูลสรุปตามหมวดหมู่บัญชี เพื่อให้ทราบยอดคงเหลือของแต่ละบัญชี
2.  สมุดบัญชีแยกประเภทมีสองรูปแบบหลัก: แบบตัว T ซึ่งเหมาะสำหรับการเรียนรู้และฝึกฝนการคำนวณ และแบบ 3 ช่อง ซึ่งเป็นที่นิยมใช้ในทางปฏิบัติและโปรแกรมบัญชีเนื่องจากแสดงยอดคงเหลือให้เห็นทันที
3.  การใช้ชื่อบัญชีตรงข้ามในช่อง 'รายการ' ของสมุดบัญชีแยกประเภทมีความสำคัญอย่างยิ่ง เพราะช่วยอธิบายที่มาของการเปลี่ยนแปลงยอดคงเหลือของบัญชีนั้นๆ ได้อย่างชัดเจน โดยไม่ต้องย้อนกลับไปดูรายละเอียดในสมุดรายวันทั่วไป
4.  ยอดคงเหลือที่ได้จากสมุดบัญชีแยกประเภทเป็นข้อมูลพื้นฐานที่ใช้ในการจัดทำงบทดลองและงบการเงิน ซึ่งเป็นรายงานสำคัญที่แสดงผลการดำเนินงานและฐานะทางการเงินของกิจการ

## คำถามทบทวน
1. การผ่านรายการไปสมุดขั้นปลายคืออะไร และมีความสำคัญอย่างไรในกระบวนการทางบัญชี?
2. สมุดบัญชีแยกประเภททั่วไปมีกี่รูปแบบ อะไรบ้าง และแต่ละรูปแบบมีข้อดีข้อเสียแตกต่างกันอย่างไร?
3. เหตุใดจึงต้องใช้ 'ชื่อบัญชีตรงข้าม' ในช่องรายการของสมุดบัญชีแยกประเภททั่วไป?
4. หากกิจการมีการนำเงินสดมาลงทุนเพิ่ม 50,000 บาท จงอธิบายขั้นตอนการผ่านรายการนี้ไปยังสมุดบัญชีแยกประเภทของบัญชีเงินสดและบัญชีทุน (แบบตัว T)?
5. ยอดคงเหลือที่ได้จากสมุดบัญชีแยกประเภททั่วไปจะถูกนำไปใช้ประโยชน์อะไรต่อไปในกระบวนการทางบัญชี?
