# การผ่านรายการไปสมุดชั้นปลาย

## บทนำ
การผ่านรายการไปสมุดชั้นปลาย หรือบัญชีแยกประเภท เป็นขั้นตอนสำคัญในกระบวนการทางบัญชีที่ต่อจากการบันทึกรายการในสมุดรายวันทั่วไป สมุดรายวันทั่วไปจะบันทึกรายการตามลำดับเหตุการณ์ที่เกิดขึ้น ซึ่งเป็นไปตามข้อกำหนดทางกฎหมายเพื่อให้สามารถตรวจสอบได้ แต่การนำข้อมูลจากสมุดรายวันไปจัดทำงบการเงินโดยตรงนั้นทำได้ยากและไม่สะดวก จึงจำเป็นต้องมีการจัดหมวดหมู่รายการเหล่านั้นใหม่ตามชื่อบัญชีที่เกี่ยวข้องในสมุดชั้นปลาย เพื่อให้เห็นยอดคงเหลือของแต่ละบัญชีได้อย่างชัดเจนและเป็นระเบียบ พร้อมสำหรับการจัดทำงบการเงินต่อไป

## วัตถุประสงค์
วัตถุประสงค์หลักของการผ่านรายการไปสมุดชั้นปลายคือ เพื่อจัดหมวดหมู่รายการค้าที่บันทึกไว้ในสมุดรายวันทั่วไปให้เป็นระบบตามประเภทของบัญชี ทำให้สามารถทราบยอดคงเหลือของแต่ละบัญชีได้ง่ายขึ้น ซึ่งเป็นข้อมูลพื้นฐานที่จำเป็นสำหรับการจัดทำงบการเงิน เช่น งบทดลอง งบกำไรขาดทุน และงบแสดงฐานะการเงิน นอกจากนี้ การผ่านรายการยังช่วยให้การตรวจสอบข้อมูลทางบัญชีเป็นไปอย่างมีประสิทธิภาพมากขึ้น เนื่องจากมีการอ้างอิงเลขที่บัญชีกลับไปยังสมุดรายวันทั่วไป เพื่อยืนยันความถูกต้องของรายการ

## แนวคิดสำคัญ
1. สมุดรายวันทั่วไป (General Journal): เป็นสมุดบัญชีขั้นต้นที่ใช้บันทึกรายการค้าที่เกิดขึ้นตามลำดับวันเวลา โดยแสดงรายการเดบิตและเครดิตของแต่ละรายการ
2. สมุดชั้นปลาย / บัญชีแยกประเภท (Ledger / General Ledger): เป็นสมุดบัญชีขั้นปลายที่ใช้รวบรวมและจัดหมวดหมู่รายการค้าจากสมุดรายวันทั่วไป โดยแยกเป็นบัญชีเฉพาะแต่ละประเภท เช่น บัญชีเงินสด บัญชีลูกหนี้ บัญชีทุน เป็นต้น เพื่อแสดงยอดคงเหลือของแต่ละบัญชี
3. การผ่านรายการ (Posting): กระบวนการถ่ายโอนรายการจากสมุดรายวันทั่วไปไปยังบัญชีแยกประเภทที่เกี่ยวข้อง โดยบันทึกจำนวนเงินเดบิตในด้านเดบิตของบัญชีแยกประเภท และจำนวนเงินเครดิตในด้านเครดิตของบัญชีแยกประเภท
4. เลขที่บัญชี (Account Number): รหัสประจำตัวของแต่ละบัญชีแยกประเภท ใช้ในการอ้างอิงและจัดหมวดหมู่บัญชี
5. ช่องรายการ (Description Column): ในบัญชีแยกประเภท จะใช้บันทึกชื่อบัญชีตรงข้าม (Contra Account Name) เพื่ออธิบายที่มาหรือการเปลี่ยนแปลงของรายการนั้นๆ
6. ช่องหน้าบัญชี (Page Reference Column): ในบัญชีแยกประเภท จะใช้บันทึกเลขที่หน้าของสมุดรายวันทั่วไปที่มาของรายการ เพื่อให้สามารถตรวจสอบย้อนกลับได้
7. การยืนยันการผ่านรายการ: หลังจากผ่านรายการจากสมุดรายวันทั่วไปไปยังบัญชีแยกประเภทแล้ว จะมีการบันทึกเลขที่บัญชีแยกประเภทในช่อง 'เลขที่บัญชี' ของสมุดรายวันทั่วไป เพื่อเป็นเครื่องหมายยืนยันว่ารายการนั้นได้ถูกผ่านไปยังสมุดชั้นปลายเรียบร้อยแล้ว

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| สมุดรายวันทั่วไป | สมุดบัญชีขั้นต้นที่บันทึกรายการค้าตามลำดับวันเวลา |
| สมุดชั้นปลาย | สมุดบัญชีขั้นปลายที่รวบรวมและจัดหมวดหมู่รายการค้าตามประเภทบัญชี |
| บัญชีแยกประเภท | ชื่อเรียกอีกอย่างของสมุดชั้นปลาย ใช้สำหรับจัดหมวดหมู่รายการบัญชี |
| การผ่านรายการ | กระบวนการถ่ายโอนรายการจากสมุดรายวันทั่วไปไปยังบัญชีแยกประเภท |
| เลขที่บัญชี | รหัสประจำตัวของแต่ละบัญชีแยกประเภท |
| เดบิต | ด้านซ้ายของบัญชี ใช้บันทึกการเพิ่มขึ้นของสินทรัพย์และค่าใช้จ่าย หรือการลดลงของหนี้สิน ส่วนของเจ้าของ และรายได้ |
| เครดิต | ด้านขวาของบัญชี ใช้บันทึกการเพิ่มขึ้นของหนี้สิน ส่วนของเจ้าของ และรายได้ หรือการลดลงของสินทรัพย์และค่าใช้จ่าย |
| ชื่อบัญชีตรงข้าม | ชื่อบัญชีที่ใช้ในช่องรายการของบัญชีแยกประเภท เพื่ออธิบายที่มาของรายการ |
| หน้าบัญชี | เลขที่หน้าของสมุดรายวันทั่วไปที่ใช้เป็นแหล่งอ้างอิงของรายการ |
| งบทดลอง | รายงานที่แสดงยอดคงเหลือเดบิตและเครดิตของทุกบัญชีแยกประเภท เพื่อตรวจสอบความสมดุล |
| งบการเงิน | รายงานสรุปผลการดำเนินงานและฐานะทางการเงินของกิจการ |
| สินทรัพย์ | ทรัพยากรที่กิจการเป็นเจ้าของและมีมูลค่าทางเศรษฐกิจ |
| หนี้สิน | ภาระผูกพันที่กิจการต้องชำระในอนาคต |
| ส่วนของเจ้าของ | ส่วนที่เหลือของสินทรัพย์หลังจากหักหนี้สินออกแล้ว |
| รายได้ | ผลตอบแทนที่กิจการได้รับจากการดำเนินงาน |

## สรุปท้ายบท
การผ่านรายการไปสมุดชั้นปลายเป็นการจัดระเบียบข้อมูลทางบัญชีที่สำคัญอย่างยิ่ง แม้ในปัจจุบันจะมีโปรแกรมบัญชีที่ช่วยดำเนินการส่วนนี้โดยอัตโนมัติ แต่การทำความเข้าใจหลักการและขั้นตอนด้วยตนเองยังคงเป็นสิ่งจำเป็น เพราะช่วยให้ผู้ทำบัญชีสามารถตรวจสอบความถูกต้องของข้อมูลที่โปรแกรมสร้างขึ้นได้ หากเกิดข้อผิดพลาดหรือระบบมีปัญหา ผู้ทำบัญชีที่มีความรู้พื้นฐานจะสามารถแก้ไขหรือดำเนินการด้วยตนเองได้ การผ่านรายการทำให้เห็นการเปลี่ยนแปลงของแต่ละบัญชีอย่างชัดเจน ซึ่งเป็นประโยชน์ในการวิเคราะห์และตัดสินใจทางธุรกิจ รวมถึงการจัดทำงบการเงินที่ถูกต้องและน่าเชื่อถือเพื่อการตรวจสอบตามกฎหมาย
