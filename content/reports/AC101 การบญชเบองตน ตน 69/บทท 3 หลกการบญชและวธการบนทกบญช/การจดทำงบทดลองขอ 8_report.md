# การจัดทำงบทดลองข้อ 8

## บทนำ
บทเรียนนี้มุ่งเน้นการจัดทำงบทดลองก่อนปรับปรุง (Unadjusted Trial Balance) ซึ่งเป็นขั้นตอนสำคัญในกระบวนการทางบัญชี โดยจะอธิบายถึงวิธีการหายอดคงเหลือของแต่ละบัญชีแยกประเภท และนำยอดคงเหลือเหล่านั้นมาจัดทำงบทดลอง เพื่อตรวจสอบความถูกต้องของการบันทึกบัญชีตามระบบบัญชีคู่ ณ วันสิ้นงวดบัญชีที่กำหนด ซึ่งในที่นี้คือวันที่ 30 มิถุนายน โดยเน้นย้ำว่านี่เป็นเพียงงบทดลองเบื้องต้นที่ยังไม่รวมการปรับปรุงรายการต่าง ๆ ที่จะกล่าวถึงในบทเรียนถัดไป

## วัตถุประสงค์
1. เพื่อให้ผู้เรียนสามารถคำนวณหายอดคงเหลือของแต่ละบัญชีแยกประเภทได้อย่างถูกต้อง 2. เพื่อให้ผู้เรียนสามารถนำยอดคงเหลือที่ได้มาจัดทำงบทดลองก่อนปรับปรุงได้อย่างเป็นระบบ 3. เพื่อให้ผู้เรียนเข้าใจถึงวัตถุประสงค์และความสำคัญของงบทดลองในการตรวจสอบความสมดุลของสมการบัญชี 4. เพื่อให้ผู้เรียนสามารถระบุประเภทของบัญชีและด้านของยอดคงเหลือที่ถูกต้องในงบทดลอง

## แนวคิดสำคัญ
การจัดทำงบทดลองก่อนปรับปรุงเป็นขั้นตอนที่เกิดขึ้นหลังจากบันทึกรายการในสมุดรายวันทั่วไปและผ่านรายการไปยังบัญชีแยกประเภททั่วไปแล้ว โดยมีวัตถุประสงค์หลักเพื่อตรวจสอบความถูกต้องของการบันทึกบัญชีตามหลักการบัญชีคู่ ซึ่งระบุว่ายอดรวมด้านเดบิตจะต้องเท่ากับยอดรวมด้านเครดิตเสมอในทุกรายการบัญชี

แนวคิดสำคัญประกอบด้วย:
1.  **ยอดคงเหลือ (Remaining Balance):** คือผลต่างระหว่างยอดรวมด้านเดบิตและยอดรวมด้านเครดิตของแต่ละบัญชีแยกประเภท โดยยอดคงเหลือจะอยู่ด้านที่มีจำนวนเงินมากกว่า
2.  **งบทดลองก่อนปรับปรุง (Unadjusted Trial Balance):** เป็นรายงานที่แสดงรายการบัญชีทั้งหมดพร้อมยอดคงเหลือ ณ วันใดวันหนึ่ง โดยยังไม่ได้มีการปรับปรุงรายการบัญชีบางประเภท เช่น ค่าใช้จ่ายค้างจ่าย รายได้ค้างรับ หรือค่าเสื่อมราคา
3.  **ระบบบัญชีคู่ (Double-Entry System):** หลักการพื้นฐานที่ทุกรายการค้าจะส่งผลกระทบต่อบัญชีอย่างน้อยสองบัญชี โดยมีผลกระทบด้านเดบิตและเครดิตที่เท่ากันเสมอ ทำให้สมการบัญชี (สินทรัพย์ = หนี้สิน + ส่วนของเจ้าของ) ยังคงสมดุล
4.  **การตรวจสอบความถูกต้อง:** งบทดลองช่วยให้มั่นใจว่ายอดรวมเดบิตและเครดิตเท่ากัน ซึ่งเป็นสัญญาณเบื้องต้นว่าการบันทึกบัญชีอาจจะถูกต้อง แต่ไม่ได้หมายความว่าไม่มีข้อผิดพลาดอื่น ๆ เช่น การบันทึกผิดบัญชีแต่จำนวนเงินถูกต้อง

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| งบทดลอง | รายงานที่แสดงรายการบัญชีทั้งหมดพร้อมยอดคงเหลือ ณ วันใดวันหนึ่ง เพื่อตรวจสอบความสมดุลของเดบิตและเครดิต |
| งบทดลองก่อนปรับปรุง | งบทดลองที่จัดทำขึ้นก่อนการบันทึกรายการปรับปรุงสิ้นงวด |
| ยอดคงเหลือ | ผลต่างระหว่างยอดรวมด้านเดบิตและยอดรวมด้านเครดิตของบัญชีแยกประเภท |
| บัญชีแยกประเภท | สมุดบัญชีที่ใช้บันทึกรายการค้าที่ผ่านการบันทึกในสมุดรายวันทั่วไป โดยแยกตามประเภทของบัญชี |
| เดบิต | ด้านซ้ายของบัญชีแยกประเภท ใช้บันทึกการเพิ่มขึ้นของสินทรัพย์และค่าใช้จ่าย หรือการลดลงของหนี้สิน ส่วนของเจ้าของ และรายได้ |
| เครดิต | ด้านขวาของบัญชีแยกประเภท ใช้บันทึกการเพิ่มขึ้นของหนี้สิน ส่วนของเจ้าของ และรายได้ หรือการลดลงของสินทรัพย์และค่าใช้จ่าย |
| ระบบบัญชีคู่ | หลักการบันทึกบัญชีที่ทุกรายการค้าจะส่งผลกระทบต่อบัญชีอย่างน้อยสองบัญชี โดยมีผลกระทบด้านเดบิตและเครดิตที่เท่ากันเสมอ |
| สินทรัพย์ | ทรัพยากรที่กิจการเป็นเจ้าของและคาดว่าจะให้ประโยชน์เชิงเศรษฐกิจในอนาคต |
| หนี้สิน | ภาระผูกพันในปัจจุบันของกิจการที่ต้องชำระคืนในอนาคต |
| ส่วนของเจ้าของ | ส่วนที่เหลือของสินทรัพย์หลังจากหักหนี้สินทั้งหมดแล้ว |
| รายได้ | การเพิ่มขึ้นของประโยชน์เชิงเศรษฐกิจในรูปของการเพิ่มขึ้นของสินทรัพย์หรือการลดลงของหนี้สิน ซึ่งส่งผลให้ส่วนของเจ้าของเพิ่มขึ้น |
| ค่าใช้จ่าย | การลดลงของประโยชน์เชิงเศรษฐกิจในรูปของการลดลงของสินทรัพย์หรือการเพิ่มขึ้นของหนี้สิน ซึ่งส่งผลให้ส่วนของเจ้าของลดลง |
| ถอนใช้ส่วนตัว | การที่เจ้าของกิจการนำเงินหรือสินทรัพย์ของกิจการไปใช้ส่วนตัว ซึ่งทำให้ส่วนของเจ้าของลดลง |
| สมุดรายวันทั่วไป | สมุดบัญชีขั้นต้นที่ใช้บันทึกรายการค้าตามลำดับวันที่เกิดเหตุการณ์ |
| เอกสาร | หลักฐานประกอบการบันทึกบัญชี เช่น ใบเสร็จรับเงิน ใบแจ้งหนี้ |

## สรุปท้ายบท
1.  **ความสำคัญของยอดคงเหลือ:** การหายอดคงเหลือของแต่ละบัญชีแยกประเภทเป็นขั้นตอนสำคัญก่อนการจัดทำงบทดลอง โดยต้องรวมยอดเดบิตและเครดิตของแต่ละบัญชี แล้วนำมาหักลบกันเพื่อหายอดสุทธิที่ถูกต้อง
2.  **งบทดลองเป็นเครื่องมือตรวจสอบเบื้องต้น:** งบทดลองก่อนปรับปรุงทำหน้าที่เป็นเครื่องมือในการตรวจสอบความถูกต้องของการบันทึกบัญชีตามระบบบัญชีคู่ หากยอดรวมเดบิตและเครดิตไม่เท่ากัน แสดงว่ามีการบันทึกผิดพลาดในสมุดรายวันทั่วไปหรือการผ่านรายการไปยังบัญชีแยกประเภท
3.  **การระบุประเภทบัญชี:** การเข้าใจลักษณะของบัญชีแต่ละประเภท (สินทรัพย์ หนี้สิน ส่วนของเจ้าของ รายได้ ค่าใช้จ่าย และถอนใช้ส่วนตัว) เป็นสิ่งจำเป็นในการกำหนดว่ายอดคงเหลือควรอยู่ด้านเดบิตหรือเครดิต เช่น บัญชีถอนใช้ส่วนตัวเป็นบัญชีที่ลดทุน จึงมียอดคงเหลือด้านเดบิต
4.  **งบทดลองก่อนปรับปรุงยังไม่สมบูรณ์:** งบทดลองที่จัดทำขึ้นนี้เป็นเพียง 'ก่อนปรับปรุง' ซึ่งหมายความว่ายังไม่ได้รวมรายการปรับปรุงสิ้นงวดต่าง ๆ เช่น ค่าเสื่อมราคา ค่าใช้จ่ายค้างจ่าย หรือรายได้ค้างรับ ดังนั้นยอดคงเหลือที่ได้จึงยังไม่สะท้อนสถานะทางการเงินที่แท้จริงทั้งหมด และไม่สามารถนำไปจัดทำงบการเงินได้ทันที
