# แบบฝึกหัดบันทึกรายวันทั่วไป

## บทนำ
บทเรียนนี้มุ่งเน้นการทำความเข้าใจและฝึกฝนการบันทึกรายการค้าในสมุดรายวันทั่วไป ซึ่งเป็นขั้นตอนแรกและสำคัญที่สุดในกระบวนการทำบัญชี โดยใช้หลักการบัญชีคู่ที่ทุกรายการค้าจะต้องมีการบันทึกทั้งด้านเดบิตและเครดิตด้วยจำนวนเงินที่เท่ากันเสมอ เพื่อให้สมการบัญชีมีความสมดุลและถูกต้อง การบันทึกบัญชีอย่างละเอียดและเป็นระบบจะช่วยให้สามารถจัดทำงบการเงินและตรวจสอบข้อมูลทางการเงินได้อย่างมีประสิทธิภาพ

## วัตถุประสงค์
เมื่อจบบทเรียนนี้ ผู้เรียนจะสามารถ: 1. วิเคราะห์รายการค้าและบันทึกรายการในสมุดรายวันทั่วไปได้อย่างถูกต้อง 2. ผ่านรายการจากสมุดรายวันทั่วไปไปยังบัญชีแยกประเภท 3. จัดทำงบทดลองจากยอดคงเหลือในบัญชีแยกประเภท

## แนวคิดสำคัญ
แนวคิดสำคัญของบทเรียนนี้คือ 'หลักการบันทึกบัญชี' หรือ 'หลักการระบบบัญชีคู่' ซึ่งหมายถึงการบันทึกรายการค้าทุกครั้งจะต้องมีการเดบิตและเครดิตด้วยตัวเลขที่เท่ากันเสมอ เพื่อให้สมการบัญชีเป็นจริงและสมดุล โดยมีหลักการวิเคราะห์ดังนี้: สินทรัพย์ (Assets) หากเพิ่มขึ้นจะบันทึกด้านเดบิต หากลดลงจะบันทึกด้านเครดิต หนี้สิน (Liabilities) หากเพิ่มขึ้นจะบันทึกด้านเครดิต หากลดลงจะบันทึกด้านเดบิต ส่วนของเจ้าของ (Equity) หากเพิ่มขึ้นจะบันทึกด้านเครดิต หากลดลงจะบันทึกด้านเดบิต รายได้ (Revenue) หากเพิ่มขึ้นจะบันทึกด้านเครดิต หากลดลงจะบันทึกด้านเดบิต ค่าใช้จ่าย (Expenses) หากเพิ่มขึ้นจะบันทึกด้านเดบิต หากลดลงจะบันทึกด้านเครดิต นอกจากนี้ยังมีการบันทึกรายการถอนใช้ส่วนตัว (Drawing) ซึ่งจะลดส่วนของเจ้าของ จึงบันทึกด้านเดบิต

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| สมุดรายวันทั่วไป | สมุดบัญชีขั้นต้นที่ใช้บันทึกรายการค้าที่เกิดขึ้นตามลำดับวันที่ |
| บัญชีแยกประเภท | สมุดบัญชีขั้นปลายที่ใช้รวบรวมรายการค้าจากสมุดรายวันทั่วไปแยกตามประเภทของบัญชี |
| งบทดลอง | รายงานที่แสดงยอดคงเหลือของบัญชีแยกประเภททั้งหมด เพื่อตรวจสอบความสมดุลของเดบิตและเครดิต |
| หลักการบัญชีคู่ | ระบบการบันทึกบัญชีที่ทุกรายการค้าจะต้องมีการบันทึกทั้งด้านเดบิตและเครดิตด้วยจำนวนเงินที่เท่ากันเสมอ |
| เดบิต | ด้านซ้ายของการบันทึกบัญชี ซึ่งใช้บันทึกการเพิ่มขึ้นของสินทรัพย์และค่าใช้จ่าย หรือการลดลงของหนี้สิน ทุน และรายได้ |
| เครดิต | ด้านขวาของการบันทึกบัญชี ซึ่งใช้บันทึกการลดลงของสินทรัพย์และค่าใช้จ่าย หรือการเพิ่มขึ้นของหนี้สิน ทุน และรายได้ |
| สินทรัพย์ | ทรัพยากรที่มีมูลค่าที่กิจการเป็นเจ้าของและควบคุมได้ |
| หนี้สิน | ภาระผูกพันที่กิจการต้องชำระคืนในอนาคต |
| ทุน | ส่วนของเจ้าของในกิจการ หรือส่วนที่เหลือของสินทรัพย์หลังจากหักหนี้สินทั้งหมด |
| รายได้ | เงินที่กิจการได้รับจากการดำเนินงานตามปกติ |
| ค่าใช้จ่าย | ต้นทุนที่เกิดขึ้นจากการดำเนินงานเพื่อสร้างรายได้ |
| ถอนใช้ส่วนตัว | การที่เจ้าของกิจการนำเงินหรือสินทรัพย์ของกิจการไปใช้ส่วนตัว ซึ่งทำให้ส่วนของเจ้าของลดลง |
| ลูกหนี้การค้า | บุคคลหรือกิจการที่ค้างชำระเงินค่าสินค้าหรือบริการแก่กิจการ |
| เจ้าหนี้การค้า | บุคคลหรือกิจการที่กิจการค้างชำระเงินค่าสินค้าหรือบริการ |
| เจ้าหนี้อื่น | บุคคลหรือกิจการที่กิจการค้างชำระเงินค่าสินทรัพย์อื่นที่ไม่ใช่สินค้าคงเหลือ |

## ตัวอย่างหรือขั้นตอน
ตัวอย่างการบันทึกรายการค้าในสมุดรายวันทั่วไปของร้านเรียบสะอาด ในเดือนมิถุนายน 25x1:

**การเขียนวันที่:** ในหนึ่งหน้าของสมุดรายวัน จะเขียนปีและเดือนเพียงครั้งแรกของหน้าเท่านั้น รายการถัดไปจะเปลี่ยนเฉพาะวัน หากยังอยู่ในเดือนและปีเดียวกัน

**1. วันที่ 1 มิถุนายน: คุณนักรีดนำเงินสด 100,000 บาท และรถยนต์ 600,000 บาท มาลงทุน**
*   **การวิเคราะห์:**
    *   เงินสด (สินทรัพย์) เพิ่มขึ้น 100,000 บาท -> เดบิต เงินสด
    *   รถยนต์ (สินทรัพย์) เพิ่มขึ้น 600,000 บาท -> เดบิต รถยนต์
    *   ทุน-คุณนักรีด (ส่วนของเจ้าของ) เพิ่มขึ้น 700,000 บาท -> เครดิต ทุน-คุณนักรีด
*   **การบันทึกบัญชี:**
    *   เดบิต เงินสด 100,000
    *   เดบิต รถยนต์ 600,000
    *   เครดิต ทุน-คุณนักรีด 700,000
*   **คำอธิบาย:** เจ้าของนำสินทรัพย์มาลงทุน

**2. วันที่ 2 มิถุนายน: กู้เงินจากธนาคารจำนวน 85,000 บาท**
*   **การวิเคราะห์:**
    *   เงินสด (สินทรัพย์) เพิ่มขึ้น 85,000 บาท -> เดบิต เงินสด
    *   เงินกู้ (หนี้สิน) เพิ่มขึ้น 85,000 บาท -> เครดิต เงินกู้
*   **การบันทึกบัญชี:**
    *   เดบิต เงินสด 85,000
    *   เครดิต เงินกู้ 85,000
*   **คำอธิบาย:** กู้เงินจากธนาคาร

**3. วันที่ 3 มิถุนายน: ซื้ออุปกรณ์การซักรีด 80,000 บาท โดยจ่ายเงินสดในวันนี้เพียง 20,000 บาท ที่เหลือเป็นเงินเชื่อ**
*   **การวิเคราะห์:**
    *   อุปกรณ์การซักรีด (สินทรัพย์) เพิ่มขึ้น 80,000 บาท -> เดบิต อุปกรณ์การซักรีด
    *   เงินสด (สินทรัพย์) ลดลง 20,000 บาท -> เครดิต เงินสด
    *   เจ้าหนี้อื่น (หนี้สิน) เพิ่มขึ้น 60,000 บาท (80,000 - 20,000) -> เครดิต เจ้าหนี้อื่น (เนื่องจากเป็นการซื้อสินทรัพย์ที่ไม่ใช่สินค้าคงเหลือ)
*   **การบันทึกบัญชี:**
    *   เดบิต อุปกรณ์การซักรีด 80,000
    *   เครดิต เงินสด 20,000
    *   เครดิต เจ้าหนี้อื่น 60,000
*   **คำอธิบาย:** ซื้ออุปกรณ์การซักรีด

**6. วันที่ 6 มิถุนายน: ซื้อวัสดุสิ้นเปลืองในการซักรีดเป็นเงินเชื่อ 12,000 บาท**
*   **การวิเคราะห์:**
    *   วัสดุสิ้นเปลืองในการซักรีด (สินทรัพย์) เพิ่มขึ้น 12,000 บาท -> เดบิต วัสดุสิ้นเปลืองในการซักรีด
    *   เจ้าหนี้การค้า (หนี้สิน) เพิ่มขึ้น 12,000 บาท (เนื่องจากเป็นการซื้อวัสดุที่ใช้แล้วหมดไปกับการดำเนินงาน)
*   **การบันทึกบัญชี:**
    *   เดบิต วัสดุสิ้นเปลืองในการซักรีด 12,000
    *   เครดิต เจ้าหนี้การค้า 12,000
*   **คำอธิบาย:** ซื้อวัสดุสิ้นเปลืองในการซักรีด

**7. วันที่ 7 มิถุนายน: เปิดบัญชีเงินฝากธนาคาร 30,000 บาท**
*   **การวิเคราะห์:**
    *   เงินฝากธนาคาร (สินทรัพย์) เพิ่มขึ้น 30,000 บาท -> เดบิต เงินฝากธนาคาร
    *   เงินสด (สินทรัพย์) ลดลง 30,000 บาท -> เครดิต เงินสด
*   **การบันทึกบัญชี:**
    *   เดบิต เงินฝากธนาคาร 30,000
    *   เครดิต เงินสด 30,000
*   **คำอธิบาย:** นำเงินสดเปิดบัญชีธนาคาร

**8. วันที่ 8 มิถุนายน: รับรายได้ค่าบริการซักรีด 30,000 บาท เป็นเงินสด**
*   **การวิเคราะห์:**
    *   เงินสด (สินทรัพย์) เพิ่มขึ้น 30,000 บาท -> เดบิต เงินสด
    *   รายได้ค่าบริการ (รายได้) เพิ่มขึ้น 30,000 บาท -> เครดิต รายได้ค่าบริการ
*   **การบันทึกบัญชี:**
    *   เดบิต เงินสด 30,000
    *   เครดิต รายได้ค่าบริการ 30,000
*   **คำอธิบาย:** รับรายได้ค่าบริการ

**10. วันที่ 10 มิถุนายน: คุณนักรีดถอนเงินสดไปใช้ส่วนตัว 10,000 บาท**
*   **การวิเคราะห์:**
    *   ถอนใช้ส่วนตัว (ลดส่วนของเจ้าของ) เพิ่มขึ้น 10,000 บาท -> เดบิต ถอนใช้ส่วนตัว
    *   เงินสด (สินทรัพย์) ลดลง 10,000 บาท -> เครดิต เงินสด
*   **การบันทึกบัญชี:**
    *   เดบิต ถอนใช้ส่วนตัว 10,000
    *   เครดิต เงินสด 10,000
*   **คำอธิบาย:** เจ้าของถอนเงินสดไปใช้ส่วนตัว

**15. วันที่ 15 มิถุนายน: ส่งบิลเรียกเก็บค่าบริการซักรีด 15,000 บาท**
*   **การวิเคราะห์:**
    *   ลูกหนี้การค้า (สินทรัพย์) เพิ่มขึ้น 15,000 บาท -> เดบิต ลูกหนี้การค้า
    *   รายได้ค่าบริการ (รายได้) เพิ่มขึ้น 15,000 บาท -> เครดิต รายได้ค่าบริการ
*   **การบันทึกบัญชี:**
    *   เดบิต ลูกหนี้การค้า 15,000
    *   เครดิต รายได้ค่าบริการ 15,000
*   **คำอธิบาย:** ส่งบิลเรียกเก็บรายได้ค่าซักรีด

**20. วันที่ 20 มิถุนายน: รับชำระหนี้จากนางดวงเดือนสำหรับบิลที่เรียกเก็บเมื่อวันที่ 15 มิถุนายน 15,000 บาท**
*   **การวิเคราะห์:**
    *   เงินสด (สินทรัพย์) เพิ่มขึ้น 15,000 บาท -> เดบิต เงินสด
    *   ลูกหนี้การค้า (สินทรัพย์) ลดลง 15,000 บาท -> เครดิต ลูกหนี้การค้า
*   **การบันทึกบัญชี:**
    *   เดบิต เงินสด 15,000
    *   เครดิต ลูกหนี้การค้า 15,000
*   **คำอธิบาย:** รับชำระหนี้ค่าบริการซักรีด

**25. วันที่ 25 มิถุนายน: โอนเงินชำระค่าสาธารณูปโภค 6,000 บาท และเงินเดือน 12,000 บาท**
*   **การวิเคราะห์:**
    *   ค่าสาธารณูปโภค (ค่าใช้จ่าย) เพิ่มขึ้น 6,000 บาท -> เดบิต ค่าสาธารณูปโภค
    *   เงินเดือน (ค่าใช้จ่าย) เพิ่มขึ้น 12,000 บาท -> เดบิต เงินเดือน
    *   เงินฝากธนาคาร (สินทรัพย์) ลดลง 18,000 บาท (6,000 + 12,000) -> เครดิต เงินฝากธนาคาร
*   **การบันทึกบัญชี:**
    *   เดบิต ค่าสาธารณูปโภค 6,000
    *   เดบิต เงินเดือน 12,000
    *   เครดิต เงินฝากธนาคาร 18,000
*   **คำอธิบาย:** โอนเงินชำระค่าใช้จ่าย

**28. วันที่ 28 มิถุนายน: จ่ายค่าพาหนะเป็นเงินสด 400 บาท**
*   **การวิเคราะห์:**
    *   ค่าพาหนะ (ค่าใช้จ่าย) เพิ่มขึ้น 400 บาท -> เดบิต ค่าพาหนะ
    *   เงินสด (สินทรัพย์) ลดลง 400 บาท -> เครดิต เงินสด
*   **การบันทึกบัญชี:**
    *   เดบิต ค่าพาหนะ 400
    *   เครดิต เงินสด 400
*   **คำอธิบาย:** จ่ายค่าพาหนะ

## สรุปท้ายบท
บทเรียนนี้เน้นย้ำถึงความสำคัญของการวิเคราะห์รายการค้าอย่างละเอียดเพื่อระบุบัญชีที่เกี่ยวข้องและผลกระทบต่อบัญชีเหล่านั้น (เพิ่มขึ้นหรือลดลง) ซึ่งเป็นพื้นฐานในการตัดสินใจว่าจะบันทึกด้านเดบิตหรือเครดิต การใช้หลักการบัญชีคู่ที่เครดิตและเดบิตต้องเท่ากันเสมอเป็นหัวใจสำคัญของการบันทึกบัญชีที่ถูกต้อง การฝึกฝนการบันทึกรายการค้าในสมุดรายวันทั่วไปจะช่วยให้ผู้เรียนมีความเข้าใจในกระบวนการบัญชีขั้นต้นและสามารถนำไปต่อยอดในการจัดทำงบการเงินในอนาคตได้

2. หากกิจการได้รับเงินสดจากการให้บริการ จะบันทึกบัญชีอย่างไร (ระบุบัญชีที่เกี่ยวข้องและด้านเดบิต/เครดิต)?
3. การที่เจ้าของกิจการถอนเงินสดไปใช้ส่วนตัว มีผลกระทบต่อบัญชีใดบ้างและบันทึกอย่างไร?
4. อธิบายความแตกต่างระหว่าง 'เจ้าหนี้การค้า' และ 'เจ้าหนี้อื่น' พร้อมยกตัวอย่างประกอบ
5. หากกิจการซื้ออุปกรณ์สำนักงานเป็นเงินเชื่อ จะบันทึกบัญชีอย่างไร (ระบุบัญชีที่เกี่ยวข้องและด้านเดบิต/เครดิต)?
