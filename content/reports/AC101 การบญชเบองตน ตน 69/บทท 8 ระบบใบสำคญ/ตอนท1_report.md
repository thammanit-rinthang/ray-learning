# ตอนที่1

## บทนำ
บทที่ 8 นี้กล่าวถึง 'ระบบใบสำคัญ' (Voucher system) ซึ่งเป็นระบบการควบคุมภายในประเภทหนึ่งที่นำหลักการบัญชีมาใช้ในการควบคุมการใช้จ่ายเงินของกิจการ โดยเฉพาะอย่างยิ่งการควบคุมเงินสด ซึ่งเป็นรายการที่รั่วไหลได้ง่ายที่สุด ระบบนี้จะช่วยให้การจ่ายเงินมีความรัดกุมและมีประสิทธิภาพมากขึ้น โดยเน้นการสร้างหลักฐานและแบ่งแยกหน้าที่ในการอนุมัติและจ่ายเงิน

## วัตถุประสงค์
1. เพื่อให้มีความรู้ความเข้าใจเกี่ยวกับระบบใบสำคัญ 2. เพื่อให้สามารถบันทึกรายการบัญชีตามวิธีการของระบบใบสำคัญได้

## แนวคิดสำคัญ
ระบบใบสำคัญเป็นระบบการควบคุมภายในที่เกี่ยวข้องกับการใช้จ่ายเงินของกิจการ มีหลักการสำคัญ 2 ประการ คือ 1. การจ่ายเงินของกิจการทุกรายการจะต้องจัดทำเอกสาร 'ใบสำคัญจ่าย' (Voucher) ขึ้นมา เพื่อใช้เป็นหลักฐานในการตรวจสอบ และใบสำคัญจ่ายทุกใบจะต้องได้รับอนุมัติจากผู้มีอำนาจเสมอ แม้จะเป็นการจ่ายเงินทันทีก็ตาม 2. การจ่ายเงินทุกครั้งทุกรายการต้องจ่ายเป็น 'เช็ค' เสมอ ยกเว้นรายการจ่ายจำนวนเล็กน้อย ซึ่งจะจ่ายจากระบบ 'เงินสดย่อย' (Petty cash) ระบบใบสำคัญช่วยให้เกิดการแบ่งแยกหน้าที่ระหว่างผู้ตั้งหนี้ (ผู้จัดทำใบสำคัญ) และผู้จ่ายเงิน (ผู้ออกเช็ค) เพื่อให้เกิดการควบคุมกันเองภายใน ป้องกันการรั่วไหลของเงินสด สำหรับรายการจ่ายเล็กน้อยที่ไม่สามารถจ่ายด้วยเช็คได้ เช่น ค่าแท็กซี่ หรือค่ารับรอง จะใช้ระบบเงินสดย่อย โดยมีการกำหนดวงเงินและผู้รับผิดชอบ ซึ่งผู้ดูแลเงินสดย่อยจะต้องมีเอกสารหลักฐานแสดงการใช้จ่ายเงินเสมอ

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| ระบบใบสำคัญ | Voucher system ระบบการควบคุมภายในที่ใช้ใบสำคัญจ่ายเป็นหลักฐานในการควบคุมการใช้จ่ายเงิน |
| ใบสำคัญจ่าย | Voucher เอกสารที่จัดทำขึ้นเพื่อเป็นหลักฐานในการจ่ายเงินทุกรายการของกิจการ และต้องได้รับการอนุมัติจากผู้มีอำนาจ |
| เงินสดย่อย | Petty cash เงินสดจำนวนเล็กน้อยที่จัดสรรไว้สำหรับจ่ายค่าใช้จ่ายยิบย่อยที่ไม่สามารถจ่ายด้วยเช็คได้ |
| ทะเบียนใบสำคัญจ่าย | Voucher Register สมุดบัญชีที่ใช้บันทึกรายการใบสำคัญจ่ายทั้งหมด แทนสมุดรายวันทั่วไปและสมุดเฉพาะอื่นๆ |
| เช็ค | Check ตราสารที่ใช้ในการสั่งจ่ายเงินจากบัญชีธนาคาร ซึ่งเป็นวิธีการจ่ายเงินหลักในระบบใบสำคัญ |
| การควบคุมภายใน | Internal Control กระบวนการที่ออกแบบมาเพื่อเพิ่มความน่าเชื่อถือของข้อมูลทางการเงินและป้องกันการทุจริต |
| การแบ่งแยกหน้าที่ | Segregation of Duties การกระจายงานที่สำคัญออกเป็นส่วนๆ ให้บุคคลหลายคนรับผิดชอบ เพื่อลดโอกาสในการทุจริตหรือข้อผิดพลาด |
| เจ้าหนี้การค้า | Accounts Payable หนี้สินที่เกิดจากการซื้อสินค้าหรือบริการเป็นเงินเชื่อ |
| ค่าใช้จ่ายค้างจ่าย | Accrued Expenses ค่าใช้จ่ายที่เกิดขึ้นแล้วแต่ยังไม่ได้จ่ายเงิน |
| ตั๋วเงินจ่าย | Notes Payable หนี้สินที่เกิดจากการออกตั๋วสัญญาใช้เงินหรือตั๋วแลกเงิน |
| วัตถุดิบ | Raw Materials วัสดุที่ใช้ในการผลิตสินค้า |
| ค่าขนส่งเข้า | Freight-in ค่าใช้จ่ายในการขนส่งสินค้าที่ซื้อเข้ามา |
| ค่าโทรศัพท์ | Telephone Expense ค่าใช้จ่ายสำหรับการบริการโทรศัพท์ |
| เงื่อนไขการชำระเงิน | Payment Terms ข้อตกลงเกี่ยวกับการชำระเงิน เช่น ส่วนลดเงินสดและระยะเวลาการชำระหนี้ |

## ตัวอย่างหรือขั้นตอน
ขั้นตอนของระบบใบสำคัญมี 5 ขั้นตอน ดังนี้: 1. การจัดทำใบสำคัญจ่าย: เมื่อมีรายการใช้จ่ายเงิน เช่น การซื้อสินค้า/สินทรัพย์, การจ่ายค่าใช้จ่ายต่างๆ, หรือการชำระหนี้/ตั๋วเงินจ่าย จะต้องจัดทำใบสำคัญจ่ายขึ้นมา โดยไม่สนใจว่าจะจ่ายเงินทันทีหรือจ่ายภายหลัง ใบสำคัญทุกฉบับต้องได้รับการอนุมัติจากผู้มีอำนาจ เช่น หัวหน้าฝ่ายจัดซื้อหรือหัวหน้าฝ่ายที่เกี่ยวข้อง รายละเอียดในใบสำคัญจะระบุว่าจ่ายอะไร, วันที่, จำนวนเงิน, รายละเอียดการจ่าย, เอกสารหลักฐานแนบ (เช่น ใบส่งของ, ใบสั่งซื้อ, สลิปเงินเดือน, ใบแจ้งหนี้, ใบเสร็จ) และต้องมีลายเซ็นรับรอง 2. การบันทึกรายการตามใบสำคัญจ่าย: ใบสำคัญที่ได้รับอนุมัติแล้วจะถูกนำมาบันทึกใน 'ทะเบียนใบสำคัญจ่าย' กิจการที่ใช้ระบบนี้จะไม่ใช้สมุดรายวันทั่วไป, สมุดจ่ายเงิน, หรือสมุดซื้อ แต่จะบันทึกในทะเบียนใบสำคัญจ่ายแทน ทุกรายการที่ต้องจ่ายจะถูกเครดิตด้วยบัญชี 'ใบสำคัญจ่าย' เสมอ ซึ่งทำหน้าที่เสมือนบัญชีเจ้าหนี้ทุกชนิด (เจ้าหนี้การค้า, เจ้าหนี้อื่น, ค่าใช้จ่ายค้างจ่าย, ตั๋วเงินจ่าย) ส่วนบัญชีที่ถูกเดบิตจะเป็นบัญชีค่าใช้จ่ายหรือสินทรัพย์ที่เกี่ยวข้อง บัญชีที่เกิดบ่อยจะมีช่องเฉพาะ เช่น ซื้อ, ค่าขนส่งเข้า, เงินเดือนค่าแรง ส่วนบัญชีที่เกิดไม่บ่อย เช่น ค่ารับรอง, ค่าโทรศัพท์ จะอยู่ในช่อง 'บัญชีอื่นๆ' 3. การจัดแฟ้มใบสำคัญจ่ายที่ยังไม่ได้จ่ายเงิน: ใบสำคัญที่ยังไม่ถึงกำหนดจ่ายจะถูกเก็บเข้าแฟ้ม โดยเรียงตามวันครบกำหนด เพื่อให้ฝ่ายการเงินสามารถหยิบมาทำเช็คได้ตามลำดับ หากเป็นรายการที่ต้องจ่ายทันที อาจข้ามขั้นตอนนี้ไป 4. การจ่ายเงินตามใบสำคัญจ่าย: เมื่อถึงกำหนดจ่ายเงิน ฝ่ายการเงินจะออกเช็คตามใบสำคัญที่อยู่ในแฟ้ม โดยเช็คจะต้องลงนามโดยผู้มีอำนาจตามจำนวนเงิน 5. การจัดแฟ้มใบสำคัญจ่ายที่จ่ายเงินแล้ว: เช็คที่จ่ายแล้วพร้อมสำเนาใบสำคัญที่เซ็นรับเรียบร้อยแล้วจะถูกเก็บเข้าแฟ้มเพื่อใช้ในการตรวจสอบในอนาคต ตัวอย่างการบันทึกในทะเบียนใบสำคัญจ่าย: - **25X1 กันยายน 1**: จัดทำใบสำคัญจ่ายเลขที่ 9-1 เพื่อซื้อวัตถุดิบจากบริษัท สรัญญา จำนวน 25,000 บาท เงื่อนไข 2/10 n/30 บันทึก: เดบิต ซื้อ 25,000 บาท, เครดิต ใบสำคัญจ่าย 25,000 บาท - **25X1 กันยายน 3**: จัดทำใบสำคัญจ่ายเลขที่ 9-2 เพื่อจ่ายค่าขนส่งเข้าให้กับบริษัท ไปรษณีย์ไทย จำกัด จำนวน 1,500 บาท บันทึก: เดบิต ค่าขนส่งเข้า 1,500 บาท, เครดิต ใบสำคัญจ่าย 1,500 บาท - **25X1 กันยายน 5**: จัดทำใบสำคัญจ่ายเลขที่ 9-3 สำหรับค่าโทรศัพท์จากองค์การโทรศัพท์ จำนวน 3,300 บาท บันทึก: เดบิต บัญชีอื่นๆ (ค่าโทรศัพท์) 3,300 บาท, เครดิต ใบสำคัญจ่าย 3,300 บาท

## สรุปท้ายบท
ระบบใบสำคัญช่วยให้การจ่ายเงินของกิจการมีความรัดกุมและโปร่งใสมากขึ้น โดยมีหลักฐานการอนุมัติและการจ่ายเงินที่ชัดเจน การแบ่งแยกหน้าที่ระหว่างผู้จัดทำใบสำคัญและผู้ออกเช็คช่วยป้องกันการทุจริตและข้อผิดพลาด นอกจากนี้ การบันทึกรายการในทะเบียนใบสำคัญจ่ายยังช่วยประหยัดเวลาและจัดหมวดหมู่ข้อมูลการลงบัญชีได้อย่างมีประสิทธิภาพ เนื่องจากทุกรายการจะถูกเครดิตด้วยบัญชี 'ใบสำคัญจ่าย' เพียงบัญชีเดียว ทำให้การจัดการหนี้สินหมุนเวียนง่ายขึ้น

## คำถามทบทวน
1. ระบบใบสำคัญคืออะไร และมีวัตถุประสงค์หลักในการควบคุมเรื่องใด?
2. หลักการสำคัญ 2 ประการของระบบใบสำคัญมีอะไรบ้าง และมีความสำคัญอย่างไร?
3. ระบบเงินสดย่อย (Petty cash) มีบทบาทอย่างไรในระบบใบสำคัญ และใช้แก้ปัญหาการจ่ายเงินประเภทใด?
4. อธิบายขั้นตอนการบันทึกรายการในทะเบียนใบสำคัญจ่าย พร้อมยกตัวอย่างบัญชีที่ถูกเดบิตและเครดิตเมื่อมีการจัดทำใบสำคัญจ่าย
5. ข้อดีของการใช้ระบบใบสำคัญมีอะไรบ้าง และส่งผลต่อการควบคุมภายในของกิจการอย่างไร?
