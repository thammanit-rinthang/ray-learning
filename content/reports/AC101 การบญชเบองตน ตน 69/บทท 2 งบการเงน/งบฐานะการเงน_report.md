# งบฐานะการเงิน

## บทนำ
งบฐานะการเงิน (Statement of Financial Position) เป็นรายงานทางการเงินที่แสดงฐานะทางการเงินของกิจการ ณ วันใดวันหนึ่ง ซึ่งประกอบด้วยองค์ประกอบหลัก 3 ส่วน ได้แก่ สินทรัพย์ (Assets) หนี้สิน (Liabilities) และส่วนของเจ้าของ (Owner's Equity) งบฐานะการเงินมีชื่อเรียกอย่างไม่เป็นทางการและเป็นที่รู้จักกันในหมู่นักบัญชีว่า 'งบดุล' เนื่องจากงบนี้แสดงความสัมพันธ์ของสมการบัญชีที่ทำให้เกิดความสมดุลกันเสมอ

## วัตถุประสงค์
วัตถุประสงค์หลักของงบฐานะการเงินคือการแสดงให้เห็นถึงองค์ประกอบสำคัญ 3 ประการของกิจการ ได้แก่ สินทรัพย์ที่กิจการมีอยู่ หนี้สินที่กิจการต้องชำระ และส่วนของเจ้าของที่เหลืออยู่หลังจากหักหนี้สินออกจากสินทรัพย์ ซึ่งเป็นการสะท้อนฐานะทางการเงินโดยรวมของกิจการและฐานะของเจ้าของกิจการ ณ วันที่จัดทำงบ

## แนวคิดสำคัญ
แนวคิดสำคัญของงบฐานะการเงินคือ 'สมการบัญชี' ซึ่งระบุว่า สินทรัพย์ (Assets) จะต้องเท่ากับ หนี้สิน (Liabilities) บวกด้วย ส่วนของเจ้าของ (Owner's Equity) เสมอ หรืออาจกล่าวได้ว่า สินทรัพย์ลบด้วยหนี้สินจะเท่ากับส่วนของเจ้าของ ซึ่งเราเรียกว่า 'สินทรัพย์สุทธิ' แนวคิดนี้เกิดจากข้อเท็จจริงที่ว่า การได้มาซึ่งสินทรัพย์ของกิจการนั้นมาจาก 2 แหล่งหลักเท่านั้น คือ การลงทุนจากเจ้าของ และการกู้ยืมจากบุคคลภายนอก (หนี้สิน) สินทรัพย์เหล่านี้จะถูกนำไปใช้ในการดำเนินงาน เช่น ซื้อสินค้า เครื่องจักร หรืออุปกรณ์ เพื่อสร้างรายได้ เมื่อกิจการดำเนินงานและมีผลกำไร เงินทุนจะเพิ่มขึ้น ทำให้สินทรัพย์และส่วนของเจ้าของเพิ่มขึ้นตามไปด้วย สินทรัพย์แบ่งออกเป็น 2 ประเภทหลัก ได้แก่ สินทรัพย์หมุนเวียน (Current Assets) และ สินทรัพย์ไม่หมุนเวียน (Non-Current Assets) สินทรัพย์หมุนเวียนคือสินทรัพย์ที่สามารถเปลี่ยนเป็นเงินสดได้ง่าย หรือใช้หมดไปภายในรอบระยะเวลาบัญชีปกติ (1 ปี) ซึ่งโดยทั่วไปคือ 1 ปีปฏิทิน การจัดเรียงสินทรัพย์หมุนเวียนในงบฐานะการเงินจะเรียงตามสภาพคล่องที่เปลี่ยนเป็นเงินสดได้ง่ายที่สุดก่อน

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| งบฐานะการเงิน | รายงานทางการเงินที่แสดงฐานะทางการเงินของกิจการ ณ วันใดวันหนึ่ง |
| สินทรัพย์ | ทรัพยากรที่กิจการเป็นเจ้าของและสามารถวัดมูลค่าเป็นตัวเงินได้ |
| หนี้สิน | ภาระผูกพันที่กิจการต้องชำระแก่บุคคลภายนอก |
| ส่วนของเจ้าของ | ส่วนที่เหลือของสินทรัพย์หลังจากหักหนี้สินออกไปแล้ว หรือเงินลงทุนของเจ้าของในกิจการ |
| งบดุล | ชื่อเรียกอย่างไม่เป็นทางการของงบฐานะการเงิน |
| สมการบัญชี | ความสัมพันธ์พื้นฐานทางบัญชีที่ว่า สินทรัพย์ = หนี้สิน + ส่วนของเจ้าของ |
| สินทรัพย์สุทธิ | สินทรัพย์ที่เหลืออยู่หลังจากหักหนี้สินออกไปแล้ว ซึ่งเท่ากับส่วนของเจ้าของ |
| สินทรัพย์หมุนเวียน | สินทรัพย์ที่สามารถเปลี่ยนเป็นเงินสดได้ง่าย หรือใช้หมดไปภายในรอบระยะเวลาบัญชีปกติ (1 ปี) |
| สินทรัพย์ไม่หมุนเวียน | สินทรัพย์ที่ไม่ได้มีวัตถุประสงค์เพื่อเปลี่ยนเป็นเงินสดหรือใช้หมดไปภายใน 1 ปี |
| เงินสด | เหรียญกษาปณ์ ธนบัตร เช็คที่ถึงกำหนดแล้ว เช็คเดินทาง ดราฟต์ ธนาณัติ ตั๋วแลกเงิน เงินสดย่อย |
| เงินฝากธนาคาร | เงินฝากในสถาบันการเงินที่ไม่มีกำหนดเวลาถอน หรือสามารถถอนได้โดยสะดวก |
| เงินลงทุนชั่วคราว | หลักทรัพย์ที่กิจการถือไว้เพื่อเก็งกำไร หรือเพื่อแสวงหาผลตอบแทนจากเงินสดส่วนเกินในระยะสั้น |
| เงินสดย่อย | เงินสดจำนวนเล็กน้อยที่กิจการเก็บไว้เพื่อใช้จ่ายค่าใช้จ่ายเล็กๆ น้อยๆ ในการดำเนินงาน |
| เช็คลงวันที่ล่วงหน้า | เช็คที่ระบุวันที่ในอนาคต ทำให้ยังไม่สามารถนำไปขึ้นเงินได้ในปัจจุบัน |
| เช็คถึงกำหนดแล้ว | เช็คที่สามารถนำไปขึ้นเงินได้ทันที เนื่องจากถึงวันที่ระบุบนเช็คแล้ว |

## ตัวอย่างหรือขั้นตอน
ในการจัดทำงบฐานะการเงิน กิจการจะต้องจำแนกสินทรัพย์ออกเป็นประเภทต่างๆ โดยเรียงตามสภาพคล่อง ตัวอย่างสินทรัพย์หมุนเวียนที่สำคัญในบัญชีเบื้องต้น ได้แก่: 1. เงินสด (Cash): หมายถึง เหรียญกษาปณ์ ธนบัตร เช็คที่ครบกำหนดแล้ว (ไม่ใช่เช็คลงวันที่ล่วงหน้า) เช็คเดินทาง ดราฟต์ ธนาณัติ และเงินสดย่อย ซึ่งทั้งหมดนี้สามารถใช้จ่ายได้ทันที 2. เงินฝากธนาคาร (Cash at Bank or Bank Deposit): หมายถึง เงินฝากในสถาบันการเงินที่ไม่ใช่เงินฝากประจำ หรือเป็นเงินฝากที่ไม่มีกำหนดเงื่อนไขในการถอนเงินที่ทำให้ไม่สามารถถอนเงินสดออกมาใช้ได้โดยสะดวก มีสภาพคล่องรองลงมาจากเงินสด 3. เงินลงทุนชั่วคราว (Current Investment หรือ Short-term Investment): หมายถึง หลักทรัพย์ที่กิจการถือไว้เพื่อความต้องการของตลาดที่เก็งกำไร หรือเพื่อแสวงหาผลตอบแทนจากเงินสดที่เหลือใช้ เช่น การซื้อหุ้นหรือหุ้นกู้เพื่อหวังกำไรหรือเงินปันผล ซึ่งการเปลี่ยนเป็นเงินสดจะใช้เวลานานกว่าเงินสดและเงินฝากธนาคารเล็กน้อย (เช่น อาจใช้เวลา 3 วันในการซื้อขายและโอนเงิน) สินทรัพย์ทั้งสามประเภทนี้จัดเป็นสินทรัพย์หมุนเวียนเนื่องจากสามารถเปลี่ยนเป็นเงินสดหรือใช้หมดไปภายใน 1 ปี

## สรุปท้ายบท
งบฐานะการเงินเป็นเครื่องมือสำคัญที่ช่วยให้ผู้ใช้งบสามารถประเมินฐานะทางการเงินของกิจการได้ โดยแสดงให้เห็นถึงแหล่งที่มาของสินทรัพย์ (จากเจ้าของหรือจากการกู้ยืม) และการจัดสรรสินทรัพย์เหล่านั้นเพื่อการดำเนินงานและการลงทุน การทำความเข้าใจสมการบัญชี (สินทรัพย์ = หนี้สิน + ส่วนของเจ้าของ) และการจำแนกประเภทสินทรัพย์ โดยเฉพาะสินทรัพย์หมุนเวียนตามสภาพคล่อง เป็นพื้นฐานสำคัญในการวิเคราะห์และตีความข้อมูลทางการเงินของกิจการได้อย่างถูกต้อง

## คำถามทบทวน
1. งบฐานะการเงินมีชื่อเรียกอย่างไม่เป็นทางการว่าอะไร และเหตุใดจึงถูกเรียกว่าเช่นนั้น?
2. สมการบัญชีพื้นฐานที่แสดงความสัมพันธ์ขององค์ประกอบในงบฐานะการเงินคืออะไร และมีความหมายว่าอย่างไร?
3. สินทรัพย์ของกิจการมีที่มาจากแหล่งเงินทุนหลักกี่แหล่ง อะไรบ้าง จงอธิบายความสัมพันธ์ของแหล่งเงินทุนกับสินทรัพย์?
4. สินทรัพย์หมุนเวียนคืออะไร และมีลักษณะสำคัญอย่างไรในการจัดเรียงลำดับในงบฐานะการเงิน?
5. จงยกตัวอย่างสินทรัพย์หมุนเวียน 3 ประเภทแรกที่กล่าวถึงในบทเรียน พร้อมอธิบายลักษณะเฉพาะของแต่ละประเภท
