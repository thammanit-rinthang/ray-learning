# ความหมายวัตถุประสงค์และส่วนประกอบของงบการเงิน

## บทนำ
บทเรียนนี้เป็นบทแรกของการเรียนบัญชีที่เน้นเรื่องงบการเงิน แม้ว่าการจัดทำงบการเงินจะเป็นขั้นตอนสุดท้ายของกระบวนการทางบัญชี แต่การเรียนรู้เกี่ยวกับงบการเงินก่อนมีความสำคัญอย่างยิ่ง เพื่อให้ผู้เรียนเข้าใจถึงประเภทของรายการบัญชีต่างๆ เช่น สินทรัพย์ หนี้สิน รายได้ และค่าใช้จ่าย ซึ่งเป็นพื้นฐานสำคัญในการบันทึกบัญชีได้อย่างถูกต้อง เปรียบเสมือนการเรียนรู้พยัญชนะ ก-ฮ หรือ A-Z ก่อนที่จะสามารถอ่านและเขียนหนังสือได้ หากไม่มีความเข้าใจในชื่อบัญชีเหล่านี้ การบันทึกรายการบัญชีจะทำได้ยากและไม่ถูกต้อง ดังนั้น การทำความเข้าใจงบการเงินและชื่อบัญชีต่างๆ ที่ปรากฏในงบการเงินจึงเป็นสิ่งจำเป็นอันดับแรก

## วัตถุประสงค์
วัตถุประสงค์หลักของการจัดทำงบการเงินคือการนำเสนอข้อมูลทางการเงินที่เป็นประโยชน์ต่อผู้ใช้งบการเงิน โดยมีวัตถุประสงค์สำคัญ 4 ประการดังนี้: 1. เพื่อแสดงผลการดำเนินงานของกิจการ: ทำให้ผู้ใช้งบการเงินทราบถึงความสามารถในการทำกำไรหรือขาดทุนของกิจการในรอบระยะเวลาบัญชีหนึ่ง ซึ่งสะท้อนผ่านงบกำไรขาดทุน 2. เพื่อแสดงฐานะการเงินของกิจการ: ทำให้ผู้ใช้งบการเงินทราบถึงความมั่นคงทางการเงินของกิจการ ณ วันใดวันหนึ่ง โดยแสดงสินทรัพย์ หนี้สิน และส่วนของเจ้าของ ซึ่งสะท้อนผ่านงบแสดงฐานะการเงิน (หรือที่เรียกว่างบดุล) 3. เพื่อแสดงการเปลี่ยนแปลงในส่วนของเจ้าของ: ทำให้ผู้ใช้งบการเงินทราบถึงการเปลี่ยนแปลงของเงินทุนที่เจ้าของลงทุนไปว่าเพิ่มขึ้นหรือลดลงด้วยสาเหตุใดในช่วงเวลาหนึ่ง 4. เพื่อแสดงสภาพคล่องของกิจการ: ทำให้ผู้ใช้งบการเงินทราบถึงการเคลื่อนไหวของเงินสด ทั้งแหล่งที่มาและการใช้ไปของเงินสด เพื่อประเมินความสามารถในการชำระหนี้ ซึ่งสะท้อนผ่านงบกระแสเงินสด

## แนวคิดสำคัญ
งบการเงิน (Financial Statements) คือรายงานทางการเงินที่จัดทำขึ้นเพื่อแสดงข้อมูลเกี่ยวกับการดำเนินงาน ฐานะการเงิน การเปลี่ยนแปลงในส่วนของเจ้าของ และกระแสเงินสดของกิจการ โดยข้อมูลเหล่านี้จะประกอบด้วย สินทรัพย์ หนี้สิน และส่วนของเจ้าของ ตามมาตรฐานการบัญชี ฉบับที่ 1 เรื่องการนำเสนองบการเงิน กำหนดให้งบการเงินที่สมบูรณ์จะต้องประกอบด้วย 5 ส่วนหลัก ได้แก่ 1. งบฐานะการเงิน (Statement of Financial Position): แสดงสินทรัพย์ หนี้สิน และส่วนของเจ้าของ ณ วันใดวันหนึ่ง 2. งบกำไรขาดทุนและกำไรขาดทุนเบ็ดเสร็จอื่น (Statement of Profit or Loss and Other Comprehensive Income): แสดงผลการดำเนินงาน รายได้ ค่าใช้จ่าย กำไรหรือขาดทุนสุทธิ และกำไรขาดทุนเบ็ดเสร็จอื่นในรอบระยะเวลาบัญชีหนึ่ง 3. งบแสดงการเปลี่ยนแปลงส่วนของเจ้าของ (Statement of Changes in Owner's Equity): แสดงการเปลี่ยนแปลงในส่วนของเจ้าของที่เกิดขึ้นในระหว่างงวดบัญชี 4. งบกระแสเงินสด (Statement of Cash Flow): แสดงการเคลื่อนไหวของเงินสด ทั้งแหล่งที่มาและการใช้ไปของเงินสด 5. หมายเหตุประกอบงบการเงิน (Notes to Financial Statements): ให้รายละเอียดเพิ่มเติมเกี่ยวกับรายการต่างๆ ในงบการเงิน นโยบายการบัญชี และข้อมูลประกอบอื่นๆ เพื่อให้ผู้ใช้งบการเงินมีความเข้าใจที่ลึกซึ้งยิ่งขึ้น อย่างไรก็ตาม สำหรับการเรียนบัญชีเบื้องต้น จะเน้นการเรียนรู้เพียง 3 งบการเงินหลัก ได้แก่ งบฐานะการเงิน งบกำไรขาดทุน (โดยยังไม่รวมกำไรขาดทุนเบ็ดเสร็จอื่น) และงบแสดงการเปลี่ยนแปลงส่วนของเจ้าของ ส่วนงบกระแสเงินสดและหมายเหตุประกอบงบการเงินจะถูกศึกษาในระดับที่สูงขึ้นต่อไป

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| งบการเงิน | รายงานทางการเงินที่แสดงข้อมูลเกี่ยวกับการดำเนินงาน ฐานะการเงิน การเปลี่ยนแปลงในส่วนของเจ้าของ และกระแสเงินสดของกิจการ |
| ผลการดำเนินงาน | ผลลัพธ์จากการดำเนินงานของกิจการในรอบระยะเวลาบัญชีหนึ่ง ซึ่งแสดงถึงกำไรหรือขาดทุน |
| ฐานะการเงิน | สถานะทางการเงินของกิจการ ณ วันใดวันหนึ่ง ซึ่งประกอบด้วย สินทรัพย์ หนี้สิน และส่วนของเจ้าของ |
| ส่วนของเจ้าของ | ส่วนที่เหลือของสินทรัพย์หลังจากหักหนี้สินทั้งหมดออกไป ซึ่งเป็นส่วนของผู้ลงทุนในกิจการ |
| สภาพคล่อง | ความสามารถของกิจการในการเปลี่ยนสินทรัพย์เป็นเงินสดเพื่อชำระหนี้สินระยะสั้น |
| กระแสเงินสด | การเคลื่อนไหวของเงินสดเข้าและออกจากกิจการในรอบระยะเวลาบัญชีหนึ่ง |
| งบฐานะการเงิน | งบการเงินที่แสดงสินทรัพย์ หนี้สิน และส่วนของเจ้าของของกิจการ ณ วันใดวันหนึ่ง |
| งบกำไรขาดทุน | งบการเงินที่แสดงรายได้ ค่าใช้จ่าย และผลกำไรหรือขาดทุนสุทธิของกิจการในรอบระยะเวลาบัญชีหนึ่ง |
| งบกำไรขาดทุนเบ็ดเสร็จอื่น | รายการรายได้และค่าใช้จ่ายที่ไม่ได้รวมอยู่ในกำไรหรือขาดทุนสุทธิ แต่รับรู้โดยตรงในส่วนของเจ้าของ |
| งบแสดงการเปลี่ยนแปลงส่วนของเจ้าของ | งบการเงินที่แสดงการเปลี่ยนแปลงในส่วนของเจ้าของที่เกิดขึ้นในระหว่างงวดบัญชี |
| งบกระแสเงินสด | งบการเงินที่แสดงแหล่งที่มาและการใช้ไปของเงินสดของกิจการในรอบระยะเวลาบัญชีหนึ่ง |
| หมายเหตุประกอบงบการเงิน | ส่วนที่ให้รายละเอียดเพิ่มเติมเกี่ยวกับรายการต่างๆ ในงบการเงิน นโยบายการบัญชี และข้อมูลประกอบอื่นๆ |
| มาตรฐานการบัญชี ฉบับที่ 1 | มาตรฐานที่กำหนดหลักเกณฑ์ในการนำเสนองบการเงินเพื่อให้ข้อมูลมีประโยชน์และเปรียบเทียบกันได้ |
| งบดุล | ชื่อเรียกเดิมของงบแสดงฐานะการเงิน |
| เกณฑ์คงค้าง | หลักการบัญชีที่บันทึกรายได้และค่าใช้จ่ายเมื่อเกิดขึ้น โดยไม่คำนึงถึงการรับหรือจ่ายเงินสด |

## ตัวอย่างหรือขั้นตอน
ในการศึกษาและทำความเข้าใจงบการเงิน ผู้สอนได้ยกตัวอย่างการค้นหาและดูงบการเงินจริงของบริษัทจดทะเบียน โดยแสดงให้เห็นถึงรายงานประจำปีของบริษัทขนาดใหญ่ เช่น โรงพยาบาล BMS (Bangkok Dusit Medical Services) ซึ่งสามารถเข้าถึงข้อมูลได้ง่ายผ่านเว็บไซต์ต่างๆ เช่น เว็บไซต์ตลาดหลักทรัพย์ฯ หรือเว็บไซต์ของบริษัทเอง เมื่อเปิดดูงบการเงินของบริษัทเหล่านี้ จะพบว่าประกอบด้วยงบการเงินหลัก 5 ส่วนตามมาตรฐานการบัญชี ได้แก่ งบฐานะการเงิน งบกำไรขาดทุน งบแสดงการเปลี่ยนแปลงส่วนของผู้ถือหุ้น งบกระแสเงินสด และที่สำคัญคือ หมายเหตุประกอบงบการเงิน ซึ่งให้รายละเอียดเพิ่มเติมของตัวเลขต่างๆ ในงบการเงิน เช่น รายละเอียดของลูกหนี้การค้า หรือนโยบายการบัญชีที่ใช้ ตัวอย่างที่แสดงให้เห็นว่างบการเงินจริงมีความซับซ้อนและมีรายละเอียดมาก โดยเฉพาะในบริษัทขนาดใหญ่ที่อาจมีงบการเงินรวม (Consolidated Financial Statements) ซึ่งจะมีการเรียนรู้ในระดับสูงขึ้น อย่างไรก็ตาม สำหรับบัญชีเบื้องต้น จะเน้นการเรียนรู้และทำความเข้าใจงบการเงินพื้นฐาน 3 ประเภทก่อน เพื่อสร้างความเข้าใจในหลักการเบื้องต้น

## สรุปท้ายบท
งบการเงินเป็นเครื่องมือสำคัญที่ให้ข้อมูลทางการเงินที่จำเป็นต่อการตัดสินใจของผู้ใช้งบการเงิน ทั้งภายในและภายนอกองค์กร การทำความเข้าใจงบการเงินตั้งแต่เริ่มต้นจะช่วยให้สามารถบันทึกบัญชีได้อย่างถูกต้องและมีประสิทธิภาพ งบการเงินที่สมบูรณ์ตามมาตรฐานการบัญชีประกอบด้วย 5 ส่วนหลัก ได้แก่ งบฐานะการเงิน งบกำไรขาดทุนและกำไรขาดทุนเบ็ดเสร็จอื่น งบแสดงการเปลี่ยนแปลงส่วนของเจ้าของ งบกระแสเงินสด และหมายเหตุประกอบงบการเงิน ซึ่งแต่ละส่วนมีวัตถุประสงค์ในการนำเสนอข้อมูลที่แตกต่างกัน เช่น ผลการดำเนินงาน ฐานะการเงิน การเปลี่ยนแปลงในส่วนของเจ้าของ และสภาพคล่องของกิจการ สำหรับการเรียนบัญชีเบื้องต้น จะเน้นการทำความเข้าใจ 3 งบการเงินหลัก ได้แก่ งบฐานะการเงิน งบกำไรขาดทุน และงบแสดงการเปลี่ยนแปลงส่วนของเจ้าของ เพื่อเป็นรากฐานที่แข็งแกร่งก่อนที่จะศึกษาในรายละเอียดที่ซับซ้อนขึ้นในระดับกลางและระดับสูงต่อไป

## คำถามทบทวน
1. เหตุใดการเรียนรู้เกี่ยวกับงบการเงินจึงมีความสำคัญเป็นอันดับแรกในการศึกษาบัญชี แม้ว่าจะเป็นขั้นตอนสุดท้ายของการทำบัญชี?
2. วัตถุประสงค์หลัก 4 ประการของการจัดทำงบการเงินมีอะไรบ้าง และแต่ละวัตถุประสงค์เกี่ยวข้องกับงบการเงินประเภทใด?
3. ตามมาตรฐานการบัญชี ฉบับที่ 1 งบการเงินที่สมบูรณ์ประกอบด้วยส่วนประกอบหลักกี่ส่วน อะไรบ้าง?
4. สำหรับบัญชีเบื้องต้น เราจะเน้นการเรียนรู้และทำความเข้าใจงบการเงินประเภทใดบ้าง และเหตุใดจึงยังไม่รวมงบการเงินบางประเภท?
5. หมายเหตุประกอบงบการเงินมีความสำคัญอย่างไรในการทำความเข้าใจข้อมูลทางการเงินของกิจการ?
