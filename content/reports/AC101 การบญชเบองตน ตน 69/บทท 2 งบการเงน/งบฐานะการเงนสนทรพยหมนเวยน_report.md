# งบฐานะการเงินสินทรัพย์หมุนเวียน

## บทนำ
บทเรียนนี้มุ่งเน้นไปที่การทำความเข้าใจสินทรัพย์หมุนเวียนในงบฐานะการเงิน โดยเฉพาะอย่างยิ่งลูกหนี้การค้าและตั๋วเงินรับ ซึ่งเป็นสินทรัพย์ที่เกิดจากการดำเนินงานปกติของกิจการ การทำความเข้าใจสินทรัพย์เหล่านี้มีความสำคัญอย่างยิ่งต่อการประเมินสถานะทางการเงินและความสามารถในการดำเนินงานของบริษัท บทเรียนจะอธิบายถึงลักษณะของสินทรัพย์แต่ละประเภท วิธีการรับรู้ทางบัญชี รวมถึงความเสี่ยงที่เกี่ยวข้องและการปรับปรุงทางบัญชีที่จำเป็นเพื่อให้ข้อมูลทางการเงินมีความน่าเชื่อถือและสะท้อนความเป็นจริงมากที่สุด

## วัตถุประสงค์
วัตถุประสงค์ของบทเรียนนี้คือเพื่อให้ผู้เรียนสามารถ: 1. เข้าใจความหมายและที่มาของลูกหนี้การค้าและตั๋วเงินรับในฐานะสินทรัพย์หมุนเวียน 2. อธิบายหลักการบัญชีในการแสดงมูลค่าลูกหนี้การค้าสุทธิ โดยเฉพาะอย่างยิ่งการตั้งค่าเผื่อหนี้สงสัยจะสูญ 3. เข้าใจถึงความสำคัญของหลักความระมัดระวังในการบันทึกบัญชีสินทรัพย์ที่มีความเสี่ยง 4. เปรียบเทียบความแตกต่างและระดับความมีสภาพคล่องของลูกหนี้การค้าและตั๋วเงินรับกับสินทรัพย์หมุนเวียนประเภทอื่น ๆ 5. สามารถระบุและจัดลำดับสินทรัพย์หมุนเวียนตามสภาพคล่องได้

## แนวคิดสำคัญ
สินทรัพย์คือทรัพยากรที่กิจการเป็นเจ้าของ มีมูลค่าที่สามารถวัดเป็นตัวเงินได้ ไม่ว่าจะมีตัวตนหรือไม่ก็ตาม ลูกหนี้การค้า (Accounts Receivable) เกิดจากการที่กิจการขายสินค้าหรือให้บริการเป็นเงินเชื่อ โดยที่ลูกค้ายังไม่ได้ชำระเงินในทันที แต่ได้เซ็นรับสินค้าหรือบริการแล้ว ทำให้เกิดสิทธิเรียกร้องให้ลูกค้าชำระเงินในอนาคต ลูกหนี้การค้ามีความเสี่ยงที่ลูกค้าบางรายอาจไม่สามารถชำระเงินได้ ซึ่งเรียกว่า หนี้สูญ (Bad Debt) ดังนั้น ตามหลักความระมัดระวัง (Principle of Conservatism) กิจการจะต้องแสดงลูกหนี้การค้าด้วยยอดสุทธิ โดยการหักค่าเผื่อหนี้สงสัยจะสูญ (Allowance for Doubtful Accounts) ออกจากยอดลูกหนี้การค้าทั้งหมด ค่าเผื่อหนี้สงสัยจะสูญเป็นบัญชีปรับมูลค่า (Valuation Account) ที่ใช้ประมาณการจำนวนลูกหนี้ที่คาดว่าจะเรียกเก็บไม่ได้ โดยอาศัยประสบการณ์ในอดีตหรือการพิจารณาสภาวะเศรษฐกิจ ตั๋วเงินรับ (Notes Receivable) เป็นสินทรัพย์ที่คล้ายกับลูกหนี้การค้า แต่มีความเป็นทางการมากกว่าเนื่องจากเป็นสัญญาที่ทำเป็นลายลักษณ์อักษร ซึ่งมักจะระบุเงื่อนไขการชำระเงินและดอกเบี้ยไว้อย่างชัดเจน ตั๋วเงินรับมีความเสี่ยงในการเรียกเก็บเงินต่ำกว่าลูกหนี้การค้าทั่วไป เนื่องจากมักจะมีการค้ำประกันหรือผ่านสถาบันการเงิน ทำให้ไม่จำเป็นต้องตั้งค่าเผื่อหนี้สงสัยจะสูญ สินทรัพย์หมุนเวียนจะถูกจัดเรียงตามลำดับความมีสภาพคล่อง โดยเงินสดและเงินฝากธนาคารจะมีความสภาพคล่องสูงสุด ตามมาด้วยเงินลงทุนชั่วคราว ลูกหนี้การค้า และตั๋วเงินรับตามลำดับ เนื่องจากลูกหนี้การค้าและตั๋วเงินรับต้องรอให้ครบกำหนดชำระจึงจะเปลี่ยนเป็นเงินสดได้

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| สินทรัพย์ | ทรัพยากรที่กิจการเป็นเจ้าของ มีมูลค่าที่สามารถวัดเป็นตัวเงินได้ ไม่ว่าจะมีตัวตนหรือไม่ก็ตาม |
| ลูกหนี้การค้า (Accounts Receivable) | สิทธิเรียกร้องที่กิจการมีเหนือบุคคลอื่นที่เกิดจากการขายสินค้าหรือบริการเป็นเงินเชื่อ |
| ค่าเผื่อหนี้สงสัยจะสูญ (Allowance for Doubtful Accounts) | บัญชีปรับมูลค่าที่ใช้ประมาณการจำนวนลูกหนี้ที่คาดว่าจะเรียกเก็บเงินไม่ได้ โดยอาศัยประสบการณ์ในอดีตหรือการพิจารณาสภาวะเศรษฐกิจ |
| ลูกหนี้การค้า-สุทธิ (Accounts Receivable - Net) | มูลค่าของลูกหนี้การค้าที่แสดงในงบการเงินหลังจากหักค่าเผื่อหนี้สงสัยจะสูญแล้ว |
| ตั๋วเงินรับ (Notes Receivable) | สัญญาที่ทำเป็นลายลักษณ์อักษร ซึ่งบ่งบอกว่าผู้ที่จะได้รับเงินและออกเบี้ย (ถ้ามี) เมื่อสัญญาดังกล่าวครบกำหนด โดยระยะเวลาของสัญญาจะต้องไม่เกินหนึ่งงวดบัญชี (1 ปี) |
| หนี้สูญ (Bad Debt) | ลูกหนี้ที่กิจการไม่สามารถเรียกเก็บเงินได้ |
| หลักความระมัดระวัง (Principle of Conservatism) | หลักการบัญชีที่ระบุว่าหากสินทรัพย์มีโอกาสที่จะลดลง ควรแสดงด้วยยอดสุทธิหรือมูลค่าที่ต่ำกว่า เพื่อป้องกันการแสดงกำไรหรือสินทรัพย์สูงเกินจริง |
| สิทธิเรียกร้องเหนือบุคคลอื่น | สิทธิที่กิจการมีในการเรียกเก็บเงินหรือทรัพย์สินจากบุคคลอื่น |
| บัญชีปรับมูลค่า | บัญชีที่ใช้เพื่อปรับมูลค่าของสินทรัพย์หรือหนี้สินให้สะท้อนมูลค่าที่แท้จริงหรือคาดการณ์ได้ |
| เงินสด (Cash) | เงินเหรียญ หรือธนบัตร หรือเช็คที่ยังไม่นำฝาก |
| เงินฝากธนาคาร (Cash at Bank or Bank Deposit) | เงินฝากในสถาบันการเงินที่ไม่ได้ฝากประจำ หรือเป็นเงินฝากที่มีกำหนดเงื่อนไขในการถอนเงินที่ทำให้ไม่สามารถถอนเงินออกมาใช้ได้โดยสะดวก |
| เงินลงทุนชั่วคราว (Current Investment / Short-term Investment) | หลักทรัพย์ในความต้องการของตลาดที่กิจการซื้อมาเพื่อการลงทุนระยะสั้น และเปลี่ยนเป็นเงินสดได้ทันทีที่ต้องการ |
| สินค้าคงเหลือ (Inventory) | สินทรัพย์ที่กิจการถือครองหรือผลิตขึ้นมาเพื่อขาย รวมถึงวัตถุดิบหรือวัสดุที่ใช้เพื่อผลิตสินค้าหรือให้บริการ หรืออยู่ในระหว่างกระบวนการผลิต |
| ลูกหนี้อื่น (Others Receivable) | ลูกหนี้ที่ไม่ได้เกิดจากการขายสินค้าหรือบริการเป็นเงินเชื่อ เช่น ลูกหนี้จากการให้บุคคลอื่นยืมเงิน |

## ตัวอย่างหรือขั้นตอน
1.  **การเกิดลูกหนี้การค้า**: เมื่อกิจการขายสินค้าหรือให้บริการเป็นเงินเชื่อ ลูกค้าจะเซ็นรับสินค้าหรือบริการ แต่ยังไม่ได้ชำระเงินทันที เช่น การขายสินค้ามูลค่า 20,000 บาท โดยลูกค้ายังไม่จ่ายเงินแต่เซ็นรับสินค้าแล้ว ถือเป็นการสร้างสิทธิเรียกร้องให้กิจการสามารถเรียกเก็บเงินจากลูกค้าได้ในอนาคต ซึ่งเป็นไปตามคำนิยามของสินทรัพย์ 2.  **ลูกหนี้ในภาคธนาคาร**: การใช้บัตรเครดิตก็เป็นตัวอย่างหนึ่งของลูกหนี้การค้า โดยผู้ใช้บัตรเป็นลูกหนี้ของธนาคาร และธนาคารมีสิทธิเรียกร้องให้ผู้ใช้บัตรชำระเงินคืน 3.  **การแสดงลูกหนี้การค้าสุทธิ**: ในงบการเงิน ลูกหนี้การค้าจะแสดงด้วยยอดสุทธิ โดยมีวิธีการคำนวณดังนี้: ลูกหนี้การค้า-สุทธิ = ลูกหนี้การค้า - หัก ค่าเผื่อหนี้สงสัยจะสูญ 4.  **การประมาณค่าเผื่อหนี้สงสัยจะสูญ**: กิจการต้องประมาณการจำนวนลูกหนี้ที่คาดว่าจะเรียกเก็บไม่ได้ โดยอาศัยประสบการณ์ในอดีต เช่น หากปีที่แล้วมีลูกหนี้ 100 บาท และเก็บได้ 97 บาท แสดงว่ามี 3% ที่ไม่สามารถเก็บได้ ดังนั้นในปีปัจจุบันก็ควรตั้งค่าเผื่อหนี้สงสัยจะสูญไว้ที่ 3% หรืออาจปรับอัตราตามสภาวะเศรษฐกิจที่เปลี่ยนแปลงไป 5.  **การใช้ตั๋วเงินรับ**: ในกรณีที่กิจการเพิ่งเริ่มทำธุรกิจกับลูกค้ารายใหม่และยังไม่มีความเชื่อใจกันมากพอ กิจการอาจขอให้ลูกค้าซื้อเป็นตั๋วสัญญาใช้เงินจากธนาคารมาให้ ซึ่งจะมีความมั่นคงในการเรียกเก็บเงินมากกว่าลูกหนี้การค้าทั่วไป เนื่องจากตั๋วเงินรับมีกำหนดระยะเวลาที่ชัดเจนและมีบทลงโทษ (เช่น ดอกเบี้ย) หากไม่ชำระตามกำหนด 6.  **ลำดับความมีสภาพคล่อง**: สินทรัพย์หมุนเวียนจะถูกจัดเรียงตามความสามารถในการเปลี่ยนเป็นเงินสดได้เร็วที่สุด โดยมีลำดับดังนี้: เงินสด, เงินฝากธนาคาร, เงินลงทุนชั่วคราว, ลูกหนี้การค้า, และตั๋วเงินรับ ลูกหนี้การค้าและตั๋วเงินรับจะอยู่ท้ายๆ เนื่องจากต้องรอให้ครบกำหนดชำระตามเงื่อนไขเครดิต (เช่น 30, 60, 90 วัน) จึงจะสามารถเปลี่ยนเป็นเงินสดได้

## สรุปท้ายบท
การทำความเข้าใจสินทรัพย์หมุนเวียน โดยเฉพาะลูกหนี้การค้าและตั๋วเงินรับ เป็นสิ่งสำคัญในการวิเคราะห์งบฐานะการเงิน ลูกหนี้การค้าเกิดจากการขายเชื่อและมีความเสี่ยงที่จะไม่สามารถเรียกเก็บได้ทั้งหมด จึงต้องมีการตั้งค่าเผื่อหนี้สงสัยจะสูญตามหลักความระมัดระวัง เพื่อให้งบการเงินแสดงฐานะที่แท้จริงและไม่สูงเกินจริง ในขณะที่ตั๋วเงินรับมีความมั่นคงกว่าเนื่องจากเป็นสัญญาที่เป็นลายลักษณ์อักษรและมีเงื่อนไขที่ชัดเจน สินทรัพย์เหล่านี้มีความแตกต่างกันในด้านสภาพคล่องและระดับความเสี่ยง การจัดการและการแสดงผลที่ถูกต้องตามหลักการบัญชีจึงเป็นหัวใจสำคัญของการนำเสนอข้อมูลทางการเงินที่น่าเชื่อถือ

## คำถามทบทวน
1. ลูกหนี้การค้าเกิดจากสาเหตุใด และเหตุใดจึงถือเป็นสินทรัพย์ของกิจการ?
2. อธิบายความหมายและวัตถุประสงค์ของการตั้งค่าเผื่อหนี้สงสัยจะสูญ และเกี่ยวข้องกับหลักการบัญชีใด?
3. ตั๋วเงินรับแตกต่างจากลูกหนี้การค้าอย่างไร และเหตุใดจึงมีความเสี่ยงในการเรียกเก็บเงินต่ำกว่า?
4. หากกิจการมีลูกหนี้การค้า 1,000,000 บาท และประมาณการว่าจะมีลูกหนี้ที่ไม่สามารถเก็บได้ 5% กิจการควรแสดงลูกหนี้การค้าสุทธิในงบการเงินเป็นจำนวนเท่าใด?
5. จงเรียงลำดับสินทรัพย์หมุนเวียนต่อไปนี้ตามความมีสภาพคล่องจากมากไปน้อย: เงินฝากธนาคาร, ลูกหนี้การค้า, เงินสด, ตั๋วเงินรับ, เงินลงทุนชั่วคราว
