# งบการเปลี่ยนแปลงและงบฐานะการเงิน

## บทนำ
บทเรียนนี้มุ่งเน้นการทบทวนและทำความเข้าใจเกี่ยวกับงบการเงินที่สำคัญสองประเภท ได้แก่ งบการเปลี่ยนแปลงส่วนของเจ้าของ (งบการเปลี่ยนแปลงฐานะ) และงบฐานะการเงิน (งบดุล) โดยเฉพาะอย่างยิ่งการจัดทำส่วนของหนี้สินและส่วนของเจ้าของในงบฐานะการเงิน ซึ่งเป็นองค์ประกอบสำคัญที่สะท้อนถึงแหล่งที่มาของเงินทุนของกิจการ และความมั่นคงทางการเงินในภาพรวม การทำความเข้าใจงบการเงินเหล่านี้จะช่วยให้นักศึกษาสามารถจำชื่อบัญชีและนำไปใช้ในการบันทึกบัญชีได้อย่างถูกต้อง

## วัตถุประสงค์
1. เพื่อให้ผู้เรียนเข้าใจโครงสร้างและองค์ประกอบของงบฐานะการเงิน โดยเฉพาะส่วนของหนี้สินและส่วนของเจ้าของ 2. เพื่อให้ผู้เรียนสามารถจำแนกประเภทของหนี้สินออกเป็นหนี้สินหมุนเวียนและหนี้สินไม่หมุนเวียนได้ 3. เพื่อให้ผู้เรียนสามารถคำนวณและแสดงยอดรวมของหนี้สินและส่วนของเจ้าของในงบฐานะการเงินได้อย่างถูกต้อง 4. เพื่อให้ผู้เรียนเข้าใจหลักการดุลกันของงบฐานะการเงินที่ว่า 'สินทรัพย์รวม = หนี้สินรวม + ส่วนของเจ้าของ' 5. เพื่อให้ผู้เรียนสามารถนำข้อมูลจากงบการเปลี่ยนแปลงส่วนของเจ้าของมาใช้ในการจัดทำงบฐานะการเงินได้

## แนวคิดสำคัญ
งบฐานะการเงิน (Statement of Financial Position) หรือที่รู้จักกันในชื่อเดิมว่า งบดุล (Balance Sheet) คือรายงานทางการเงินที่แสดงฐานะทางการเงินของกิจการ ณ วันใดวันหนึ่ง ประกอบด้วย สินทรัพย์ หนี้สิน และส่วนของเจ้าของ โดยยึดตามสมการบัญชี: สินทรัพย์ = หนี้สิน + ส่วนของเจ้าของ

หนี้สิน (Liabilities) คือ ภาระผูกพันของกิจการที่ต้องชำระคืนในอนาคต แบ่งออกเป็น:
- หนี้สินหมุนเวียน (Current Liabilities): หนี้สินที่คาดว่าจะชำระคืนภายในหนึ่งปี หรือภายในรอบระยะเวลาดำเนินงานปกติของกิจการ เช่น เจ้าหนี้การค้า ภาษีเงินได้ค้างจ่าย
- หนี้สินไม่หมุนเวียน (Non-current Liabilities): หนี้สินที่คาดว่าจะชำระคืนเกินกว่าหนึ่งปี หรือเกินกว่ารอบระยะเวลาดำเนินงานปกติของกิจการ เช่น เงินกู้ระยะยาว

ส่วนของเจ้าของ (Owner's Equity) คือ ส่วนที่เหลือของสินทรัพย์หลังจากหักหนี้สินทั้งหมดออกไปแล้ว ซึ่งแสดงถึงสิทธิเรียกร้องของเจ้าของในสินทรัพย์ของกิจการ โดยยอดทุนปลายงวดจะถูกนำมาจากงบการเปลี่ยนแปลงส่วนของเจ้าของ

| งบการเปลี่ยนแปลงส่วนของเจ้าของ | Statement of Changes in Equity รายงานที่แสดงการเปลี่ยนแปลงในส่วนของเจ้าของในช่วงเวลาหนึ่ง |
| หนี้สิน | Liabilities ภาระผูกพันของกิจการที่ต้องชำระคืนในอนาคต |
| หนี้สินหมุนเวียน | Current Liabilities หนี้สินที่ต้องชำระคืนภายในหนึ่งปี |
| หนี้สินไม่หมุนเวียน | Non-current Liabilities หนี้สินที่ต้องชำระคืนเกินกว่าหนึ่งปี |
| เจ้าหนี้การค้า | Accounts Payable เงินที่กิจการค้างชำระค่าสินค้าหรือบริการแก่ผู้ขาย |
| ภาษีเงินได้ค้างจ่าย | Income Tax Payable ภาษีเงินได้ที่กิจการมีภาระต้องจ่ายแต่ยังไม่ได้จ่าย |
| เงินกู้ระยะยาว | Long-term Loan เงินกู้ที่ต้องชำระคืนในระยะเวลาเกินกว่าหนึ่งปี |

| สินทรัพย์ | Assets ทรัพยากรที่กิจการควบคุมและคาดว่าจะได้รับประโยชน์เชิงเศรษฐกิจในอนาคต |
| สินทรัพย์หมุนเวียน | Current Assets สินทรัพย์ที่คาดว่าจะเปลี่ยนเป็นเงินสดหรือใช้หมดไปภายในหนึ่งปี |
| สินทรัพย์ไม่หมุนเวียน | Non-current Assets สินทรัพย์ที่มีอายุการใช้งานเกินกว่าหนึ่งปี |

## ตัวอย่างหรือขั้นตอน
การจัดทำงบฐานะการเงินสำหรับร้านนักซ่อม ณ วันที่ 31 ธันวาคม 25x1 (หน่วย: บาท) โดยเน้นที่ส่วนของหนี้สินและส่วนของเจ้าของ:

**1. หนี้สิน (Liabilities)**
   **1.1 หนี้สินหมุนเวียน (Current Liabilities)**
       *   เจ้าหนี้การค้า (Accounts Payable): 47,000 บาท
       *   ภาษีเงินได้ค้างจ่าย (Income Tax Payable): 38,000 บาท
       *   **รวมหนี้สินหมุนเวียน**: 47,000 + 38,000 = 85,000 บาท

   **1.2 หนี้สินไม่หมุนเวียน (Non-current Liabilities)**
       *   เงินกู้ระยะยาว (Long-term Loan): 200,000 บาท
       *   **รวมหนี้สินไม่หมุนเวียน**: 200,000 บาท

   **1.3 รวมหนี้สินทั้งหมด (Total Liabilities)**
       *   รวมหนี้สินหมุนเวียน + รวมหนี้สินไม่หมุนเวียน = 85,000 + 200,000 = 285,000 บาท

**2. ส่วนของผู้เป็นเจ้าของ (Owner's Equity)**
   *   ทุน-นายซ่อมเก่ง (Capital - Mr. Somkeng): 1,056,600 บาท (ยอดนี้ได้มาจากการหยิบยอดทุนปลายงวดจากงบการเปลี่ยนแปลงส่วนของเจ้าของ)

**3. รวมหนี้สินและส่วนของผู้เป็นเจ้าของ (Total Liabilities and Owner's Equity)**
   *   รวมหนี้สินทั้งหมด + ทุน-นายซ่อมเก่ง = 285,000 + 1,056,600 = 1,341,600 บาท

**การตรวจสอบความสมดุล:**
ยอดรวมหนี้สินและส่วนของผู้เป็นเจ้าของ (1,341,600 บาท) จะต้องเท่ากับยอดรวมสินทรัพย์ (Total Assets) ซึ่งในกรณีนี้คือ 1,341,600 บาท แสดงให้เห็นว่างบฐานะการเงินมีความสมดุลกันตามหลักการบัญชี

## สรุปท้ายบท
งบฐานะการเงินเป็นเครื่องมือสำคัญในการประเมินความมั่นคงทางการเงินของกิจการ ณ จุดเวลาใดเวลาหนึ่ง โดยแสดงให้เห็นว่ากิจการมีสินทรัพย์อะไรบ้าง และสินทรัพย์เหล่านั้นมาจากแหล่งใด (หนี้สินหรือส่วนของเจ้าของ) การที่ยอดรวมหนี้สินและส่วนของเจ้าของเท่ากับยอดรวมสินทรัพย์เป็นหลักการพื้นฐานที่สำคัญที่สุดของงบนี้ ซึ่งสะท้อนถึงสมการบัญชีที่สมดุล การวิเคราะห์สัดส่วนหนี้สินต่อสินทรัพย์สามารถบ่งบอกถึงความเสี่ยงและความมั่นคงของกิจการได้ เช่น ในตัวอย่างนี้ หนี้สินมีสัดส่วนน้อยกว่า 20% ของสินทรัพย์รวม ซึ่งแสดงถึงความมั่นคงในระดับที่ดี นอกจากนี้ การจัดทำงบฐานะการเงินยังต้องอาศัยข้อมูลจากงบการเงินอื่น ๆ โดยเฉพาะยอดทุนปลายงวดจากงบการเปลี่ยนแปลงส่วนของเจ้าของ เพื่อให้ข้อมูลมีความครบถ้วนและถูกต้อง

## คำถามทบทวน
1. งบฐานะการเงินมีชื่อเรียกอีกอย่างหนึ่งว่าอะไร และแสดงข้อมูลอะไรบ้าง?
2. หนี้สินในงบฐานะการเงินแบ่งออกเป็นกี่ประเภท อะไรบ้าง และแต่ละประเภทมีความหมายอย่างไร?
3. ในตัวอย่างของร้านนักซ่อม ยอดรวมหนี้สินหมุนเวียนและหนี้สินไม่หมุนเวียนมีจำนวนเท่าใด?
4. ยอดทุนของนายซ่อมเก่งในส่วนของเจ้าของของงบฐานะการเงินได้มาจากงบการเงินใด?
5. หลักการสำคัญที่แสดงถึงความสมดุลของงบฐานะการเงินคืออะไร และมีความสำคัญอย่างไร?
