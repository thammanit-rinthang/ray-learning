# ร้านนักซ่อม

## บทนำ
บทเรียนนี้กล่าวถึง 'ร้านนักซ่อม' ซึ่งเป็นธุรกิจบริการรับซ่อมรถยนต์ โดยมีนายซ่อมเก่งเป็นเจ้าของกิจการ ณ วันที่ 31 ธันวาคม ซึ่งเป็นวันปิดบัญชีสำหรับงวดเวลา 1 ปี กิจการมีรายการบัญชีต่างๆ ที่ต้องนำมาจัดทำงบการเงิน เพื่อให้ทราบผลการดำเนินงาน ฐานะการเงิน และการเปลี่ยนแปลงส่วนของเจ้าของ โดยเน้นย้ำถึงความสำคัญของการจัดประเภทบัญชีที่ถูกต้องแม่นยำ ซึ่งเป็นพื้นฐานสำคัญของการทำบัญชีตั้งแต่ระดับต้นจนถึงระดับสูง

## วัตถุประสงค์
1. เพื่อให้ผู้เรียนสามารถจัดทำงบกำไรขาดทุนเพื่อทราบกำไรสุทธิของกิจการได้ 2. เพื่อให้ผู้เรียนสามารถจัดทำงบแสดงการเปลี่ยนแปลงส่วนของผู้เป็นเจ้าของ เพื่อแสดงการเปลี่ยนแปลงของทุนว่าเพิ่มขึ้นหรือลดลง 3. เพื่อให้ผู้เรียนสามารถจัดทำงบฐานะการเงินเพื่อสรุปฐานะของกิจการได้ 4. เพื่อให้ผู้เรียนเข้าใจหลักการจัดประเภทบัญชีต่างๆ ทั้งสินทรัพย์ หนี้สิน ส่วนของเจ้าของ รายได้ และค่าใช้จ่าย 5. เพื่อให้ผู้เรียนตระหนักถึงความสำคัญของความรู้พื้นฐานทางบัญชีในการตรวจสอบและจัดทำงบการเงิน แม้จะมีการใช้โปรแกรมคอมพิวเตอร์ช่วยก็ตาม

## แนวคิดสำคัญ
1. **งบการเงินหลัก 3 ประเภท:** ประกอบด้วย งบกำไรขาดทุน (Income Statement), งบแสดงการเปลี่ยนแปลงส่วนของผู้เป็นเจ้าของ (Statement of Changes in Owner's Equity) และงบฐานะการเงิน (Balance Sheet) ซึ่งเป็นเครื่องมือสำคัญในการรายงานผลการดำเนินงานและฐานะทางการเงินของกิจการ 2. **การจัดประเภทบัญชี:** การจำแนกรายการบัญชีต่างๆ ออกเป็นหมวดหมู่หลัก ได้แก่ สินทรัพย์ (Assets), หนี้สิน (Liabilities), ส่วนของเจ้าของ (Owner's Equity), รายได้ (Revenues) และค่าใช้จ่าย (Expenses) ซึ่งเป็นขั้นตอนแรกที่สำคัญในการจัดทำงบการเงิน 3. **หลักการคำนวณกำไรสุทธิ:** กำไรสุทธิคำนวณจาก รายได้หักด้วยค่าใช้จ่ายทั้งหมด 4. **การเปลี่ยนแปลงส่วนของเจ้าของ:** ทุนของเจ้าของจะเพิ่มขึ้นจากกำไรสุทธิและลดลงจากการถอนใช้ส่วนตัว 5. **สมการบัญชี:** สินทรัพย์เท่ากับหนี้สินบวกส่วนของเจ้าของ (Assets = Liabilities + Owner's Equity) ซึ่งเป็นพื้นฐานของงบฐานะการเงิน 6. **ค่าเสื่อมราคา (Depreciation):** การปันส่วนต้นทุนของสินทรัพย์ถาวรตลอดอายุการใช้งาน เพื่อให้สะท้อนมูลค่าที่ลดลงจากการใช้งาน 7. **ค่าเสื่อมราคาสะสม (Accumulated Depreciation):** บัญชีปรับมูลค่าสินทรัพย์ (Contra-asset account) ที่แสดงถึงมูลค่าสินทรัพย์ที่ถูกใช้ไปแล้ว ซึ่งจะนำไปหักออกจากมูลค่าสินทรัพย์นั้นๆ ในงบฐานะการเงิน 8. **ค่าเผื่อหนี้สงสัยจะสูญ (Allowance for Doubtful Accounts):** บัญชีปรับมูลค่าสินทรัพย์ (Contra-asset account) ที่ตั้งขึ้นเพื่อประมาณการหนี้ที่คาดว่าจะเรียกเก็บไม่ได้ ซึ่งจะนำไปหักออกจากลูกหนี้การค้าในงบฐานะการเงิน 9. **ค่าใช้จ่ายโดยตรงและค่าใช้จ่ายสนับสนุน:** การจำแนกค่าใช้จ่ายที่เกี่ยวข้องโดยตรงกับการให้บริการ (เช่น วัสดุสิ้นเปลืองใช้ไป, เงินเดือนพนักงานซ่อม) กับค่าใช้จ่ายในการบริหารจัดการ (เช่น ค่ารับรอง, ค่าสาธารณูปโภค, ค่าเสื่อมราคาอาคาร) ซึ่งส่งผลต่อการจัดทำงบกำไรขาดทุน

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| ร้านนักซ่อม | ธุรกิจบริการรับซ่อมรถยนต์ |
| งบกำไรขาดทุน | รายงานทางการเงินที่แสดงผลการดำเนินงานของกิจการในช่วงเวลาหนึ่ง โดยแสดงรายได้และค่าใช้จ่ายเพื่อหากำไรสุทธิหรือขาดทุนสุทธิ |
| งบแสดงการเปลี่ยนแปลงส่วนของผู้เป็นเจ้าของ | รายงานทางการเงินที่แสดงการเปลี่ยนแปลงของส่วนของเจ้าของกิจการในช่วงเวลาหนึ่ง โดยพิจารณาจากทุนเริ่มต้น กำไรสุทธิ (หรือขาดทุนสุทธิ) และเงินถอน |
| งบฐานะการเงิน | รายงานทางการเงินที่แสดงฐานะทางการเงินของกิจการ ณ วันใดวันหนึ่ง โดยแสดงสินทรัพย์ หนี้สิน และส่วนของเจ้าของ |
| สินทรัพย์ | ทรัพยากรที่กิจการเป็นเจ้าของและสามารถก่อให้เกิดประโยชน์เชิงเศรษฐกิจในอนาคต |
| หนี้สิน | ภาระผูกพันในปัจจุบันของกิจการที่ต้องชำระคืนในอนาคต |
| ทุน | ส่วนของเจ้าของกิจการในสินทรัพย์ที่เหลืออยู่หลังจากหักหนี้สินทั้งหมดแล้ว |
| รายได้ | ผลตอบแทนที่กิจการได้รับจากการดำเนินงานตามปกติ เช่น รายได้ค่าบริการ |
| ค่าใช้จ่าย | ต้นทุนที่เกิดขึ้นจากการดำเนินงานเพื่อก่อให้เกิดรายได้ |
| เงินถอน | เงินหรือสินทรัพย์ที่เจ้าของกิจการถอนไปใช้ส่วนตัว ซึ่งจะทำให้ส่วนของเจ้าของลดลง |
| ค่าเสื่อมราคา | ค่าใช้จ่ายที่เกิดจากการปันส่วนต้นทุนของสินทรัพย์ถาวรตลอดอายุการใช้งาน |
| ค่าเสื่อมราคาสะสม | บัญชีปรับมูลค่าสินทรัพย์ที่แสดงถึงยอดรวมของค่าเสื่อมราคาที่ตัดจำหน่ายไปแล้วสำหรับสินทรัพย์ถาวร |
| ค่าเผื่อหนี้สงสัยจะสูญ | บัญชีปรับมูลค่าสินทรัพย์ที่ตั้งขึ้นเพื่อประมาณการจำนวนลูกหนี้ที่คาดว่าจะเรียกเก็บไม่ได้ |
| วัสดุสิ้นเปลืองในการซ่อมรถใช้ไป | ต้นทุนของวัสดุที่ใช้ไปโดยตรงในการให้บริการซ่อมรถ |
| ค่ารับรอง | ค่าใช้จ่ายในการต้อนรับลูกค้าหรือบุคคลภายนอกเพื่อสนับสนุนการดำเนินงาน |

*   **พันธบัตรรัฐบาล:** 100,000 บาท (CA1 - สินทรัพย์หมุนเวียน: เงินสดและรายการเทียบเท่าเงินสด)

*   **ค่าเผื่อหนี้สงสัยจะสูญ:** 2,500 บาท (CA4 - สินทรัพย์หมุนเวียน: บัญชีปรับมูลค่าลูกหนี้การค้า, ตัวหัก)

*   **ค่าเสื่อมราคา-อาคาร:** 40,000 บาท (E3 - ค่าใช้จ่ายในการบริหาร)

**ขั้นตอนการจัดทำงบการเงิน:**
1.  **งบกำไรขาดทุน:** นำรายได้ทั้งหมดหักด้วยค่าใช้จ่ายทั้งหมด เพื่อหากำไรสุทธิหรือขาดทุนสุทธิ
2.  **งบแสดงการเปลี่ยนแปลงส่วนของผู้เป็นเจ้าของ:** นำทุนต้นงวด บวกด้วยกำไรสุทธิ (หรือหักขาดทุนสุทธิ) และหักด้วยเงินถอน เพื่อหาทุนปลายงวด
3.  **งบฐานะการเงิน:** จัดเรียงสินทรัพย์ หนี้สิน และส่วนของเจ้าของ โดยให้สมการบัญชี สินทรัพย์ = หนี้สิน + ส่วนของเจ้าของ ดุลกัน

## สรุปท้ายบท
การจัดทำงบการเงินที่ถูกต้องเริ่มต้นจากการจัดประเภทบัญชีที่แม่นยำ ซึ่งเป็นทักษะพื้นฐานที่สำคัญสำหรับนักบัญชี การทำความเข้าใจความแตกต่างระหว่างสินทรัพย์และค่าใช้จ่าย รวมถึงบทบาทของบัญชีปรับมูลค่าสินทรัพย์ เช่น ค่าเสื่อมราคาสะสมและค่าเผื่อหนี้สงสัยจะสูญ จะช่วยให้สามารถนำเสนอฐานะการเงินและผลการดำเนินงานของกิจการได้อย่างสมจริงและน่าเชื่อถือ นอกจากนี้ การฝึกฝนการจัดทำงบการเงินด้วยตนเองจะช่วยเสริมสร้างความเข้าใจในหลักการบัญชีและเตรียมความพร้อมสำหรับการทำงานจริงในอนาคต
