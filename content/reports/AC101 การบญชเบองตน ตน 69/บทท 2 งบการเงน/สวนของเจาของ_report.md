# ส่วนของเจ้าของ

## บทนำ
ส่วนของเจ้าของ (Owner's Equity) คือส่วนสุดท้ายที่ปรากฏในงบดุล และเป็นส่วนที่เหลือจากสินทรัพย์ทั้งหมดหักด้วยหนี้สินทั้งหมด จึงเรียกอีกชื่อหนึ่งว่า 'สินทรัพย์สุทธิ' (Net Assets) ซึ่งแสดงถึงส่วนของความเป็นเจ้าของในสินทรัพย์ของกิจการ โดยส่วนของเจ้าของจะมีความแตกต่างกันออกไปตามลักษณะการจัดตั้งกิจการตามกฎหมาย ซึ่งแบ่งได้เป็น 3 ประเภทหลัก ได้แก่ กิจการเจ้าของคนเดียว ห้างหุ้นส่วน และบริษัทจำกัด การทำความเข้าใจส่วนของเจ้าของมีความสำคัญอย่างยิ่งในการอ่านงบการเงินและประเมินฐานะทางการเงินของกิจการ

## วัตถุประสงค์
1. เพื่อให้เข้าใจความหมายและองค์ประกอบของส่วนของเจ้าของในรูปแบบกิจการต่างๆ 2. เพื่อให้สามารถจำแนกและบันทึกรายการที่เกี่ยวข้องกับส่วนของเจ้าของในกิจการเจ้าของคนเดียว ห้างหุ้นส่วน และบริษัทจำกัด 3. เพื่อให้เข้าใจถึงความแตกต่างของโครงสร้างส่วนของเจ้าของในแต่ละประเภทกิจการ และเหตุผลเบื้องหลังความแตกต่างนั้น 4. เพื่อให้สามารถนำความรู้เรื่องส่วนของเจ้าของไปใช้ในการวิเคราะห์งบการเงินและตัดสินใจทางธุรกิจเบื้องต้นได้

## แนวคิดสำคัญ
ส่วนของเจ้าของคือส่วนที่เหลือจากสินทรัพย์ลบหนี้สินเสมอ โดยมีโครงสร้างและชื่อบัญชีที่เกี่ยวข้องแตกต่างกันไปตามประเภทของกิจการ ดังนี้:  1. กิจการเจ้าของคนเดียว (Single Proprietorship): มีส่วนของเจ้าของเรียกว่า 'ส่วนของผู้เป็นเจ้าของ' ซึ่งประกอบด้วยรายการที่สำคัญดังนี้:    *   **บัญชีทุน (Capital)**: เป็นบัญชีที่ใช้บันทึกการลงทุนครั้งแรก การถอนทุน และการเพิ่มทุนของผู้เป็นเจ้าของกิจการ    *   **บัญชีถอนใช้ส่วนตัว (Withdrawal)**: เป็นบัญชีที่ใช้บันทึกการถอนเงินสดหรือสินทรัพย์ไปใช้ส่วนตัวของผู้เป็นเจ้าของกิจการ    *   **บัญชีกำไรขาดทุน (Profit and Loss)**: เป็นบัญชีที่ใช้บันทึกผลกำไรหรือขาดทุนสุทธิของกิจการในช่วงเวลาใดเวลาหนึ่ง ซึ่งกำไรจะทำให้ส่วนของผู้เป็นเจ้าของเพิ่มขึ้น และขาดทุนจะทำให้ลดลง  2. ห้างหุ้นส่วน (Partnership): ส่วนของเจ้าของจะเรียกว่า 'ส่วนของผู้เป็นหุ้นส่วน' ซึ่งมีวิธีการบันทึกทุน 2 แบบหลัก:    *   **กรณีที่ใช้วิธีทุนคงที่ (Fixed Capital Method)**: หุ้นส่วนแต่ละคนจะมี 2 บัญชี คือ      *   **บัญชีทุน (Capital)**: ใช้บันทึกเฉพาะการลงทุนครั้งแรกและการถอนทุนเท่านั้น โดยจำนวนบัญชีทุนจะเท่ากับจำนวนผู้เป็นหุ้นส่วน      *   **บัญชีกระแสทุน (Current Capital)**: ใช้บันทึกรายการเกี่ยวกับการเคลื่อนไหวของเงินทุนที่มีการเปลี่ยนแปลงในระหว่างงวด เช่น การแบ่งกำไร การถอนใช้ส่วนตัว การรับเงินเดือน โบนัส และการแบ่งกำไรขาดทุนของหุ้นส่วนแต่ละราย วิธีนี้มักใช้ในห้างหุ้นส่วนที่ตกลงแบ่งกำไรขาดทุนตามยอดคงเหลือในบัญชีทุน โดยต้องการให้บัญชีทุนคงที่และผลกำไรเป็นเรื่องของการทำมาหาได้ร่วมกัน    *   **กรณีที่ใช้วิธีทุนเปลี่ยนแปลง (Fluctuating Capital Method)**: หุ้นส่วนแต่ละคนจะมีบัญชีทุนเพียงบัญชีเดียว คือ      *   **บัญชีทุน (Capital)**: ใช้บันทึกทุกรายการ ทั้งการลงทุน การถอนทุน ผลกำไรขาดทุน การถอนใช้ส่วนตัว และการแบ่งเงินเดือน/โบนัส วิธีนี้ใช้เมื่อตกลงแบ่งกำไรจากทุนสิ้นงวด (ทุนที่นับรวมผลกำไรขาดทุนและหักการถอนใช้แล้ว)    *   นอกจากนี้ ห้างหุ้นส่วนอาจมีบัญชีกำไรขาดทุนที่ยังไม่แบ่ง เพื่อกันกำไรไว้ใช้ในการขยายกิจการ  3. บริษัทจำกัด (Corporation): มีส่วนของเจ้าของเรียกว่า 'ส่วนของผู้ถือหุ้น' ซึ่งประกอบด้วยรายการที่สำคัญดังนี้:    *   **บัญชีหุ้นทุน (Share Capital)**: เป็นบัญชีที่บันทึกหุ้นที่บริษัทนำออกจำหน่ายแล้ว โดยทุนหุ้นของบริษัทมี 2 ประเภท คือ      *   **หุ้นสามัญ (Common Stock)**: เป็นหุ้นที่มีอำนาจในการบริหารกิจการและเป็นหุ้นที่ต้องมีสำหรับการจัดตั้งบริษัท      *   **หุ้นบุริมสิทธิ (Preferred Stock)**: เป็นหุ้นที่ไม่มีสิทธิออกเสียงในการบริหารกิจการ แต่มีสิทธิที่จะได้รับผลตอบแทนและรับคืนทุนก่อนหุ้นสามัญ    *   **ส่วนเกินทุน (Capital Surplus)**: เป็นส่วนที่เกินกว่ามูลค่าหุ้น หรือเกิดจากผลกำไรอื่นๆ ที่ไม่ได้มาจากการดำเนินงานและมาตรฐานบัญชีห้ามรับรู้เป็นรายได้ เช่น ส่วนเกินมูลค่าหุ้น    *   **กำไรสะสม (Retained Earnings)**: เป็นกำไรที่บริษัทยังไม่ได้แบ่งให้ผู้ถือหุ้น ซึ่งจะถูกนำไปจ่ายปันผลในภายหลัง

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| ส่วนของเจ้าของ (Owner's Equity) | ส่วนที่เหลือจากสินทรัพย์ทั้งหมดหักด้วยหนี้สินทั้งหมด แสดงถึงสิทธิเรียกร้องของเจ้าของในสินทรัพย์ของกิจการ |
| สินทรัพย์สุทธิ (Net Assets) | คำเรียกอีกชื่อหนึ่งของส่วนของเจ้าของ ซึ่งคำนวณจากสินทรัพย์ลบหนี้สิน |
| กิจการเจ้าของคนเดียว (Single Proprietorship) | รูปแบบธุรกิจที่มีเจ้าของเพียงคนเดียว |
| บัญชีทุน (Capital Account) | บัญชีที่ใช้บันทึกการลงทุน การถอนทุน และการเพิ่มทุนของผู้เป็นเจ้าของ |
| บัญชีถอนใช้ส่วนตัว (Withdrawal Account) | บัญชีที่ใช้บันทึกการถอนเงินสดหรือสินทรัพย์ของกิจการไปใช้ส่วนตัวของเจ้าของ |
| บัญชีกำไรขาดทุน (Profit and Loss Account) | บัญชีที่ใช้บันทึกผลกำไรหรือขาดทุนสุทธิของกิจการ |
| ห้างหุ้นส่วน (Partnership) | รูปแบบธุรกิจที่มีบุคคลตั้งแต่สองคนขึ้นไปร่วมกันลงทุนและดำเนินกิจการ |
| วิธีทุนคงที่ (Fixed Capital Method) | วิธีการบันทึกบัญชีทุนของหุ้นส่วนที่แยกบัญชีทุนและบัญชีกระแสทุนออกจากกัน โดยบัญชีทุนจะคงที่ |
| บัญชีกระแสทุน (Current Capital Account) | บัญชีที่ใช้บันทึกรายการที่เกี่ยวข้องกับการเปลี่ยนแปลงทุนของหุ้นส่วนที่ไม่ใช่การลงทุนหรือถอนทุน เช่น การแบ่งกำไร การถอนใช้ส่วนตัว |
| วิธีทุนเปลี่ยนแปลง (Fluctuating Capital Method) | วิธีการบันทึกบัญชีทุนของหุ้นส่วนที่รวมทุกรายการที่เกี่ยวข้องกับทุนไว้ในบัญชีทุนเพียงบัญชีเดียว |
| บริษัทจำกัด (Corporation) | รูปแบบธุรกิจที่มีผู้ถือหุ้นหลายคน มีสถานะเป็นนิติบุคคลแยกต่างหากจากเจ้าของ |
| ส่วนของผู้ถือหุ้น (Shareholders' Equity) | ส่วนของเจ้าของในบริษัทจำกัด |
| หุ้นสามัญ (Common Stock) | หุ้นที่ให้สิทธิในการออกเสียงและมีอำนาจในการบริหารกิจการ |
| หุ้นบุริมสิทธิ (Preferred Stock) | หุ้นที่ไม่มีสิทธิออกเสียงในการบริหาร แต่มีสิทธิได้รับเงินปันผลและเงินคืนทุนก่อนหุ้นสามัญ |
| กำไรสะสม (Retained Earnings) | กำไรสุทธิของบริษัทที่ยังไม่ได้จ่ายเป็นเงินปันผลให้แก่ผู้ถือหุ้น |

## ตัวอย่างหรือขั้นตอน
1.  **การคำนวณส่วนของเจ้าของ**: ส่วนของเจ้าของ = สินทรัพย์ - หนี้สิน  ตัวอย่าง: หากกิจการมีสินทรัพย์ 1,000 ล้านบาท และมีหนี้สิน 200 ล้านบาท ส่วนของเจ้าของจะเท่ากับ 1,000 ล้านบาท - 200 ล้านบาท = 800 ล้านบาท  2.  **ผลกระทบของรายการต่อส่วนของเจ้าของในกิจการเจ้าของคนเดียว**:    *   **เจ้าของนำเงินมาลงทุน**: ส่วนของเจ้าของ (บัญชีทุน) เพิ่มขึ้น    *   **เจ้าของถอนเงินไปใช้ส่วนตัว**: ส่วนของเจ้าของ (บัญชีถอนใช้ส่วนตัว) ลดลง    *   **กิจการมีกำไร**: ส่วนของเจ้าของ (บัญชีกำไรขาดทุน) เพิ่มขึ้น    *   **กิจการมีขาดทุน**: ส่วนของเจ้าของ (บัญชีกำไรขาดทุน) ลดลง  3.  **โครงสร้างงบแสดงฐานะการเงิน (ตัวอย่าง)**:    *   **สินทรัพย์**:      *   สินทรัพย์หมุนเวียน (เงินสด, เงินฝาก, ลูกหนี้, สินค้า, ค่าเบี้ยล่วงหน้า, วัสดุ)      *   สินทรัพย์ไม่หมุนเวียน (เงินให้กู้ระยะยาว, ที่ดิน อาคาร อุปกรณ์)      *   รวมสินทรัพย์    *   **หนี้สินและส่วนของเจ้าของ**:      *   หนี้สินหมุนเวียน (เจ้าหนี้การค้า, รายได้รับล่วงหน้า)      *   หนี้สินไม่หมุนเวียน (เงินกู้)      *   รวมหนี้สิน      *   **ส่วนของเจ้าของ**:        *   **กิจการเจ้าของคนเดียว**: ทุน - นายตัวอย่าง        *   **บริษัทจำกัด**: ทุนเรือนหุ้น (หุ้นสามัญ, หุ้นบุริมสิทธิ), ส่วนเกินทุน, กำไรสะสม (จัดสรรตามกฎหมาย, ยังไม่ได้จัดสรร)      *   รวมหนี้สินและส่วนของเจ้าของ (ต้องเท่ากับรวมสินทรัพย์เสมอ)  4.  **เหตุผลในการเลือกรูปแบบธุรกิจที่ส่งผลต่อส่วนของเจ้าของและภาษี**:    *   **กิจการเจ้าของคนเดียว**: เหมาะสำหรับผู้เริ่มต้น เพราะเสียภาษีแบบบุคคลธรรมดา ซึ่งเป็นอัตราก้าวหน้า (เช่น 10%, 15%, 20%, 25%, 30%) หากรายได้ยังไม่สูงมาก ฐานภาษีจะต่ำ    *   **ห้างหุ้นส่วน/บริษัทจำกัด**: เหมาะสำหรับกิจการที่มีรายได้สูงขึ้น หรือต้องการร่วมลงทุนกับผู้อื่น เพราะเสียภาษีแบบนิติบุคคลในอัตราคงที่ (เช่น 20% จากกำไรสุทธิ) ซึ่งจะคุ้มค่ากว่าการเสียภาษีบุคคลธรรมดาในอัตราที่สูงขึ้น (เช่น 30%) หากกิจการมีกำไรมาก การเปลี่ยนรูปแบบธุรกิจจึงเป็นกลยุทธ์ในการบริหารภาษีและขยายกิจการ

## สรุปท้ายบท
ส่วนของเจ้าของเป็นองค์ประกอบสำคัญในงบดุลที่สะท้อนถึงสิทธิเรียกร้องของเจ้าของในสินทรัพย์ของกิจการ ซึ่งคำนวณจากสินทรัพย์หักหนี้สินเสมอ โครงสร้างและชื่อบัญชีที่ใช้ในส่วนของเจ้าของจะแตกต่างกันไปตามรูปแบบของกิจการ ไม่ว่าจะเป็นกิจการเจ้าของคนเดียว ห้างหุ้นส่วน หรือบริษัทจำกัด การทำความเข้าใจความแตกต่างเหล่านี้มีความสำคัญต่อการวิเคราะห์ฐานะทางการเงินและผลการดำเนินงานของกิจการ รวมถึงการตัดสินใจทางธุรกิจ เช่น การเลือกรูปแบบกิจการที่เหมาะสมกับขนาดและเป้าหมายของธุรกิจ โดยเฉพาะอย่างยิ่งในเรื่องของภาระภาษีและการระดมทุน

## คำถามทบทวน
1. ส่วนของเจ้าของมีความสัมพันธ์กับสินทรัพย์และหนี้สินอย่างไร และมีชื่อเรียกอื่นว่าอะไรบ้าง?
