# AC101บทที่7 ตอนที่1ความหมายผู้มีหน้าที่การยกเว้นภาษีมูลค่าเพิ่ม

## บทนำ
บทเรียนนี้เป็นส่วนหนึ่งของวิชาบัญชีภาษีมูลค่าเพิ่มในบทที่ 7 โดยจะอธิบายถึงความหมายของผู้มีหน้าที่เสียภาษีมูลค่าเพิ่มและกรณีที่ได้รับการยกเว้นภาษีมูลค่าเพิ่ม แม้ว่าภาษีจะเป็นเรื่องของรัฐ แต่ก็มีความเกี่ยวข้องกับการบัญชีอย่างใกล้ชิด เนื่องจากผู้ประกอบการมีหน้าที่ในการจัดเก็บภาษีแทนรัฐบาล ภาษีมูลค่าเพิ่มเป็นภาษีทางอ้อมที่รัฐเรียกเก็บจากการบริโภคสินค้าหรือบริการของผู้บริโภค โดยรัฐไม่ได้ทำหน้าที่จัดเก็บเอง แต่กำหนดให้ผู้ประกอบการในระบบภาษีมูลค่าเพิ่มทำหน้าที่จัดเก็บภาษีแทนกรมสรรพากร ซึ่งหมายความว่าผู้ประกอบการเป็นตัวแทนของรัฐในการเรียกเก็บภาษีจากผู้บริโภคเมื่อมีการซื้อขายสินค้าหรือบริการ

## วัตถุประสงค์
1. เพื่อให้เข้าใจความหมายและลักษณะของภาษีมูลค่าเพิ่มว่าเป็นภาษีทางอ้อม 2. เพื่อให้ทราบถึงผู้ที่มีหน้าที่เสียภาษีมูลค่าเพิ่มและเงื่อนไขในการเข้าสู่ระบบภาษีมูลค่าเพิ่ม 3. เพื่อให้เข้าใจหน้าที่สำคัญ 3 ประการของผู้ประกอบการที่อยู่ในระบบภาษีมูลค่าเพิ่ม 4. เพื่อให้สามารถระบุประเภทของสินค้าและบริการที่ได้รับการยกเว้นภาษีมูลค่าเพิ่มได้ 5. เพื่อให้เข้าใจถึงผลกระทบและข้อดีของการเข้าสู่ระบบภาษีมูลค่าเพิ่มแม้รายรับจะไม่ถึงเกณฑ์ที่กำหนด

## แนวคิดสำคัญ
ภาษีมูลค่าเพิ่ม (Value Added Tax - VAT) คือภาษีทางอ้อมที่รัฐโดยกรมสรรพากรเรียกเก็บจากการบริโภคสินค้าหรือบริการของผู้บริโภค โดยรัฐไม่ได้จัดเก็บเอง แต่กำหนดให้ผู้ประกอบการในระบบภาษีมูลค่าเพิ่มทำหน้าที่จัดเก็บภาษีแทน ผู้ประกอบการจึงเป็นตัวแทนของรัฐในการเรียกเก็บภาษีจากผู้บริโภคเมื่อมีการซื้อขายสินค้าหรือบริการ

**ผู้มีหน้าที่เสียภาษีมูลค่าเพิ่ม:**
1.  **ผู้ประกอบการ ผู้ที่นำเข้า และผู้ที่กฎหมายกำหนดเพิ่มเติม:** ที่มีรายรับต่อปีเกิน 1,800,000 บาท (จากเดิม 1,200,000 บาท) รายรับในที่นี้หมายถึงยอดขายหรือรายได้ ไม่ได้หักค่าใช้จ่ายหรือกำไร
2.  **ผู้ประกอบการ ผู้ที่นำเข้า และผู้ที่กฎหมายกำหนดเพิ่มเติม:** ที่มีรายรับต่อปีไม่เกิน 1,800,000 บาท แต่ต้องการขอเข้าสู่ระบบภาษีมูลค่าเพิ่มโดยสมัครใจ เพื่อประโยชน์ในการขอคืนภาษีซื้อ

**ผู้ประกอบการ** หมายถึง บุคคลที่ขายสินค้าหรือให้บริการในทางธุรกิจหรือวิชาชีพที่ประกอบกิจการในราชอาณาจักร ไม่ว่าจะได้รับประโยชน์หรือค่าตอบแทนหรือไม่

**หน้าที่ของผู้มีหน้าที่เสียภาษีมูลค่าเพิ่ม (3 ประการ):**
1.  **เรียกเก็บภาษีมูลค่าเพิ่ม:** จากผู้ซื้อสินค้าหรือบริการทุกครั้ง พร้อมทั้งออกใบกำกับภาษีเป็นหลักฐาน
2.  **จัดทำเอกสารและรายงานต่างๆ:** ตามที่กฎหมายกำหนด เช่น ใบกำกับภาษี รายงานภาษีซื้อ รายงานภาษีขาย รายงานสินค้าและวัตถุดิบ ส่งให้กรมสรรพากร
3.  **คำนวณภาษีมูลค่าเพิ่มทุกเดือน:** และยื่นแบบแสดงรายการเสียภาษีมูลค่าเพิ่ม (ภ.พ.30) ภายในวันที่ 15 ของเดือนถัดไป พร้อมทั้งนำส่งหรือขอคืนภาษีตามวิธีการที่กฎหมายกำหนด

**ผู้ที่ได้รับการยกเว้นภาษีมูลค่าเพิ่ม:** เพื่อเป็นการแบ่งเบาภาระของผู้บริโภคหรือประชาชน โดยเฉพาะสินค้าและบริการที่เป็นปัจจัยพื้นฐานในการดำรงชีวิต

**การขายสินค้าที่ได้รับการยกเว้น (ตัวอย่าง):**
*   พืชผลทางการเกษตรสด (เช่น ผักสด, ผลไม้สด) และสัตว์ที่มีชีวิตและไม่มีชีวิตในสภาพสด (เช่น ปลาสด) แต่ไม่รวมผลิตภัณฑ์อาหารที่บรรจุกระป๋องหรือแปรรูป
*   การขายปุ๋ย อาหารสัตว์ ยาหรือเคมีภัณฑ์ที่ใช้สำหรับพืชหรือสัตว์
*   การขายหนังสือ ตำราเรียน นิตยสาร หรือหนังสือพิมพ์
*   การขายสินค้าของกระทรวง ทบวง กรม ซึ่งส่งรายรับให้แก่รัฐโดยไม่หักรายจ่าย (เช่น ค่าภาษีรถยนต์ประจำปีที่จ่ายให้กรมการขนส่งทางบก)
*   การขายสินค้าเพื่อประโยชน์แก่การศาสนา หรือสาธารณกุศลภายในประเทศ
*   การขายสลากกินแบ่งรัฐบาล สลากออมสิน

**การให้บริการที่ได้รับการยกเว้น (ตัวอย่าง):**
*   การให้บริการของสถานศึกษา (สถาบันอุดมศึกษาทั้งรัฐและเอกชน)
*   การให้บริการทางการแพทย์ของสถานพยาบาล
*   การให้บริการประกอบวิชาชีพอิสระ (เช่น การสอบบัญชี, การว่าความ, การประกอบโรคศิลป์) ซึ่งรวมถึงการตั้งสำนักงานบัญชีและทนายความ
*   การให้บริการตามสัญญาจ้างแรงงาน (เช่น เงินเดือน)
*   การให้บริการขนส่งในราชอาณาจักร (เช่น ค่าขนส่งเข้า, ค่าขนส่งออก)
*   การให้เช่าอสังหาริมทรัพย์ (เช่น ค่าเช่าร้าน)
*   การให้บริการของกระทรวง ทบวง กรม ซึ่งส่งรายรับให้แก่รัฐโดยไม่หักรายจ่าย

**ข้อสังเกต:** บริการสาธารณูปโภค เช่น ค่าไฟฟ้าและค่าน้ำประปา ไม่ได้รับการยกเว้นภาษีมูลค่าเพิ่ม เนื่องจากเป็นการให้บริการโดยรัฐวิสาหกิจ ซึ่งมีวัตถุประสงค์ในการแสวงหากำไรและไม่ได้นำรายรับทั้งหมดส่งให้รัฐบาลโดยตรง

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| ภาษีมูลค่าเพิ่ม (VAT) | ภาษีทางอ้อมที่รัฐเรียกเก็บจากการบริโภคสินค้าหรือบริการ |
| ผู้ประกอบการ | บุคคลที่ขายสินค้าหรือให้บริการในทางธุรกิจหรือวิชาชีพ และมีหน้าที่จัดเก็บภาษีมูลค่าเพิ่มแทนรัฐ |
| ภาษีทางอ้อม | ภาษีที่รัฐไม่ได้จัดเก็บโดยตรงจากผู้บริโภค แต่จัดเก็บผ่านตัวกลาง เช่น ผู้ประกอบการ |
| ภาษีซื้อ | ภาษีมูลค่าเพิ่มที่ผู้ประกอบการจ่ายไปเมื่อซื้อสินค้าหรือบริการ |
| ภาษีขาย | ภาษีมูลค่าเพิ่มที่ผู้ประกอบการเรียกเก็บจากผู้ซื้อสินค้าหรือบริการ |
| ใบกำกับภาษี | เอกสารหลักฐานที่ผู้ประกอบการออกให้ผู้ซื้อเพื่อแสดงการเรียกเก็บภาษีมูลค่าเพิ่ม |
| รายรับ | ยอดขายหรือรายได้รวมก่อนหักค่าใช้จ่ายใดๆ |
| ยกเว้นภาษี | การที่สินค้าหรือบริการบางประเภทไม่ต้องเสียภาษีมูลค่าเพิ่มตามที่กฎหมายกำหนด |
| กรมสรรพากร | หน่วยงานของรัฐที่มีหน้าที่จัดเก็บภาษี |
| สถาบันอุดมศึกษา | สถานศึกษาในระดับอุดมศึกษาที่ได้รับการยกเว้นภาษีมูลค่าเพิ่มสำหรับบริการทางการศึกษา |
| บริการขนส่งในราชอาณาจักร | บริการขนส่งภายในประเทศที่ได้รับการยกเว้นภาษีมูลค่าเพิ่ม |
| สัญญาจ้างแรงงาน | การจ้างงานที่ได้รับค่าตอบแทนเป็นเงินเดือน ซึ่งได้รับการยกเว้นภาษีมูลค่าเพิ่ม |
| ให้เช่าอสังหาริมทรัพย์ | การให้เช่าทรัพย์สินที่ไม่สามารถเคลื่อนที่ได้ เช่น ที่ดิน อาคาร ซึ่งได้รับการยกเว้นภาษีมูลค่าเพิ่ม |
| วิชาชีพอิสระ | อาชีพที่ต้องใช้ความรู้ความสามารถเฉพาะทาง เช่น นักบัญชี ทนายความ ซึ่งได้รับการยกเว้นภาษีมูลค่าเพิ่ม |
| รัฐวิสาหกิจ | กิจการที่รัฐเป็นเจ้าของหรือถือหุ้นส่วนใหญ่ แต่ไม่ได้นำรายรับทั้งหมดส่งให้รัฐบาลโดยตรง เช่น การไฟฟ้า การประปา |

## ตัวอย่างหรือขั้นตอน
1.  **การคำนวณภาษีมูลค่าเพิ่ม:** หากคุณขายสินค้าในราคา 100 บาท และอัตราภาษีมูลค่าเพิ่มปัจจุบันคือ 7% คุณจะต้องเรียกเก็บเงินจากลูกค้า 107 บาท (100 บาทสำหรับราคาสินค้า + 7 บาทสำหรับภาษีมูลค่าเพิ่ม) โดย 7 บาทนี้คือภาษีขายที่คุณต้องนำส่งกรมสรรพากร
2.  **ตัวอย่างสินค้าที่ได้รับการยกเว้นภาษี:**
    *   คุณไปซื้อปลาสดจากตลาดสด ไม่ต้องเสียภาษีมูลค่าเพิ่ม เพราะเป็นพืชผลทางการเกษตรสด
    *   คุณซื้อหนังสือเรียนจากร้านหนังสือ ไม่ต้องเสียภาษีมูลค่าเพิ่ม
    *   คุณจ่ายค่าภาษีรถยนต์ประจำปีที่กรมการขนส่งทางบก ไม่ต้องเสียภาษีมูลค่าเพิ่ม เพราะเป็นการจ่ายให้กระทรวง ทบวง กรม
3.  **ตัวอย่างบริการที่ได้รับการยกเว้นภาษี:**
    *   คุณจ่ายค่าเทอมให้มหาวิทยาลัย ไม่ต้องเสียภาษีมูลค่าเพิ่ม เพราะเป็นบริการของสถานศึกษา
    *   คุณไปหาหมอที่โรงพยาบาล ค่ารักษาพยาบาลไม่ต้องเสียภาษีมูลค่าเพิ่ม
    *   คุณจ้างสำนักงานบัญชีทำบัญชีให้ ไม่ต้องเสียภาษีมูลค่าเพิ่ม เพราะเป็นการประกอบวิชาชีพอิสระ
    *   คุณจ่ายเงินเดือนพนักงาน ไม่ต้องเสียภาษีมูลค่าเพิ่ม เพราะเป็นสัญญาจ้างแรงงาน
    *   คุณจ่ายค่าเช่าร้านค้า ไม่ต้องเสียภาษีมูลค่าเพิ่ม เพราะเป็นการให้เช่าอสังหาริมทรัพย์
4.  **ตัวอย่างบริการที่ไม่ได้รับการยกเว้นภาษี:**
    *   คุณจ่ายค่าไฟฟ้าหรือค่าน้ำประปา จะมีภาษีมูลค่าเพิ่ม 7% รวมอยู่ในบิล เนื่องจากเป็นการให้บริการโดยรัฐวิสาหกิจ ซึ่งไม่ถือเป็นหน่วยงานราชการที่ได้รับการยกเว้นภาษี

## สรุปท้ายบท
ภาษีมูลค่าเพิ่มเป็นส่วนสำคัญของการดำเนินธุรกิจและการบัญชีในประเทศไทย ผู้ประกอบการมีบทบาทเป็นผู้จัดเก็บภาษีแทนรัฐ และต้องปฏิบัติตามหน้าที่ 3 ประการอย่างเคร่งครัด ได้แก่ การเรียกเก็บภาษี การจัดทำเอกสาร และการยื่นแบบแสดงรายการภาษีเป็นประจำทุกเดือน การทำความเข้าใจเกี่ยวกับเกณฑ์รายรับที่ต้องเข้าสู่ระบบภาษีมูลค่าเพิ่ม (เกิน 1.8 ล้านบาทต่อปี) และกรณีที่ได้รับการยกเว้นภาษีเป็นสิ่งสำคัญอย่างยิ่ง เพื่อให้สามารถบริหารจัดการภาษีได้อย่างถูกต้องและมีประสิทธิภาพ นอกจากนี้ ผู้ประกอบการที่มีรายรับไม่ถึงเกณฑ์ก็สามารถเลือกเข้าสู่ระบบภาษีมูลค่าเพิ่มได้ เพื่อประโยชน์ในการขอคืนภาษีซื้อ ซึ่งจะช่วยลดต้นทุนและเพิ่มความสามารถในการแข่งขันได้
