# AC101บทที่7 ตอนที่3การบัญชีภาษีมูลค่าเพิ่ม

## บทนำ
บทเรียนนี้มุ่งเน้นไปที่การบันทึกบัญชีภาษีมูลค่าเพิ่ม (VAT) และผลกระทบต่อรายการค้าต่างๆ สำหรับกิจการที่ให้บริการหรือกิจการซื้อขายสินค้าที่เข้าสู่ระบบภาษีมูลค่าเพิ่ม โดยเฉพาะอย่างยิ่งกิจการที่มีรายรับเกิน 1.8 ล้านบาทต่อปี ซึ่งจะต้องมีการบันทึกบัญชีที่เกี่ยวข้องกับภาษีมูลค่าเพิ่มเข้ามาด้วย การบันทึกบัญชีดังกล่าวต้องอ้างอิงหลักเกณฑ์ทางกฎหมายที่เกี่ยวข้อง และจะแยกการอธิบายออกเป็น 5 เรื่องหลัก ได้แก่ การบันทึกบัญชีภาษีมูลค่าเพิ่มเกี่ยวกับการซื้อสินค้า, การบันทึกบัญชีภาษีมูลค่าเพิ่มเกี่ยวกับการขายสินค้า, การบันทึกบัญชีภาษีมูลค่าเพิ่มเกี่ยวกับการจ่ายค่าใช้จ่ายหรือซื้อสินทรัพย์, การบันทึกภาษีมูลค่าเพิ่ม ณ วันสิ้นเดือน และการบันทึกบัญชีเกี่ยวกับการนำส่งภาษีมูลค่าเพิ่ม

## วัตถุประสงค์
วัตถุประสงค์ของบทเรียนนี้คือเพื่อให้ผู้เรียนเข้าใจและสามารถบันทึกบัญชีภาษีมูลค่าเพิ่มได้อย่างถูกต้องในสถานการณ์ต่างๆ รวมถึงการคำนวณภาษีซื้อและภาษีขาย การปรับปรุงรายการเมื่อมีการส่งคืนหรือรับคืนสินค้า การคำนวณส่วนลดรับและส่วนลดจ่ายที่ไม่รวมภาษีมูลค่าเพิ่ม และการบันทึกบัญชีภาษีมูลค่าเพิ่ม ณ สิ้นเดือน เพื่อให้สอดคล้องกับข้อกำหนดทางกฎหมายและหลักการบัญชี

## แนวคิดสำคัญ
แนวคิดสำคัญในบทเรียนนี้ประกอบด้วย:
1.  **ภาษีซื้อ (Input Tax):** ภาษีมูลค่าเพิ่มที่กิจการจ่ายไปเมื่อซื้อสินค้าหรือบริการจากผู้ประกอบการจดทะเบียนภาษีมูลค่าเพิ่ม
2.  **ภาษีขาย (Output Tax):** ภาษีมูลค่าเพิ่มที่กิจการเรียกเก็บจากผู้ซื้อเมื่อขายสินค้าหรือบริการ
3.  **ราคาที่รวมภาษีมูลค่าเพิ่ม (VAT-inclusive price):** ราคาที่รวมภาษีมูลค่าเพิ่ม 7% ไว้แล้ว การคำนวณภาษีต้องใช้ 7/107
4.  **ราคาที่ยังไม่รวมภาษีมูลค่าเพิ่ม (VAT-exclusive price):** ราคาที่ยังไม่รวมภาษีมูลค่าเพิ่ม การคำนวณภาษีต้องใช้ 7/100
5.  **การยกเว้นภาษีมูลค่าเพิ่ม:** ค่าขนส่งภายในประเทศทุกชนิดได้รับการยกเว้นภาษีมูลค่าเพิ่ม ไม่ว่าจะเป็นการขนส่งเข้าหรือออก
6.  **ส่วนลดรับ/ส่วนลดจ่าย:** การคำนวณส่วนลดต้องคิดจากมูลค่าสินค้าที่ไม่รวมภาษีมูลค่าเพิ่มเท่านั้น ไม่สามารถนำภาษีมูลค่าเพิ่มมาลดได้
7.  **สินทรัพย์ที่ไม่มีภาษีซื้อ:** ภาษีซื้อสำหรับรถยนต์นั่งส่วนบุคคลไม่สามารถนำมาหักเป็นภาษีซื้อได้ ต้องนำไปรวมเป็นราคาทุนของรถยนต์
8.  **การสรุปภาษีมูลค่าเพิ่ม:** กฎหมายกำหนดให้สรุปภาษีมูลค่าเพิ่มทุกสิ้นเดือน และต้องยื่นแบบภายในวันที่ 15 ของเดือนถัดไป

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| ภาษีมูลค่าเพิ่ม (VAT) | ภาษีที่เก็บจากการบริโภคสินค้าและบริการในแต่ละขั้นตอนของการผลิตและการจำหน่าย |
| ภาษีซื้อ (Input Tax) | ภาษีมูลค่าเพิ่มที่ผู้ประกอบการจดทะเบียนภาษีมูลค่าเพิ่มได้จ่ายไปเมื่อซื้อสินค้าหรือบริการ |
| ภาษีขาย (Output Tax) | ภาษีมูลค่าเพิ่มที่ผู้ประกอบการจดทะเบียนภาษีมูลค่าเพิ่มเรียกเก็บจากผู้ซื้อเมื่อขายสินค้าหรือบริการ |
| สินทรัพย์ | ทรัพยากรที่มีมูลค่าทางเศรษฐกิจที่กิจการเป็นเจ้าของและคาดว่าจะให้ประโยชน์ในอนาคต |
| เจ้าหนี้ | บุคคลหรือกิจการที่กิจการเป็นหนี้อยู่จากการซื้อสินค้าหรือบริการเป็นเงินเชื่อ |
| ลูกหนี้ | บุคคลหรือกิจการที่เป็นหนี้กิจการอยู่จากการขายสินค้าหรือบริการเป็นเงินเชื่อ |
| ส่วนลดรับ | ส่วนลดที่กิจการได้รับจากการชำระหนี้ค่าสินค้าหรือบริการก่อนกำหนด |
| ส่วนลดจ่าย | ส่วนลดที่กิจการให้แก่ลูกค้าที่ชำระหนี้ค่าสินค้าหรือบริการก่อนกำหนด |
| ใบกำกับภาษี | เอกสารหลักฐานที่ผู้ประกอบการจดทะเบียนภาษีมูลค่าเพิ่มออกให้แก่ผู้ซื้อสินค้าหรือบริการ เพื่อแสดงมูลค่าสินค้าหรือบริการและภาษีมูลค่าเพิ่มที่เรียกเก็บ |
| ใบส่งคืน | เอกสารที่ผู้ซื้อออกเมื่อส่งคืนสินค้าที่ซื้อไป |
| ใบรับคืน | เอกสารที่ผู้ขายออกเมื่อรับคืนสินค้าที่ขายไป |
| สินค้าคงเหลือแบบต่อเนื่อง (Perpetual Inventory System) | ระบบการบันทึกสินค้าคงเหลือที่ปรับปรุงยอดสินค้าคงเหลือและต้นทุนขายทุกครั้งที่มีการซื้อหรือขายสินค้า |
| สินค้าคงเหลือแบบสิ้นงวด (Periodic Inventory System) | ระบบการบันทึกสินค้าคงเหลือที่ปรับปรุงยอดสินค้าคงเหลือและต้นทุนขายเมื่อสิ้นงวดบัญชีเท่านั้น |

## ตัวอย่างหรือขั้นตอน
การบันทึกบัญชีภาษีมูลค่าเพิ่มจะแตกต่างกันไปตามประเภทของรายการค้าและวิธีการบันทึกบัญชีสินค้าคงเหลือ (แบบต่อเนื่องหรือแบบสิ้นงวด) โดยมีตัวอย่างและขั้นตอนดังนี้:

**1. การบันทึกบัญชีภาษีมูลค่าเพิ่มเกี่ยวกับการซื้อสินค้า**
*   **กรณีซื้อสินค้าเป็นเงินเชื่อ 50,000 บาท (ราคาที่ยังไม่รวมภาษีมูลค่าเพิ่ม) มีเงื่อนไขการชำระเงิน 2/10, n/30**
    *   **การคำนวณภาษีซื้อ:** 50,000 บาท x 7/100 = 3,500 บาท
    *   **มูลค่ารวมภาษี:** 50,000 บาท + 3,500 บาท = 53,500 บาท
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบต่อเนื่อง):**
        *   เดบิต สินค้าคงเหลือ 50,000
        *   เดบิต ภาษีซื้อ 3,500
        *   เครดิต เจ้าหนี้การค้า 53,500
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบสิ้นงวด):**
        *   เดบิต ซื้อ 50,000
        *   เดบิต ภาษีซื้อ 3,500
        *   เครดิต เจ้าหนี้การค้า 53,500

**2. การบันทึกบัญชีภาษีมูลค่าเพิ่มเกี่ยวกับการจ่ายค่าขนส่งเข้า**
*   **กรณีจ่ายค่าขนส่งสินค้า 1,000 บาท (ภายในประเทศ)**
    *   ค่าขนส่งภายในประเทศได้รับการยกเว้นภาษีมูลค่าเพิ่ม จึงไม่ต้องบันทึกภาษีซื้อ
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบต่อเนื่อง):**
        *   เดบิต สินค้าคงเหลือ 1,000
        *   เครดิต เงินสด 1,000
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบสิ้นงวด):**
        *   เดบิต ค่าขนส่งเข้า 1,000
        *   เครดิต เงินสด 1,000

**3. การบันทึกบัญชีภาษีมูลค่าเพิ่มเมื่อส่งคืนสินค้า**
*   **กรณีส่งคืนสินค้าที่ซื้อเมื่อวันที่ 1 พ.ย. จำนวน 4,000 บาท (ยังไม่รวมภาษีมูลค่าเพิ่ม)**
    *   **การคำนวณภาษีซื้อที่ลดลง:** 4,000 บาท x 7/100 = 280 บาท
    *   **มูลค่ารวมภาษีที่ลดลง:** 4,000 บาท + 280 บาท = 4,280 บาท
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบต่อเนื่อง):**
        *   เดบิต เจ้าหนี้การค้า 4,280
        *   เครดิต สินค้าคงเหลือ 4,000
        *   เครดิต ภาษีซื้อ 280
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบสิ้นงวด):**
        *   เดบิต เจ้าหนี้การค้า 4,280
        *   เครดิต ส่งคืนและส่วนลด 4,000
        *   เครดิต ภาษีซื้อ 280

**4. การบันทึกบัญชีภาษีมูลค่าเพิ่มเมื่อจ่ายชำระหนี้ให้เจ้าหนี้การค้า**
*   **กรณีจ่ายชำระหนี้ค่าสินค้าที่ซื้อเมื่อวันที่ 1 พ.ย. (ซื้อ 50,000 คืน 4,000 เหลือ 46,000) ได้รับส่วนลด 2% เนื่องจากชำระภายใน 10 วัน**
    *   **มูลค่าสินค้าที่เหลือหลังหักคืน:** 50,000 - 4,000 = 46,000 บาท (มูลค่าไม่รวม VAT)
    *   **ส่วนลดรับ:** 46,000 บาท x 2% = 920 บาท (ส่วนลดต้องคิดจากมูลค่าสินค้าที่ไม่รวม VAT เท่านั้น)
    *   **ยอดที่ต้องชำระ (ไม่รวม VAT):** 46,000 - 920 = 45,080 บาท
    *   **ภาษีซื้อที่เกี่ยวข้อง:** 46,000 x 7/100 = 3,220 บาท (ภาษีซื้อเดิมที่ยังไม่ถูกลดจากการคืนสินค้า)
    *   **ยอดเจ้าหนี้ที่ต้องชำระ (รวม VAT):** (50,000 + 3,500) - (4,000 + 280) = 53,500 - 4,280 = 49,220 บาท
    *   **ยอดเงินสดที่จ่าย:** 49,220 (เจ้าหนี้รวม VAT) - 920 (ส่วนลดรับ) = 48,300 บาท
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบต่อเนื่อง):**
        *   เดบิต เจ้าหนี้การค้า 49,220
        *   เครดิต เงินสด 48,300
        *   เครดิต สินค้าคงเหลือ 920
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบสิ้นงวด):**
        *   เดบิต เจ้าหนี้การค้า 49,220
        *   เครดิต เงินสด 48,300
        *   เครดิต ส่วนลดรับ 920

**5. การบันทึกบัญชีภาษีมูลค่าเพิ่มเกี่ยวกับการขายสินค้า**
*   **กรณีขายสินค้าจำนวน 85,600 บาท (ราคารวมภาษีมูลค่าเพิ่มแล้ว) มีราคาทุน 45,000 บาท**
    *   **การคำนวณมูลค่าขาย (ไม่รวม VAT):** 85,600 บาท x 100/107 = 80,000 บาท
    *   **การคำนวณภาษีขาย:** 85,600 บาท x 7/107 = 5,600 บาท
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบต่อเนื่อง):**
        *   เดบิต ลูกหนี้การค้า 85,600
        *   เครดิต ขาย 80,000
        *   เครดิต ภาษีขาย 5,600
        *   เดบิต ต้นทุนขาย 45,000
        *   เครดิต สินค้าคงเหลือ 45,000
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบสิ้นงวด):**
        *   เดบิต ลูกหนี้การค้า 85,600
        *   เครดิต ขาย 80,000
        *   เครดิต ภาษีขาย 5,600

**6. การบันทึกบัญชีภาษีมูลค่าเพิ่มเมื่อรับคืนสินค้า**
*   **กรณีรับคืนสินค้าที่ขายเมื่อวันที่ 14 พ.ย. จำนวน 10,700 บาท (ราคารวมภาษีมูลค่าเพิ่มแล้ว)**
    *   **การคำนวณมูลค่าขายที่ลดลง (ไม่รวม VAT):** 10,700 บาท x 100/107 = 10,000 บาท
    *   **การคำนวณภาษีขายที่ลดลง:** 10,700 บาท x 7/107 = 700 บาท
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบต่อเนื่อง):**
        *   เดบิต รับคืนและส่วนลด 10,000
        *   เดบิต ภาษีขาย 700
        *   เครดิต ลูกหนี้การค้า 10,700
    *   **บันทึกบัญชี (สินค้าคงเหลือแบบสิ้นงวด):**
        *   เดบิต รับคืนและส่วนลด 10,000
        *   เดบิต ภาษีขาย 700
        *   เครดิต ลูกหนี้การค้า 10,700

**7. การบันทึกบัญชีภาษีมูลค่าเพิ่มเมื่อรับชำระหนี้จากลูกหนี้การค้า**
*   **กรณีรับชำระหนี้ค่าสินค้าที่ขายเมื่อวันที่ 14 พ.ย. (ขาย 85,600 คืน 10,700 เหลือ 74,900) ให้ส่วนลด 1% เนื่องจากชำระภายใน 15 วัน**
    *   **มูลค่าสินค้าที่เหลือหลังหักคืน:** 80,000 - 10,000 = 70,000 บาท (มูลค่าไม่รวม VAT)
    *   **ส่วนลดจ่าย:** 70,000 บาท x 1% = 700 บาท (ส่วนลดต้องคิดจากมูลค่าสินค้าที่ไม่รวม VAT เท่านั้น)
    *   **ยอดที่ต้องรับชำระ (ไม่รวม VAT):** 70,000 - 700 = 69,300 บาท
    *   **ภาษีขายที่เกี่ยวข้อง:** 70,000 x 7/100 = 4,900 บาท (ภาษีขายเดิมที่ยังไม่ถูกลดจากการรับคืนสินค้า)
    *   **ยอดลูกหนี้ที่ต้องรับชำระ (รวม VAT):** (80,000 + 5,600) - (10,000 + 700) = 85,600 - 10,700 = 74,900 บาท
    *   **ยอดเงินสดที่รับ:** 74,900 (ลูกหนี้รวม VAT) - 700 (ส่วนลดจ่าย) = 74,200 บาท
    *   **บันทึกบัญชี:**
        *   เดบิต เงินสด 74,200
        *   เดบิต ส่วนลดจ่าย 700
        *   เครดิต ลูกหนี้การค้า 74,900

**8. การบันทึกบัญชีภาษีมูลค่าเพิ่มเกี่ยวกับการจ่ายค่าใช้จ่ายหรือซื้อสินทรัพย์**
*   **กรณีซื้ออุปกรณ์สำนักงานหรือวัสดุสำนักงานจากร้านค้าที่อยู่ในระบบ VAT:**
    *   เดบิต อุปกรณ์สำนักงาน (มูลค่าไม่รวม VAT)
    *   เดบิต ภาษีซื้อ (7% ของมูลค่าไม่รวม VAT)
    *   เครดิต เงินสด/เจ้าหนี้
*   **ข้อยกเว้น:** สำหรับรถยนต์นั่งส่วนบุคคล ภาษีซื้อไม่สามารถนำมาหักได้ ต้องนำไปรวมเป็นราคาทุนของรถยนต์

## สรุปท้ายบท
การบันทึกบัญชีภาษีมูลค่าเพิ่มเป็นสิ่งสำคัญสำหรับกิจการที่จดทะเบียนภาษีมูลค่าเพิ่ม โดยมีข้อควรจำหลักๆ ดังนี้:
1.  **ทุกรายการซื้อและขายสินค้า/บริการ** สำหรับกิจการที่อยู่ในระบบภาษีมูลค่าเพิ่ม จะต้องมีการบันทึกภาษีซื้อหรือภาษีขายควบคู่ไปกับรายการหลักเสมอ
2.  **การคำนวณภาษีมูลค่าเพิ่ม** ต้องพิจารณาว่าราคาที่ได้รับมานั้นเป็นราคาที่รวมภาษีแล้วหรือไม่ หากรวมแล้วให้ใช้ 7/107 ในการแยกภาษีออก แต่หากยังไม่รวมให้ใช้ 7/100 ในการคำนวณภาษีเพิ่ม
3.  **ค่าขนส่งภายในประเทศ** ได้รับการยกเว้นภาษีมูลค่าเพิ่ม ดังนั้นจึงไม่ต้องบันทึกภาษีซื้อหรือภาษีขายสำหรับค่าขนส่งภายในประเทศ
4.  **ส่วนลดการค้าและส่วนลดเงินสด** ทั้งส่วนลดรับและส่วนลดจ่าย จะต้องคำนวณจากมูลค่าสินค้าหรือบริการที่ยังไม่รวมภาษีมูลค่าเพิ่มเท่านั้น ไม่สามารถนำภาษีมูลค่าเพิ่มมาลดได้
5.  **ภาษีซื้อสำหรับรถยนต์นั่ง** ไม่สามารถนำมาหักเป็นภาษีซื้อได้ ต้องนำไปรวมเป็นราคาทุนของรถยนต์
6.  **การสรุปและนำส่งภาษีมูลค่าเพิ่ม** ต้องดำเนินการทุกสิ้นเดือนและยื่นแบบภายในวันที่ 15 ของเดือนถัดไปตามที่กฎหมายกำหนด
