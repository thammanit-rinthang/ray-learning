# บทที่5ตอนที่10แบบฝึกหัดข้อ7

## บทนำ
บทเรียนนี้มุ่งเน้นการทำความเข้าใจและปฏิบัติการปิดบัญชีสำหรับกิจการซื้อมาขายไป โดยเฉพาะอย่างยิ่งการปิดบัญชีตามวิธีบันทึกสินค้าคงเหลือแบบต่อเนื่อง (Perpetual Inventory System) ซึ่งเป็นส่วนหนึ่งของการทำแบบฝึกหัดข้อที่ 7 โดยจะอธิบายถึงความแตกต่างระหว่างการบันทึกบัญชีสินค้าคงเหลือแบบต่อเนื่องและแบบสิ้นงวด (Periodic Inventory System) และขั้นตอนการปิดบัญชีรายได้ ค่าใช้จ่าย รวมถึงบัญชีที่เกี่ยวข้องกับสินค้าคงเหลือและเงินปันผล เพื่อสรุปผลการดำเนินงานและโอนไปยังบัญชีกำไรสะสม

## วัตถุประสงค์
1. สามารถจำแนกความแตกต่างระหว่างการบันทึกบัญชีสินค้าคงเหลือแบบต่อเนื่อง (Perpetual) และแบบสิ้นงวด (Periodic) ได้จากรายการบัญชีที่ปรากฏ 2. สามารถระบุบัญชีรายได้ บัญชีค่าใช้จ่าย บัญชีที่เกี่ยวข้องกับการขาย และบัญชีเงินปันผลที่ต้องทำการปิดบัญชีได้ 3. สามารถจัดทำรายการปิดบัญชีสำหรับกิจการซื้อมาขายไปตามวิธี Perpetual Inventory System ได้อย่างถูกต้องตามขั้นตอน 4. เข้าใจถึงผลกระทบของการปิดบัญชีต่อบัญชีกำไรขาดทุนและกำไรสะสม

## แนวคิดสำคัญ
การบันทึกบัญชีสินค้าคงเหลือแบบต่อเนื่อง (Perpetual Inventory System) คือวิธีการบันทึกบัญชีสินค้าคงเหลือที่ปรับปรุงยอดสินค้าและต้นทุนขายอย่างต่อเนื่องทุกครั้งที่มีการซื้อหรือขาย ทำให้ยอดคงเหลือของสินค้าคงเหลือและต้นทุนขายในงบทดลองเป็นยอด ณ วันที่นั้นๆ เสมอ การบันทึกบัญชีสินค้าคงเหลือแบบสิ้นงวด (Periodic Inventory System) คือวิธีการบันทึกบัญชีสินค้าคงเหลือที่ไม่ได้ปรับปรุงยอดสินค้าและต้นทุนขายอย่างต่อเนื่อง แต่จะบันทึกการซื้อเป็นบัญชี 'ซื้อ' และคำนวณต้นทุนขายเมื่อสิ้นงวดโดยการตรวจนับสินค้าคงเหลือปลายงวด การปิดบัญชี (Closing Entries) คือกระบวนการโอนย้ายยอดคงเหลือของบัญชีรายได้และค่าใช้จ่าย (บัญชีชั่วคราว) ไปยังบัญชีกำไรขาดทุน (Income Summary) เพื่อสรุปผลกำไรหรือขาดทุนสุทธิ และโอนไปยังบัญชีกำไรสะสม (Retained Earnings) รวมถึงการปิดบัญชีเงินปันผลด้วย บัญชีรับคืนและส่วนลด (Sales Returns and Allowances) และส่วนลดจ่าย (Sales Discounts) เป็นบัญชีปรับมูลค่ารายได้ (Contra-Revenue Accounts) ที่มีสถานะคล้ายค่าใช้จ่ายเนื่องจากทำให้ยอดขายสุทธิลดลง

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| Perpetual Inventory System | วิธีบันทึกสินค้าคงเหลือแบบต่อเนื่อง โดยปรับปรุงยอดสินค้าและต้นทุนขายทุกครั้งที่มีการซื้อขาย |
| Periodic Inventory System | วิธีบันทึกสินค้าคงเหลือแบบสิ้นงวด โดยบันทึกการซื้อเป็นบัญชีซื้อ และคำนวณต้นทุนขายเมื่อสิ้นงวดจากการตรวจนับ |
| ต้นทุนขาย (Cost of Goods Sold) | ต้นทุนของสินค้าที่กิจการขายไปในระหว่างงวด |
| ซื้อ (Purchases) | บัญชีที่ใช้บันทึกการซื้อสินค้าในวิธี Periodic |
| ค่าขนส่งเข้า (Freight-in) | ค่าใช้จ่ายในการขนส่งสินค้าที่ซื้อเข้ามาในกิจการ |
| ส่งคืน (Purchase Returns) | สินค้าที่ส่งคืนผู้ขายเนื่องจากชำรุดหรือไม่ตรงตามสั่ง |
| ส่วนลดรับ (Purchase Discounts) | ส่วนลดที่ได้รับจากการชำระหนี้ค่าสินค้าภายในเงื่อนไขที่กำหนด |
| ขาย (Sales) | รายได้หลักจากการขายสินค้าของกิจการ |
| รับคืนและส่วนลด (Sales Returns and Allowances) | สินค้าที่ลูกค้านำมาคืนหรือส่วนลดที่ให้ลูกค้าเนื่องจากสินค้ามีตำหนิ |
| ส่วนลดจ่าย (Sales Discounts) | ส่วนลดที่กิจการให้ลูกค้าเมื่อชำระเงินค่าสินค้าภายในระยะเวลาที่กำหนด |
| กำไรขาดทุน (Income Summary) | บัญชีชั่วคราวที่ใช้รวบรวมยอดรายได้และค่าใช้จ่ายเพื่อสรุปผลกำไรหรือขาดทุนสุทธิ |
| กำไรสะสม (Retained Earnings) | กำไรสุทธิที่สะสมไว้ในกิจการหลังจากหักเงินปันผลแล้ว |
| เงินปันผล (Dividends) | ส่วนแบ่งกำไรที่จ่ายคืนให้แก่ผู้ถือหุ้น |
| ค่าเสื่อมราคา (Depreciation Expense) | ค่าใช้จ่ายที่เกิดจากการปันส่วนมูลค่าของสินทรัพย์ถาวรตลอดอายุการใช้งาน |
| ดอกเบี้ยจ่าย (Interest Expense) | ค่าใช้จ่ายที่เกิดจากการกู้ยืมเงิน |

## ตัวอย่างหรือขั้นตอน
การปิดบัญชีสำหรับกิจการซื้อมาขายไป (วิธี Perpetual Inventory System) จากแบบฝึกหัดข้อ 7 มีขั้นตอนดังนี้:

**การระบุวิธีบันทึกสินค้าคงเหลือ:**
*   **ข้อ 7 (Perpetual):** สังเกตจากงบทดลองหลังปรับปรุงพบว่ามีบัญชี 'ต้นทุนขาย' (Cost of Goods Sold) ปรากฏอยู่ทันที และไม่มีบัญชี 'ซื้อ', 'ค่าขนส่งเข้า', 'ส่งคืน', 'ส่วนลดรับ' ซึ่งเป็นลักษณะของวิธี Perpetual ที่บันทึกต้นทุนขายทุกครั้งที่ขายสินค้า ทำให้ยอดสินค้าคงเหลือในงบทดลองเป็นยอด ณ วันสิ้นงวดที่ถูกต้องแล้ว
*   **ข้อ 8 (Periodic):** สังเกตจากงบทดลองพบว่ามีบัญชี 'ซื้อ', 'ขนเข้า', 'ส่งคืน', 'ส่วนลดรับ' ซึ่งเป็นลักษณะของวิธี Periodic ที่จะคำนวณต้นทุนขายเมื่อสิ้นงวดจากการตรวจนับสินค้าคงเหลือปลายงวด

**ขั้นตอนการปิดบัญชีสำหรับข้อ 7 (Perpetual Inventory System):**

**ขั้นที่ 1: ปิดบัญชีรายได้เข้าบัญชีกำไรขาดทุน**
*   บัญชีรายได้หลักคือ 'ขาย' (Sales) มียอดคงเหลือด้านเครดิต 231,450 บาท
*   **รายการปรับปรุง:**
    *   เดบิต บัญชีขาย 231,450 บาท
    *   เครดิต บัญชีกำไรขาดทุน 231,450 บาท
    *   (คำอธิบาย: ปิดรายได้เข้ากำไรขาดทุน)

**ขั้นที่ 2: ปิดบัญชีค่าใช้จ่ายและบัญชีปรับมูลค่ารายได้เข้าบัญชีกำไรขาดทุน**
*   บัญชีปรับมูลค่ารายได้ (มีลักษณะคล้ายค่าใช้จ่าย): 'รับคืนและส่วนลด' (Sales Returns and Allowances) ยอดเดบิต 1,400 บาท และ 'ส่วนลดจ่าย' (Sales Discounts) ยอดเดบิต 4,200 บาท
*   บัญชีต้นทุนขาย: 'ต้นทุนขาย' (Cost of Goods Sold) ยอดเดบิต 97,600 บาท
*   บัญชีค่าใช้จ่ายอื่นๆ:
    *   ค่าขนส่งออก (Freight-out) 1,350 บาท
    *   เงินเดือนพนักงานขาย (Sales Staff Salary) 16,800 บาท
    *   ค่าโฆษณา (Advertising Expense) 4,000 บาท
    *   ค่าเบี้ยประกันภัย (Insurance Expense) 6,000 บาท
    *   ค่าใช้จ่ายเบ็ดเตล็ด (Miscellaneous Expense) 1,600 บาท
    *   ค่าเสื่อมราคา - อาคาร (Depreciation Expense - Building) 10,000 บาท
    *   ดอกเบี้ยจ่าย (Interest Expense) 2,050 บาท
*   รวมยอดค่าใช้จ่ายและบัญชีปรับมูลค่ารายได้ทั้งหมด = 1,400 + 4,200 + 97,600 + 1,350 + 16,800 + 4,000 + 6,000 + 1,600 + 10,000 + 2,050 = 145,000 บาท
*   **รายการปรับปรุง:**
    *   เดบิต บัญชีกำไรขาดทุน 145,000 บาท
    *   เครดิต บัญชีรับคืนและส่วนลด 1,400 บาท
    *   เครดิต บัญชีส่วนลดจ่าย 4,200 บาท
    *   เครดิต บัญชีต้นทุนขาย 97,600 บาท
    *   เครดิต บัญชีค่าขนส่งออก 1,350 บาท
    *   เครดิต บัญชีเงินเดือนพนักงานขาย 16,800 บาท
    *   เครดิต บัญชีค่าโฆษณา 4,000 บาท
    *   เครดิต บัญชีค่าเบี้ยประกันภัย 6,000 บาท
    *   เครดิต บัญชีค่าใช้จ่ายเบ็ดเตล็ด 1,600 บาท
    *   เครดิต บัญชีค่าเสื่อมราคา - อาคาร 10,000 บาท
    *   เครดิต บัญชีดอกเบี้ยจ่าย 2,050 บาท
    *   (คำอธิบาย: ปิดค่าใช้จ่ายเข้ากำไรขาดทุน)

**ขั้นที่ 3: ปิดบัญชีกำไรขาดทุนเข้าบัญชีกำไรสะสม**
*   ยอดคงเหลือในบัญชีกำไรขาดทุน = รายได้ (231,450) - ค่าใช้จ่าย (145,000) = 86,450 บาท (ยอดเครดิต แสดงถึงกำไรสุทธิ)
*   **รายการปรับปรุง:**
    *   เดบิต บัญชีกำไรขาดทุน 86,450 บาท
    *   เครดิต บัญชีกำไรสะสม 86,450 บาท
    *   (คำอธิบาย: ปิดบัญชีกำไรขาดทุน)

**ขั้นที่ 4: ปิดบัญชีเงินปันผลเข้าบัญชีกำไรสะสม**
*   บัญชีเงินปันผล (Dividends) มียอดคงเหลือด้านเดบิต 9,000 บาท
*   **รายการปรับปรุง:**
    *   เดบิต บัญชีกำไรสะสม 9,000 บาท
    *   เครดิต บัญชีเงินปันผล 9,000 บาท
    *   (คำอธิบาย: ปิดบัญชีเงินปันผล)

## สรุปท้ายบท
การปิดบัญชีสำหรับกิจการซื้อมาขายไปมีความแตกต่างจากกิจการให้บริการในหลายจุดสำคัญ ได้แก่:
1.  **บัญชีรายได้:** รายได้หลักเปลี่ยนจาก 'รายได้ค่าบริการ' เป็น 'ขาย'
2.  **บัญชีปรับมูลค่ารายได้:** มีบัญชีใหม่เพิ่มเข้ามาคือ 'รับคืนและส่วนลด' และ 'ส่วนลดจ่าย' ซึ่งทำหน้าที่ลดทอนยอดขายสุทธิ และจะถูกปิดพร้อมกับบัญชีค่าใช้จ่ายอื่นๆ
3.  **บัญชีต้นทุนขาย:** เป็นค่าใช้จ่ายหลักของกิจการซื้อมาขายไป ซึ่งในวิธี Perpetual จะมียอดคงเหลือในงบทดลองที่สามารถนำมาปิดบัญชีได้ทันที ในขณะที่วิธี Periodic จะต้องคำนวณต้นทุนขายจากบัญชีสินค้าต้นงวด ซื้อสุทธิ และสินค้าปลายงวด
4.  **ความซับซ้อนในการปิดบัญชี:** แม้จะมีบัญชีเพิ่มขึ้น แต่หลักการปิดบัญชียังคงเหมือนเดิม คือการโอนบัญชีรายได้และค่าใช้จ่ายไปยังบัญชีกำไรขาดทุน และสรุปผลไปยังกำไรสะสม การทำความเข้าใจความแตกต่างเหล่านี้เป็นสิ่งสำคัญในการจัดทำงบการเงินที่ถูกต้องสำหรับกิจการซื้อมาขายไป

2. บัญชี 'รับคืนและส่วนลด' และ 'ส่วนลดจ่าย' มีสถานะทางบัญชีอย่างไร และถูกปิดบัญชีในขั้นตอนใด?

5. ขั้นตอนสุดท้ายของการปิดบัญชีคือการปิดบัญชีใด และมีผลกระทบต่อบัญชีใดบ้าง?
