# บทที่5ตอนที่14แบบฝึกหัดข้อ10ตอนที่4จบ

## บทนำ
บทเรียนนี้มุ่งเน้นการจัดทำงบกำไรขาดทุนสำหรับกิจการซื้อมาขายไป โดยเฉพาะอย่างยิ่งการคำนวณต้นทุนขายภายใต้วิธีการบันทึกบัญชีสินค้าคงเหลือแบบ Periodic (สิ้นงวด) ซึ่งแตกต่างจากการบันทึกบัญชีแบบ Perpetual (ต่อเนื่อง) และการจัดทำงบกำไรขาดทุนสำหรับกิจการให้บริการ โดยจะแสดงให้เห็นถึงโครงสร้างและรายการที่สำคัญในการคำนวณยอดขายสุทธิ ต้นทุนขาย และกำไรขั้นต้น

## วัตถุประสงค์
1. เข้าใจความแตกต่างของการนำเสนอรายการในงบกำไรขาดทุนระหว่างกิจการให้บริการและกิจการซื้อมาขายไป 2. สามารถคำนวณหายอดขายสุทธิ (Net Sales) ได้อย่างถูกต้อง โดยพิจารณารายการหักต่างๆ 3. สามารถคำนวณหาต้นทุนขาย (Cost of Goods Sold) ภายใต้วิธีการบันทึกบัญชีสินค้าคงเหลือแบบ Periodic ได้อย่างละเอียด 4. สามารถคำนวณหากำไรขั้นต้น (Gross Profit) จากยอดขายสุทธิและต้นทุนขาย

## แนวคิดสำคัญ
งบกำไรขาดทุนของกิจการซื้อมาขายไปจะเริ่มต้นด้วย 'ขาย' แทน 'รายได้ค่าบริการ' การคำนวณยอดขายสุทธิจะต้องหักรายการรับคืนและส่วนลด รวมถึงส่วนลดจ่ายออกจากยอดขายรวม การคำนวณต้นทุนขายภายใต้วิธี Periodic จะต้องนำสินค้าต้นงวดบวกด้วยซื้อสุทธิ (ซึ่งประกอบด้วยซื้อบวกค่าขนส่งเข้า หักส่งคืนและส่วนลด และส่วนลดรับ) เพื่อหาสินค้าที่มีไว้เพื่อขายทั้งสิ้น จากนั้นจึงหักสินค้าปลายงวดออกไป การบันทึกบัญชีแบบ Periodic เหมาะสำหรับกิจการที่มีสินค้าจำนวนมากและมีมูลค่าต่อหน่วยไม่สูงมากนัก เช่น ร้านอาหาร ในขณะที่วิธี Perpetual เหมาะสำหรับกิจการที่มีสินค้ามูลค่าสูงและจำนวนไม่มาก เช่น รถยนต์หรือเพชร

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| Periodic Inventory System (วิธีสิ้นงวด) | ระบบการบันทึกบัญชีสินค้าคงเหลือที่ไม่ได้บันทึกต้นทุนขายทุกครั้งที่มีการขาย แต่จะทำการตรวจนับสินค้าคงเหลือ ณ วันสิ้นงวดเพื่อคำนวณต้นทุนขาย |
| Perpetual Inventory System (วิธีต่อเนื่อง) | ระบบการบันทึกบัญชีสินค้าคงเหลือที่บันทึกต้นทุนขายทุกครั้งที่มีการขาย ทำให้ทราบยอดสินค้าคงเหลือและต้นทุนขายได้ตลอดเวลา |
| Net Sales (ขายสุทธิ) | ยอดขายรวมที่หักด้วยรายการรับคืนและส่วนลดจากการขาย และส่วนลดจ่ายแล้ว |
| Sales Returns and Allowances (รับคืนและส่วนลด) | รายการที่ลูกค้าส่งคืนสินค้าหรือได้รับส่วนลดเนื่องจากสินค้ามีตำหนิหรือไม่ตรงตามที่สั่ง |
| Sales Discounts (ส่วนลดจ่าย) | ส่วนลดที่กิจการให้แก่ลูกค้าเพื่อจูงใจให้ชำระหนี้เร็วขึ้น |
| Cost of Goods Sold (ต้นทุนขาย) | ต้นทุนของสินค้าที่กิจการขายไปในระหว่างงวดบัญชี |
| Beginning Inventory (สินค้าต้นงวด) | มูลค่าสินค้าคงเหลือ ณ วันเริ่มต้นงวดบัญชี |
| Purchases (ซื้อ) | มูลค่าสินค้าที่กิจการซื้อมาเพื่อขายในระหว่างงวด |
| Freight-in (ค่าขนส่งเข้า) | ค่าใช้จ่ายในการขนส่งสินค้าที่ซื้อมายังกิจการ |
| Purchase Returns and Allowances (ส่งคืนและส่วนลด) | รายการที่กิจการส่งคืนสินค้าที่ซื้อมา หรือได้รับส่วนลดจากผู้ขายเนื่องจากสินค้ามีตำหนิหรือไม่ตรงตามที่สั่ง |
| Purchase Discounts (ส่วนลดรับ) | ส่วนลดที่กิจการได้รับจากผู้ขายเพื่อจูงใจให้ชำระหนี้เร็วขึ้น |
| Net Purchases (ซื้อสุทธิ) | ยอดซื้อรวมที่บวกค่าขนส่งเข้า และหักด้วยรายการส่งคืนและส่วนลดจากการซื้อ และส่วนลดรับแล้ว |
| Goods Available for Sale (สินค้าที่มีไว้เพื่อขายทั้งสิ้น) | มูลค่ารวมของสินค้าคงเหลือต้นงวดและสินค้าที่ซื้อสุทธิในระหว่างงวด ซึ่งเป็นสินค้าทั้งหมดที่พร้อมจะขาย |
| Ending Inventory (สินค้าปลายงวด) | มูลค่าสินค้าคงเหลือ ณ วันสิ้นงวดบัญชี ซึ่งมาจากการตรวจนับ |
| Gross Profit (กำไรขั้นต้น) | ผลต่างระหว่างยอดขายสุทธิและต้นทุนขาย |

## ตัวอย่างหรือขั้นตอน
การจัดทำงบกำไรขาดทุนสำหรับกิจการซื้อมาขายไป (วิธี Periodic) ของบริษัท หน้าข้าว จำกัด สำหรับงวด 1 ปี สิ้นสุดวันที่ 31 ธันวาคม 25x1 มีดังนี้:

**1. การคำนวณยอดขายสุทธิ (Net Sales)**
*   ขาย (Sales): 316,500 บาท
*   หัก: รับคืนและส่วนลด (Sales Returns and Allowances): 1,800 บาท
*   หัก: ส่วนลดจ่าย (Sales Discounts): 1,500 บาท
*   รวมรายการหัก: 1,800 + 1,500 = 3,300 บาท
*   **ขายสุทธิ (Net Sales): 316,500 - 3,300 = 313,200 บาท**

**2. การคำนวณต้นทุนขาย (Cost of Goods Sold)**
*   สินค้าต้นงวด (Beginning Inventory): 46,000 บาท
*   บวก: ซื้อสุทธิ (Net Purchases)
    *   ซื้อ (Purchases): 155,000 บาท
    *   บวก: ค่าขนส่งเข้า (Freight-in): 2,000 บาท
    *   ซื้อทั้งสิ้น (Total Purchases): 155,000 + 2,000 = 157,000 บาท
    *   หัก: ส่งคืนและส่วนลด (Purchase Returns and Allowances): 1,800 บาท
    *   หัก: ส่วนลดรับ (Purchase Discounts): 1,200 บาท
    *   รวมรายการหัก: 1,800 + 1,200 = 3,000 บาท
    *   **ซื้อสุทธิ (Net Purchases): 157,000 - 3,000 = 154,000 บาท**
*   สินค้าที่มีไว้เพื่อขายทั้งสิ้น (Goods Available for Sale): 46,000 (สินค้าต้นงวด) + 154,000 (ซื้อสุทธิ) = 200,000 บาท
*   หัก: สินค้าปลายงวด (Ending Inventory): 10,700 บาท
*   **ต้นทุนขาย (Cost of Goods Sold): 200,000 - 10,700 = 189,300 บาท**

**3. การคำนวณกำไรขั้นต้น (Gross Profit)**
*   **กำไรขั้นต้น (Gross Profit): 313,200 (ขายสุทธิ) - 189,300 (ต้นทุนขาย) = 123,900 บาท**

ส่วนประกอบอื่นๆ ของงบกำไรขาดทุน เช่น รายได้อื่น ค่าใช้จ่ายในการดำเนินงาน ดอกเบี้ย และภาษี จะถูกนำมาคำนวณต่อจากกำไรขั้นต้นในลักษณะเดียวกันกับกิจการประเภทอื่นๆ

## สรุปท้ายบท
การจัดทำงบกำไรขาดทุนสำหรับกิจการซื้อมาขายไปภายใต้วิธี Periodic มีความแตกต่างอย่างชัดเจนจากกิจการให้บริการและวิธี Perpetual โดยเฉพาะในส่วนของการคำนวณยอดขายสุทธิและต้นทุนขาย ซึ่งต้องมีการแยกแสดงรายการหักต่างๆ อย่างละเอียดเพื่อให้ข้อมูลที่ถูกต้องและเป็นประโยชน์ต่อการวิเคราะห์ประสิทธิภาพของกิจการ การแยกรายการรับคืน ส่วนลดจ่าย ส่งคืน และส่วนลดรับออกจากยอดรวมจะช่วยให้ผู้บริหารสามารถประเมินผลการดำเนินงานและเปรียบเทียบกับคู่แข่งได้อย่างมีประสิทธิภาพ วิธี Periodic เหมาะสำหรับธุรกิจที่มีการซื้อขายสินค้าจำนวนมากและมีมูลค่าต่อหน่วยต่ำ ในขณะที่วิธี Perpetual เหมาะสำหรับสินค้าที่มีมูลค่าสูงและจำนวนน้อย เพื่อให้สามารถติดตามต้นทุนขายและสินค้าคงเหลือได้อย่างแม่นยำตลอดเวลา

2. ในการคำนวณยอดขายสุทธิ มีรายการใดบ้างที่ต้องนำมาหักออกจากยอดขายรวม?
