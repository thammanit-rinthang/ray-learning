# บทที่5ตอนที่1การดำเนินการซื้อขายสินค้า

## บทนำ
บทที่ 5 ตอนที่ 1 นี้จะกล่าวถึงการบัญชีสำหรับกิจการซื้อขายสินค้า (Accounting for Merchandising Firms) ซึ่งแตกต่างจาก 4 บทแรกที่เน้นการบัญชีสำหรับธุรกิจบริการ (Service Firms) ที่มีเพียงวัสดุสิ้นเปลืองและไม่มีสินค้าคงเหลือ กิจการซื้อขายสินค้าจะมีความซับซ้อนมากกว่าธุรกิจบริการ เนื่องจากมีการดำเนินงานที่เกี่ยวข้องกับการซื้อและขายสินค้า กิจการซื้อขายสินค้าแบ่งออกเป็น 2 ประเภทหลัก ได้แก่ กิจการซื้อมาขายไป (Merchandise Firms) ซึ่งเน้นการซื้อสินค้าสำเร็จรูปมาจำหน่ายโดยตรง และกิจการอุตสาหกรรม (Manufacturing Firms) ซึ่งเกี่ยวข้องกับการซื้อวัตถุดิบมาแปรรูปเป็นสินค้าสำเร็จรูป บทเรียนนี้จะเน้นไปที่กิจการซื้อมาขายไปเป็นหลัก โดยจะอธิบายถึงกระบวนการและเอกสารที่เกี่ยวข้องกับการดำเนินงานซื้อขายสินค้า รวมถึงบทบาทของแผนกต่างๆ และความสำคัญของการควบคุมภายใน

## วัตถุประสงค์
วัตถุประสงค์ของบทเรียนนี้คือเพื่อให้ผู้เรียนเข้าใจความหมายและลักษณะของกิจการซื้อขายสินค้าประเภทซื้อมาขายไป สามารถอธิบายกระบวนการดำเนินงานที่เกี่ยวข้องกับการซื้อขายสินค้าได้อย่างละเอียด รวมถึงบทบาทหน้าที่ของแผนกต่างๆ ที่เกี่ยวข้อง และเข้าใจถึงความสำคัญของการควบคุมภายในในการดำเนินงานซื้อขายสินค้า เพื่อป้องกันการทุจริตและเพิ่มประสิทธิภาพในการทำงาน นอกจากนี้ยังมุ่งเน้นให้เข้าใจถึงเอกสารหลักฐานที่ใช้ในแต่ละขั้นตอนของวงจรการซื้อขายสินค้า และบทบาทของแผนกบัญชีในการบันทึกรายการค้าที่เกิดขึ้น

## แนวคิดสำคัญ
แนวคิดสำคัญในบทเรียนนี้คือการทำความเข้าใจความแตกต่างระหว่างธุรกิจบริการและกิจการซื้อขายสินค้า โดยกิจการซื้อขายสินค้าจะมีการดำเนินงานที่ซับซ้อนกว่าเนื่องจากมีสินค้าคงเหลือเข้ามาเกี่ยวข้อง กิจการซื้อขายสินค้าแบ่งเป็น 2 ประเภทหลักคือ กิจการซื้อมาขายไป (Merchandise Firms) ที่ซื้อสินค้าสำเร็จรูปมาขาย และกิจการอุตสาหกรรม (Manufacturing Firms) ที่ซื้อวัตถุดิบมาผลิตเป็นสินค้าสำเร็จรูป การซื้อขายสินค้าสามารถแบ่งเป็นการขายปลีก (Retailing) ให้กับลูกค้ารายย่อย และการขายส่ง (Wholesaling) ให้กับลูกค้ารายใหญ่หรือผู้ค้าปลีก การดำเนินงานซื้อขายสินค้าที่ดีต้องมีการแบ่งแยกหน้าที่ความรับผิดชอบของแผนกต่างๆ เพื่อให้เกิดการควบคุมภายในที่ดีและป้องกันการทุจริต โดยมี 5 แผนกหลักที่เกี่ยวข้อง ได้แก่ แผนกคลังสินค้า แผนกจัดซื้อ แผนกตรวจรับสินค้า แผนกขาย และแผนกบัญชี ซึ่งแต่ละแผนกมีบทบาทและเอกสารที่เกี่ยวข้องเฉพาะตัว เช่น ใบขอซื้อ (Purchase Requisition Slip) จากแผนกคลังสินค้า ใบสั่งซื้อ (Purchase Order) จากแผนกจัดซื้อ และใบตรวจรับ (Inventory Receiving Slip) จากแผนกตรวจรับสินค้า แผนกบัญชีมีบทบาทสำคัญในการรวบรวมเอกสารทั้งหมดเพื่อบันทึกรายการค้า

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| กิจการซื้อมาขายไป (Merchandise Firms) | กิจการที่ดำเนินงานโดยการซื้อสินค้าสำเร็จรูปมาจำหน่ายให้กับลูกค้าโดยตรง |
| กิจการอุตสาหกรรม (Manufacturing Firms) | กิจการที่ซื้อวัตถุดิบมาแปรรูปเป็นสินค้าสำเร็จรูปก่อนนำออกจำหน่าย |
| ขายปลีก (Retailing) | การจำหน่ายสินค้าให้กับลูกค้ารายย่อย |
| ขายส่ง (Wholesaling) | การจำหน่ายสินค้าให้กับลูกค้ารายใหญ่หรือผู้ค้าปลีก |
| ใบขอซื้อ (Purchase Requisition Slip - PR) | เอกสารที่แผนกคลังสินค้าจัดทำขึ้นเพื่อแจ้งความต้องการซื้อสินค้าไปยังแผนกจัดซื้อ |
| ใบสั่งซื้อ (Purchase Order - PO) | เอกสารที่แผนกจัดซื้อออกให้ผู้ขายสินค้าเพื่อสั่งซื้อสินค้าตามที่ต้องการ |
| ใบตรวจรับ (Inventory Receiving Slip) | เอกสารที่แผนกตรวจรับสินค้าจัดทำขึ้นเพื่อยืนยันการรับสินค้าที่ถูกต้องตรงตามใบสั่งซื้อ |
| ใบเสร็จรับเงิน (Cash Receipt) | เอกสารที่ออกให้ลูกค้าเมื่อมีการขายสินค้าเป็นเงินสด |
| ใบกำกับสินค้า (Sales Invoice) | เอกสารที่ออกให้ลูกค้าเมื่อมีการขายสินค้าเป็นเงินเชื่อ หรือใช้เป็นหลักฐานการส่งมอบสินค้า |
| แผนกคลังสินค้า | แผนกที่มีหน้าที่จัดเก็บ ดูแล และตรวจสอบปริมาณสินค้าคงเหลือ |
| แผนกจัดซื้อ | แผนกที่มีหน้าที่ดำเนินการจัดซื้อสินค้าตามใบขอซื้อ |
| แผนกตรวจรับสินค้า | แผนกที่มีหน้าที่ตรวจสอบและรับสินค้าที่ผู้ขายนำมาส่งให้ถูกต้องตรงตามใบสั่งซื้อ |
| แผนกขาย | แผนกที่มีหน้าที่เบิกสินค้าเพื่อจำหน่ายให้กับลูกค้า |
| แผนกบัญชี | แผนกที่มีหน้าที่รวบรวมเอกสารและบันทึกรายการค้าที่เกิดขึ้นในวงจรการซื้อขายสินค้า |
| การควบคุมภายใน | ระบบและกระบวนการที่ออกแบบมาเพื่อป้องกันการทุจริตและเพิ่มประสิทธิภาพในการดำเนินงาน โดยเฉพาะการแบ่งแยกหน้าที่ความรับผิดชอบ |

## ตัวอย่างหรือขั้นตอน
การดำเนินงานซื้อขายสินค้าของกิจการซื้อมาขายไปมีความซับซ้อนกว่าธุรกิจบริการ โดยมี 5 แผนกหลักที่เกี่ยวข้องและมีบทบาทสำคัญในการควบคุมภายใน ดังนี้: 1. แผนกคลังสินค้า: มีหน้าที่จัดเก็บสินค้าที่ซื้อมาเพื่อขาย และตรวจสอบปริมาณสินค้าคงเหลือ เมื่อปริมาณสินค้าลดลงถึงจุดต่ำสุดที่กำหนด แผนกคลังสินค้าจะจัดทำเอกสาร 'ใบขอซื้อ' (Purchase Requisition Slip) เพื่อแสดงรายละเอียดสินค้าที่ต้องการซื้อ และส่งให้แผนกจัดซื้อ โดยมีสำเนาส่งให้แผนกบัญชีเพื่อเป็นหลักฐานประกอบการบันทึกบัญชี และเก็บสำเนาไว้สำหรับแผนกคลังสินค้าเอง การที่แผนกคลังสินค้าไม่สามารถสั่งซื้อเองได้เป็นการควบคุมภายในเพื่อป้องกันการทุจริต 2. แผนกจัดซื้อ: มีหน้าที่ดำเนินการจัดซื้อสินค้าตามใบขอซื้อที่ได้รับจากแผนกคลังสินค้า แผนกจัดซื้อจะตรวจสอบความถูกต้องของใบขอซื้อ รวมถึงการอนุมัติ และอาจสุ่มตรวจสต็อกจริงก่อนที่จะออก 'ใบสั่งซื้อ' (Purchase Order) ซึ่งเป็นเอกสารที่ส่งให้ผู้ขายสินค้าหรือเจ้าหนี้การค้าของกิจการ โดยมีสำเนาส่งให้แผนกบัญชีเพื่อตรวจสอบ และส่งให้แผนกตรวจรับสินค้าเพื่อใช้เป็นหลักฐานในการรับสินค้า 3. แผนกตรวจรับสินค้า: มีหน้าที่ตรวจสอบและรับสินค้าที่ผู้ขายนำมาส่ง โดยอ้างอิงจากใบสั่งซื้อที่ได้รับจากแผนกจัดซื้อ และต้องตรวจนับสินค้าให้ถูกต้องตรงตามใบสั่งซื้อ หากถูกต้องจะจัดทำ 'ใบตรวจรับ' (Inventory Receiving Slip) โดยมีต้นฉบับส่งให้แผนกบัญชีเพื่อบันทึกบัญชี สำเนาส่งให้แผนกจัดซื้อเพื่อตรวจสอบ และสำเนาส่งให้แผนกคลังสินค้าเพื่อใช้ตรวจสอบกับสินค้าที่ได้รับ การแบ่งแยกหน้าที่ระหว่างผู้ขอซื้อ ผู้สั่งซื้อ และผู้รับสินค้า เป็นการควบคุมภายในที่สำคัญ 4. แผนกขาย: มีหน้าที่ในการจำหน่ายสินค้าให้กับลูกค้า เมื่อได้รับคำสั่งซื้อจากลูกค้า แผนกขายจะทำ 'ใบเบิก' สินค้าจากคลังสินค้าเพื่อนำไปขาย หากเป็นการขายสด จะออก 'ใบเสร็จรับเงิน' (Cash Receipt) ให้ลูกค้า หากเป็นการขายเชื่อ จะออก 'ใบกำกับสินค้า' (Sales Invoice) หรือใบส่งของ เพื่อเป็นหลักฐานการขาย โดยมีต้นฉบับให้ลูกค้า และสำเนาส่งให้แผนกบัญชี 5. แผนกบัญชี: เป็นแผนกที่มีบทบาทสำคัญที่สุดในการรวบรวมเอกสารทั้งหมดจากทุกแผนกที่เกี่ยวข้อง ตั้งแต่ใบขอซื้อ ใบสั่งซื้อ ใบตรวจรับ ใบเสร็จรับเงิน และใบกำกับสินค้า เพื่อใช้เป็นหลักฐานในการบันทึกรายการค้าที่เกิดขึ้นในวงจรการซื้อขายสินค้า ตั้งแต่การซื้อจนถึงการขายสินค้าออกไป แผนกบัญชีจะรู้ทุกเรื่องที่เกี่ยวกับตัวเงินของธุรกิจและเป็นศูนย์กลางข้อมูลทางการเงิน

## สรุปท้ายบท
การบัญชีสำหรับกิจการซื้อขายสินค้ามีความซับซ้อนและมีรายละเอียดมากกว่าธุรกิจบริการอย่างมาก เนื่องจากมีสินค้าคงเหลือเข้ามาเกี่ยวข้องและมีกระบวนการดำเนินงานหลายขั้นตอน การควบคุมภายในที่ดีเป็นสิ่งสำคัญอย่างยิ่งในการดำเนินงานซื้อขายสินค้า เพื่อป้องกันการทุจริตและเพิ่มประสิทธิภาพ โดยเฉพาะการแบ่งแยกหน้าที่ความรับผิดชอบของแผนกต่างๆ เช่น แผนกคลังสินค้า แผนกจัดซื้อ แผนกตรวจรับสินค้า และแผนกขาย แผนกบัญชีมีบทบาทสำคัญและเป็นศูนย์กลางในการรวบรวมเอกสารหลักฐานทั้งหมดจากทุกแผนก เพื่อใช้ในการบันทึกรายการค้าที่เกิดขึ้นในวงจรการซื้อขายสินค้าตั้งแต่ต้นจนจบ ทำให้แผนกบัญชีมีความเข้าใจในทุกธุรกรรมทางการเงินของกิจการ

## คำถามทบทวน
1. กิจการซื้อขายสินค้าแตกต่างจากธุรกิจบริการอย่างไร และมีกิจการซื้อขายสินค้ากี่ประเภท อะไรบ้าง
2. อธิบายบทบาทและหน้าที่ของแผนกคลังสินค้าและแผนกจัดซื้อในการดำเนินงานซื้อขายสินค้า พร้อมระบุเอกสารหลักฐานที่เกี่ยวข้อง
3. เหตุใดการแบ่งแยกหน้าที่ระหว่างแผนกคลังสินค้า แผนกจัดซื้อ และแผนกตรวจรับสินค้าจึงมีความสำคัญต่อการควบคุมภายใน
4. แผนกตรวจรับสินค้ามีหน้าที่อะไร และใช้เอกสารใดเป็นหลักฐานในการตรวจสอบสินค้าที่ได้รับ
5. แผนกบัญชีมีบทบาทสำคัญอย่างไรในวงจรการซื้อขายสินค้า และได้รับเอกสารอะไรบ้างจากแผนกอื่นๆ
