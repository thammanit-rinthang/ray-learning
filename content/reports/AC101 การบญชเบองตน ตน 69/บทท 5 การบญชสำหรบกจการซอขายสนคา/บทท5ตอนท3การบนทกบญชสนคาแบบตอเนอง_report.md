# บทที่5ตอนที่3การบันทึกบัญชีสินค้าแบบต่อเนื่อง

## บทนำ
บทเรียนนี้จะอธิบายเกี่ยวกับการบันทึกบัญชีสำหรับกิจการซื้อมาขายไป โดยเน้นที่วิธีการบันทึกบัญชีสินค้าคงเหลือแบบต่อเนื่อง (Perpetual Inventory Method) ซึ่งแตกต่างจากการบันทึกบัญชีของกิจการให้บริการที่ได้เรียนรู้มาแล้ว กิจการซื้อมาขายไปจะมีรายการค้าทั่วไปคล้ายกับธุรกิจบริการ เช่น การลงทุนของเจ้าของ การซื้อสินทรัพย์ การรับชำระหนี้ การจ่ายชำระหนี้ การจ่ายค่าใช้จ่าย และการปรับปรุง ณ วันสิ้นงวด แต่จะมีรายได้หลักมาจากการขายสินค้า และมีรายการบัญชีที่เกี่ยวข้องกับการซื้อและขายสินค้าเพิ่มขึ้น 8 รายการ ซึ่งจะแบ่งเป็น 4 รายการสำหรับการซื้อ และ 4 รายการสำหรับการขาย บทเรียนนี้จะเน้นการทำความเข้าใจหลักการและวิธีการบันทึกบัญชีสำหรับรายการเหล่านี้โดยละเอียด

## วัตถุประสงค์
เมื่อจบบทเรียนนี้ ผู้เรียนจะสามารถ: 1. เข้าใจหลักการและวิธีการบันทึกบัญชีสินค้าคงเหลือแบบต่อเนื่อง (Perpetual Inventory Method) ได้อย่างถูกต้อง 2. ระบุและบันทึกบัญชีรายการค้าที่เกี่ยวข้องกับการซื้อสินค้า 4 รายการ ได้แก่ การซื้อสินค้า ค่าขนส่งเข้า การส่งคืนสินค้า และส่วนลดรับ 3. ระบุและบันทึกบัญชีรายการค้าที่เกี่ยวข้องกับการขายสินค้า 4 รายการ ได้แก่ การขายสินค้า ค่าขนส่งออก การรับคืนและส่วนลด และส่วนลดจ่าย 4. อธิบายความแตกต่างและข้อดีข้อเสียของการบันทึกบัญชีสินค้าคงเหลือแบบต่อเนื่องได้

## แนวคิดสำคัญ
การบันทึกบัญชีสินค้าคงเหลือแบบต่อเนื่อง (Perpetual Inventory Method) คือวิธีการบันทึกบัญชีที่สินค้าคงเหลือจะถูกปรับปรุงทุกครั้งที่มีการเปลี่ยนแปลง ไม่ว่าจะเป็นการเพิ่มขึ้นหรือลดลง โดยจะเดบิตบัญชีสินค้าคงเหลือเมื่อสินค้าเพิ่มขึ้น และเครดิตบัญชีสินค้าคงเหลือเมื่อสินค้าลดลง วิธีนี้ทำให้ยอดสินค้าคงเหลือและต้นทุนขายในบัญชีตรงกับยอดสินค้าจริงตลอดเวลา เหมาะสำหรับกิจการที่ขายสินค้าที่มีมูลค่าสูงหรือมีจำนวนรายการไม่มากนัก เพื่อให้สามารถควบคุมสินค้าได้ดีและทราบต้นทุนขายได้ทันทีที่เกิดการขาย

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| การบันทึกบัญชีสินค้าคงเหลือแบบต่อเนื่อง (Perpetual Inventory Method) | วิธีการบันทึกบัญชีที่ปรับปรุงยอดสินค้าคงเหลือและต้นทุนขายทุกครั้งที่มีการซื้อ ขาย หรือเปลี่ยนแปลงสินค้า |
| FOB Shipping Point | เงื่อนไขการส่งมอบสินค้าที่ผู้ซื้อเป็นผู้รับผิดชอบค่าขนส่งและกรรมสิทธิ์ในสินค้าโอนเมื่อสินค้าออกจากคลังผู้ขาย |
| FOB Destination | เงื่อนไขการส่งมอบสินค้าที่ผู้ขายเป็นผู้รับผิดชอบค่าขนส่งและกรรมสิทธิ์ในสินค้าโอนเมื่อสินค้าถึงมือผู้ซื้อ |
| ค่าขนส่งเข้า (Freight-in) | ค่าใช้จ่ายในการขนส่งสินค้าที่ซื้อมา ซึ่งถือเป็นส่วนหนึ่งของต้นทุนสินค้าในวิธี Perpetual |
| ค่าขนส่งออก (Freight-out) | ค่าใช้จ่ายในการขนส่งสินค้าที่ขายไป ซึ่งถือเป็นค่าใช้จ่ายในการขาย |
| ส่วนลดรับ (Purchase Discount) | ส่วนลดที่ผู้ซื้อได้รับจากการชำระหนี้ค่าสินค้าภายในระยะเวลาที่กำหนด ซึ่งจะลดต้นทุนสินค้า |
| ส่วนลดจ่าย (Sales Discount) | ส่วนลดที่ผู้ขายมอบให้แก่ลูกค้าที่ชำระหนี้ค่าสินค้าภายในระยะเวลาที่กำหนด ซึ่งจะลดรายได้จากการขาย |
| รับคืนและส่วนลด (Sales Returns and Allowances) | รายการที่เกิดขึ้นเมื่อลูกค้าส่งคืนสินค้าหรือได้รับส่วนลดเนื่องจากสินค้าชำรุดหรือไม่ตรงตามสั่ง ซึ่งจะลดรายได้จากการขาย |
| ต้นทุนขาย (Cost of Goods Sold) | ต้นทุนของสินค้าที่ขายไป ซึ่งจะบันทึกทุกครั้งที่มีการขายสินค้าในวิธี Perpetual |
| เจ้าหนี้การค้า (Accounts Payable) | หนี้สินที่กิจการค้างชำระค่าสินค้าหรือบริการที่ซื้อมา |
| ลูกหนี้การค้า (Accounts Receivable) | สินทรัพย์ที่กิจการมีสิทธิเรียกร้องจากลูกค้าจากการขายสินค้าหรือบริการ |

## ตัวอย่างหรือขั้นตอน
การบันทึกบัญชีสำหรับกิจการซื้อมาขายไปด้วยวิธี Perpetual Inventory Method มี 8 รายการหลักที่เพิ่มขึ้นมา ดังนี้: 1. การบันทึกบัญชีเกี่ยวกับการซื้อสินค้า (4 รายการ) 1.1. การซื้อสินค้า: เป็นการบันทึกเมื่อกิจการได้รับสินค้าคงเหลือเข้ามา โดยเดบิต 'สินค้าคงเหลือ' และเครดิต 'เงินสด' (ถ้าซื้อสด) หรือ 'เจ้าหนี้การค้า' (ถ้าซื้อเชื่อ) 1.2. การจ่ายค่าขนส่งเข้า: ค่าขนส่งเข้าถือเป็นส่วนหนึ่งของต้นทุนสินค้าที่ทำให้สินค้าพร้อมขาย ดังนั้นจึงเดบิต 'สินค้าคงเหลือ' และเครดิต 'เงินสด' (ถ้าจ่ายเอง) หรือ 'เจ้าหนี้การค้า' (ถ้าผู้ขายจ่ายแทนไปก่อนในกรณี FOB Shipping Point) 1.3. การส่งคืนสินค้า: เมื่อสินค้าที่ซื้อมาไม่ตรงตามสั่งหรือชำรุดเสียหายและมีการส่งคืน จะเดบิต 'เงินสด' (ถ้าเคยจ่ายสด) หรือ 'เจ้าหนี้การค้า' (ถ้าซื้อเชื่อ) และเครดิต 'สินค้าคงเหลือ' เพื่อลดมูลค่าสินค้า 1.4. ส่วนลดรับ: เมื่อชำระหนี้ค่าสินค้าภายในเงื่อนไขที่ได้รับส่วนลดเงินสด จะเดบิต 'เจ้าหนี้การค้า' ด้วยยอดเต็ม เครดิต 'เงินสด' ด้วยยอดที่จ่ายจริง และเครดิต 'สินค้าคงเหลือ' ด้วยจำนวนส่วนลดที่ได้รับ เพื่อลดต้นทุนสินค้า 2. การบันทึกบัญชีเกี่ยวกับการขายสินค้า (4 รายการ) 2.1. การขายสินค้า: มี 2 รายการบันทึกบัญชี คือ:     *   บันทึกรายได้: เดบิต 'เงินสด' (ถ้าขายสด) หรือ 'ลูกหนี้การค้า' (ถ้าขายเชื่อ) และเครดิต 'ขาย'     *   บันทึกต้นทุนขาย: เดบิต 'ต้นทุนขาย' และเครดิต 'สินค้าคงเหลือ' เพื่อแสดงว่าสินค้าได้ถูกขายออกไปแล้ว 2.2. การจ่ายค่าขนส่งออก: ค่าขนส่งออกถือเป็นค่าใช้จ่ายในการขาย ไม่ใช่ต้นทุนสินค้า ดังนั้นจะเดบิต 'ค่าขนส่งออก' และเครดิต 'เงินสด' (ถ้าจ่ายเอง) หรือ 'ลูกหนี้การค้า' (ถ้าผู้ซื้อจ่ายแทนไปก่อนในกรณี FOB Destination) 2.3. การรับคืนและส่วนลด: เมื่อลูกค้าส่งคืนสินค้าหรือได้รับส่วนลด มี 2 รายการบันทึกบัญชี คือ:     *   บันทึกการลดลงของรายได้: เดบิต 'รับคืนและส่วนลด' (เป็นบัญชีหมวดรายได้ที่อยู่ด้านเดบิต) และเครดิต 'เงินสด' (ถ้าคืนเงินสด) หรือ 'ลูกหนี้การค้า' (ถ้ายังไม่ได้รับชำระ)     *   บันทึกการเพิ่มขึ้นของสินค้าคงเหลือ: เดบิต 'สินค้าคงเหลือ' และเครดิต 'ต้นทุนขาย' เพื่อนำสินค้าที่รับคืนกลับเข้าคลังและลดต้นทุนขาย 2.4. ส่วนลดจ่าย: เมื่อลูกค้าชำระหนี้ค่าสินค้าภายในเงื่อนไขที่ได้รับส่วนลดเงินสด จะเดบิต 'เงินสด' ด้วยยอดที่ได้รับจริง เดบิต 'ส่วนลดจ่าย' (เป็นบัญชีหมวดรายได้ที่อยู่ด้านเดบิต) และเครดิต 'ลูกหนี้การค้า' ด้วยยอดเต็ม

## สรุปท้ายบท
การบันทึกบัญชีสินค้าคงเหลือแบบต่อเนื่อง (Perpetual Inventory Method) มีข้อดีคือช่วยให้กิจการสามารถทราบยอดสินค้าคงเหลือและต้นทุนขายได้อย่างถูกต้องและเป็นปัจจุบันตลอดเวลา ทำให้ง่ายต่อการควบคุมสินค้าและสามารถตรวจสอบความถูกต้องของสินค้าคงเหลือได้ทันทีที่ต้องการ โดยเฉพาะอย่างยิ่งสำหรับสินค้าที่มีมูลค่าสูง เช่น รถยนต์ อัญมณี หรือเครื่องใช้ไฟฟ้า อย่างไรก็ตาม วิธีนี้อาจมีความซับซ้อนและยุ่งยากหากกิจการมีสินค้าหลากหลายชนิดและมีปริมาณมาก เนื่องจากต้องบันทึกการเปลี่ยนแปลงของสินค้าทุกครั้ง ทำให้ต้องใช้ระบบที่รองรับการบันทึกข้อมูลจำนวนมากและละเอียด

## คำถามทบทวน
1. อธิบายความแตกต่างหลักระหว่างการบันทึกบัญชีสินค้าคงเหลือแบบต่อเนื่อง (Perpetual) และแบบสิ้นงวด (Periodic) พร้อมยกตัวอย่างสถานการณ์ที่เหมาะสมกับแต่ละวิธี
2. ในวิธี Perpetual Inventory Method การบันทึกบัญชี 'สินค้าคงเหลือ' จะเพิ่มขึ้นหรือลดลงด้วยรายการใดบ้าง จงยกตัวอย่างประกอบ
3. หากกิจการซื้อสินค้าโดยมีเงื่อนไข FOB Shipping Point และผู้ขายจ่ายค่าขนส่งแทนไปก่อน กิจการผู้ซื้อจะบันทึกบัญชีค่าขนส่งนี้อย่างไรในวิธี Perpetual
4. เมื่อกิจการขายสินค้าด้วยวิธี Perpetual Inventory Method จะต้องบันทึกบัญชีทั้งหมดกี่รายการ และแต่ละรายการมีผลต่อบัญชีใดบ้าง
5. อธิบายเหตุผลที่กิจการควรบันทึก 'รับคืนและส่วนลด' และ 'ส่วนลดจ่าย' แยกต่างหากจากบัญชี 'ขาย' ในวิธี Perpetual
