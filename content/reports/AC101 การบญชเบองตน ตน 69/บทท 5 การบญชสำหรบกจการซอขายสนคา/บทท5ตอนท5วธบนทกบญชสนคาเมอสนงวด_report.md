# บทที่5ตอนที่5วิธีบันทึกบัญชีสินค้าเมื่อสิ้นงวด

## บทนำ
บทเรียนนี้จะอธิบายวิธีการบันทึกบัญชีสินค้าคงเหลือแบบสิ้นงวด (Periodic Inventory Method) ซึ่งแตกต่างจากวิธีบันทึกบัญชีสินค้าคงเหลือแบบต่อเนื่อง (Perpetual Inventory Method) ที่ได้เรียนไปแล้ว วิธีสิ้นงวดนี้จะไม่มีการบันทึกบัญชีสินค้าคงเหลือหรือต้นทุนขายในระหว่างงวด แต่จะมีการบันทึกบัญชีสินค้าคงเหลือเฉพาะ ณ วันสิ้นงวดเท่านั้น โดยการตรวจนับสินค้าคงเหลือที่มีอยู่จริง และนำมาคำนวณหาต้นทุนขายในภายหลัง วิธีนี้เหมาะสำหรับกิจการที่มีสินค้าจำนวนมาก หลากหลายชนิด และมีราคาต่อหน่วยค่อนข้างต่ำ เช่น ร้านเครื่องเขียน หรือซูเปอร์มาร์เก็ต ซึ่งหากใช้วิธีต่อเนื่องจะทำให้การบันทึกบัญชีมีความยุ่งยากและไม่สะดวก

## วัตถุประสงค์
เมื่อจบบทเรียนนี้ ผู้เรียนจะสามารถ: 1. เข้าใจหลักการและเหตุผลในการใช้วิธีบันทึกบัญชีสินค้าคงเหลือแบบสิ้นงวด 2. ระบุและบันทึกรายการค้าที่เกี่ยวข้องกับการซื้อขายสินค้าโดยใช้วิธีสิ้นงวดได้อย่างถูกต้อง 3. คำนวณต้นทุนขายและสินค้าคงเหลือปลายงวด ณ วันสิ้นงวดได้ 4. เปรียบเทียบความแตกต่างระหว่างวิธีบันทึกบัญชีสินค้าคงเหลือแบบสิ้นงวดและแบบต่อเนื่องได้

## แนวคิดสำคัญ
วิธีบันทึกบัญชีสินค้าคงเหลือแบบสิ้นงวด (Periodic Inventory Method) จะไม่บันทึกความเคลื่อนไหวของสินค้าคงเหลือและต้นทุนขายในระหว่างงวด แต่จะใช้บัญชีเฉพาะกิจ 4 บัญชีในการบันทึกรายการที่เกี่ยวข้องกับการซื้อสินค้า ได้แก่: 1. บัญชีซื้อ (Purchases Account) ใช้บันทึกการซื้อสินค้าทั้งหมดเป็นค่าใช้จ่าย 2. บัญชีค่าขนส่งเข้า (Freight-In Account) ใช้บันทึกค่าขนส่งสินค้าที่ซื้อเข้ามา 3. บัญชีส่งคืนและส่วนลด (Purchase Returns and Allowances Account) ใช้บันทึกการส่งคืนสินค้าที่ซื้อไปหรือส่วนลดที่ได้รับ 4. บัญชีส่วนลดรับ (Purchase Discounts Account) ใช้บันทึกส่วนลดที่ได้รับจากการชำระหนี้ค่าสินค้า การบันทึกรายการเหล่านี้จะช่วยลดความยุ่งยากในการบันทึกบัญชีสำหรับกิจการที่มีสินค้าหลากหลายและราคาไม่สูง เมื่อมีการขายสินค้า จะบันทึกเพียงรายได้จากการขายเท่านั้น โดยไม่มีการบันทึกต้นทุนขายในขณะนั้น ต้นทุนขายจะถูกคำนวณเพียงครั้งเดียว ณ วันสิ้นงวด โดยการตรวจนับสินค้าคงเหลือจริง และใช้สูตรคำนวณ ต้นทุนขาย = สินค้าต้นงวด + ซื้อสุทธิ - สินค้าปลายงวด โดยที่ซื้อสุทธิ = ซื้อ + ค่าขนส่งเข้า - ส่งคืนและส่วนลด - ส่วนลดรับ สินค้าคงเหลือปลายงวดที่ตรวจนับได้จะถูกนำไปแสดงในงบแสดงฐานะการเงิน และจะกลายเป็นสินค้าต้นงวดสำหรับงวดถัดไป

| บัญชีค่าขนส่งเข้า | บัญชีหมวดค่าใช้จ่ายที่ใช้บันทึกการจ่ายค่าขนส่งสำหรับสินค้าที่ซื้อเข้ามา |

| บัญชีส่วนลดรับ | บัญชีหมวดค่าใช้จ่ายที่ใช้บันทึกส่วนลดเงินสดที่ได้รับจากการชำระหนี้ค่าสินค้า |
| ต้นทุนขาย | ต้นทุนของสินค้าที่ขายออกไปในระหว่างงวด ซึ่งคำนวณ ณ วันสิ้นงวดด้วยวิธีสิ้นงวด |
| สินค้าต้นงวด | มูลค่าสินค้าคงเหลือ ณ วันเริ่มต้นของงวดบัญชี |
| สินค้าปลายงวด | มูลค่าสินค้าคงเหลือ ณ วันสิ้นสุดของงวดบัญชี ซึ่งได้จากการตรวจนับจริง |
| ซื้อสุทธิ | ยอดรวมของการซื้อสินค้าทั้งหมด หักด้วยส่งคืนและส่วนลด และส่วนลดรับ และบวกด้วยค่าขนส่งเข้า |
| สินค้าที่มีไว้เพื่อขาย | ผลรวมของสินค้าต้นงวดและซื้อสุทธิ ซึ่งแสดงถึงมูลค่าสินค้าทั้งหมดที่มีอยู่เพื่อขายในระหว่างงวด |
| ค่าขนส่งออก | ค่าใช้จ่ายในการขนส่งสินค้าที่ขายออกไปให้ลูกค้า ซึ่งถือเป็นค่าใช้จ่ายในการขาย |
| ส่วนลดจ่าย | ส่วนลดเงินสดที่กิจการให้แก่ลูกค้าเพื่อจูงใจให้ชำระหนี้เร็วขึ้น |
| ส่งคืนและส่วนลด | บัญชีที่ใช้บันทึกการรับคืนสินค้าจากลูกค้า หรือส่วนลดที่ให้แก่ลูกค้า |

## ตัวอย่างหรือขั้นตอน
การบันทึกบัญชีสินค้าด้วยวิธีสิ้นงวดจะแตกต่างจากการบันทึกด้วยวิธีต่อเนื่อง โดยเฉพาะในส่วนของการซื้อและการคำนวณต้นทุนขาย

**1. การบันทึกรายการซื้อสินค้า**
*   **เมื่อซื้อสินค้า (ไม่ว่าเงินสดหรือเงินเชื่อ)**
    *   เดบิต: ซื้อ (Purchases) XX
    *   เครดิต: เงินสด (Cash) หรือ เจ้าหนี้การค้า (Accounts Payable) XX
    (ตัวอย่าง: ซื้อสินค้า 45,000 บาท จะเดบิต ซื้อ 45,000 เครดิต เจ้าหนี้การค้า 45,000)

**2. การบันทึกค่าขนส่งเข้า**
*   **เมื่อจ่ายค่าขนส่งสินค้าที่ซื้อเข้ามา**
    *   เดบิต: ค่าขนส่งเข้า (Freight-In) XX
    *   เครดิต: เงินสด (Cash) หรือ เจ้าหนี้การค้า (Accounts Payable) XX
    (ตัวอย่าง: จ่ายค่าขนส่งเข้า 1,000 บาท จะเดบิต ค่าขนส่งเข้า 1,000 เครดิต เงินสด 1,000)

**3. การบันทึกส่งคืนและส่วนลด**
*   **เมื่อส่งคืนสินค้าที่ซื้อมา หรือได้รับส่วนลด**
    *   เดบิต: เงินสด (Cash) หรือ เจ้าหนี้การค้า (Accounts Payable) XX
    *   เครดิต: ส่งคืนและส่วนลด (Purchase Returns and Allowances) XX
    (ตัวอย่าง: ส่งคืนสินค้า 6,600 บาท จะเดบิต เจ้าหนี้การค้า 6,600 เครดิต ส่งคืนและส่วนลด 6,600)

**4. การบันทึกส่วนลดรับ**
*   **เมื่อชำระหนี้และได้รับส่วนลด**
    *   เดบิต: เจ้าหนี้การค้า (Accounts Payable) XX
    *   เครดิต: เงินสด (Cash) XX
    *   เครดิต: ส่วนลดรับ (Purchase Discounts) XX
    (ตัวอย่าง: ชำระหนี้และได้รับส่วนลด 564 บาท จะเดบิต เจ้าหนี้การค้า 564 เครดิต เงินสด 564)

**5. การบันทึกการขายสินค้า**
*   **เมื่อขายสินค้า (ไม่ว่าเงินสดหรือเงินเชื่อ)**
    *   เดบิต: เงินสด (Cash) หรือ ลูกหนี้การค้า (Accounts Receivable) XX
    *   เครดิต: ขาย (Sales) XX
    (หมายเหตุ: จะไม่มีการบันทึกต้นทุนขายในขณะที่ขายสินค้า)

**6. การบันทึกค่าขนส่งออก**
*   **เมื่อจ่ายค่าขนส่งสินค้าที่ขายออกไป**
    *   เดบิต: ค่าขนส่งออก (Freight-Out) XX
    *   เครดิต: เงินสด (Cash) XX

**7. การคำนวณต้นทุนขาย ณ วันสิ้นงวด**
ณ วันสิ้นงวด จะต้องมีการตรวจนับสินค้าคงเหลือจริง และนำมาคำนวณต้นทุนขาย โดยใช้สูตรดังนี้:

*   **ขั้นตอนที่ 1: คำนวณซื้อสุทธิ (Net Purchases)**
    ซื้อสุทธิ = ซื้อ + ค่าขนส่งเข้า - ส่งคืนและส่วนลด - ส่วนลดรับ
    *ตัวอย่าง:* ซื้อ 45,000 + ค่าขนส่งเข้า 1,000 - ส่งคืนและส่วนลด 6,600 - ส่วนลดรับ 564 = 38,836 บาท

*   **ขั้นตอนที่ 2: คำนวณสินค้าที่มีไว้เพื่อขาย (Goods Available for Sale)**
    สินค้าที่มีไว้เพื่อขาย = สินค้าต้นงวด + ซื้อสุทธิ
    *ตัวอย่าง:* สินค้าต้นงวด 10,000 บาท + ซื้อสุทธิ 38,836 บาท = 48,836 บาท

*   **ขั้นตอนที่ 3: คำนวณต้นทุนขาย (Cost of Goods Sold)**
    ต้นทุนขาย = สินค้าที่มีไว้เพื่อขาย - สินค้าปลายงวด
    *ตัวอย่าง:* สินค้าที่มีไว้เพื่อขาย 48,836 บาท - สินค้าปลายงวด (จากการตรวจนับ) 10,100 บาท = 38,736 บาท

ดังนั้น ต้นทุนขายสำหรับงวดนี้คือ 38,736 บาท ซึ่งจะถูกบันทึกในงบกำไรขาดทุน

## สรุปท้ายบท
วิธีบันทึกบัญชีสินค้าคงเหลือแบบสิ้นงวดเหมาะสำหรับกิจการที่มีสินค้าจำนวนมาก หลากหลายชนิด และมีราคาต่อหน่วยต่ำ เนื่องจากช่วยลดความซับซ้อนในการบันทึกบัญชีในแต่ละวัน โดยไม่จำเป็นต้องบันทึกความเคลื่อนไหวของสินค้าคงเหลือและต้นทุนขายอย่างต่อเนื่อง การบันทึกรายการซื้อจะใช้บัญชี 'ซื้อ' 'ค่าขนส่งเข้า' 'ส่งคืนและส่วนลด' และ 'ส่วนลดรับ' แทนบัญชี 'สินค้าคงเหลือ' โดยตรง การคำนวณต้นทุนขายจะทำเพียงครั้งเดียว ณ วันสิ้นงวด หลังจากตรวจนับสินค้าคงเหลือจริง ซึ่งจะทำให้ทราบยอดสินค้าคงเหลือปลายงวดและต้นทุนขายที่ถูกต้อง อย่างไรก็ตาม ข้อเสียคือกิจการจะไม่ทราบยอดสินค้าคงเหลือและต้นทุนขายที่แท้จริงในระหว่างงวด ทำให้การบริหารจัดการสินค้าคงเหลือแบบทันทีทำได้ยากกว่าวิธีต่อเนื่อง

2. กิจการประเภทใดที่เหมาะสมกับการใช้วิธีบันทึกบัญชีสินค้าคงเหลือแบบสิ้นงวดมากที่สุด และเพราะเหตุใด?
