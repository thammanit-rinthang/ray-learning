# บทที่5ตอนที่4ตัวอย่างวิธีPerpetual

## บทนำ
บทเรียนนี้เป็นการอธิบายตัวอย่างการบันทึกบัญชีสินค้าคงเหลือด้วยวิธี Perpetual (Perpetual Inventory Method) สำหรับบริษัทขายสินค้า โดยเน้นการทำความเข้าใจและบันทึกรายการค้าที่เกี่ยวข้องกับการซื้อและขายสินค้าในเดือนตุลาคม 25x1 ซึ่งรวมถึงการซื้อขายแบบมีเงื่อนไข การจ่ายค่าขนส่ง การส่งคืนสินค้า การรับส่วนลด และการรับชำระหนี้ โดยมีสินค้าคงเหลือยกมาจากเดือนก่อน 10,000 บาท

## วัตถุประสงค์
วัตถุประสงค์ของบทเรียนนี้คือเพื่อให้ผู้เรียนสามารถบันทึกบัญชีรายการค้าที่เกี่ยวข้องกับสินค้าคงเหลือตามวิธี Perpetual ได้อย่างถูกต้องและครบถ้วน รวมถึงการทำความเข้าใจผลกระทบของเงื่อนไขการค้าต่างๆ เช่น ส่วนลดการค้า ส่วนลดเงินสด และเงื่อนไขการส่งมอบ (FOB) ต่อการบันทึกบัญชีสินค้าคงเหลือ ต้นทุนขาย และบัญชีที่เกี่ยวข้องอื่นๆ

## แนวคิดสำคัญ
แนวคิดสำคัญที่ครอบคลุมในบทเรียนนี้ได้แก่ วิธี Perpetual Inventory Method ซึ่งเป็นการบันทึกบัญชีสินค้าคงเหลือและต้นทุนขายอย่างต่อเนื่องทุกครั้งที่มีการเคลื่อนไหวของสินค้า ทำให้ทราบยอดคงเหลือและต้นทุนขายได้ทันที นอกจากนี้ยังครอบคลุมถึงการแยกแยะและบันทึกส่วนลดการค้า (Trade Discount) ซึ่งเป็นการลดราคาทันทีและไม่บันทึกบัญชี กับส่วนลดเงินสด (Cash Discount) ที่ให้เพื่อจูงใจให้ชำระหนี้เร็วขึ้น โดยส่วนลดรับจะลดต้นทุนสินค้า และส่วนลดจ่ายจะลดรายได้จากการขาย รวมถึงการทำความเข้าใจเงื่อนไขการส่งมอบ (FOB Shipping Point และ FOB Destination) ที่มีผลต่อการรับผิดชอบค่าขนส่งเข้า (Freight-In) ซึ่งถือเป็นส่วนหนึ่งของต้นทุนสินค้า และค่าขนส่งออก (Freight-Out) ซึ่งถือเป็นค่าใช้จ่ายในการขาย

## คำศัพท์
| ศัพท์ | ความหมาย |
|---|---|
| Perpetual Inventory Method | วิธีการบันทึกบัญชีสินค้าคงเหลือที่ปรับปรุงยอดสินค้าคงเหลือและต้นทุนขายทุกครั้งที่มีการซื้อ ขาย หรือส่งคืนสินค้า |
| สินค้าคงเหลือ (Inventory) | สินทรัพย์ที่กิจการมีไว้เพื่อขายในการดำเนินงานตามปกติ |
| ต้นทุนขาย (Cost of Goods Sold) | ต้นทุนของสินค้าที่ขายไปในระหว่างงวดบัญชี |
| เจ้าหนี้การค้า (Accounts Payable) | หนี้สินที่เกิดจากการซื้อสินค้าหรือบริการเป็นเงินเชื่อ |
| ลูกหนี้การค้า (Accounts Receivable) | สินทรัพย์ที่เกิดจากการขายสินค้าหรือบริการเป็นเงินเชื่อ |
| ส่วนลดการค้า (Trade Discount) | ส่วนลดที่ผู้ขายให้แก่ผู้ซื้อทันที ณ เวลาที่ซื้อขาย ไม่มีการบันทึกบัญชี |
| ส่วนลดเงินสด (Cash Discount) | ส่วนลดที่ผู้ขายเสนอให้ผู้ซื้อเพื่อจูงใจให้ชำระหนี้ภายในระยะเวลาที่กำหนด |
| ส่วนลดรับ (Purchase Discount) | ส่วนลดเงินสดที่ผู้ซื้อได้รับจากการชำระหนี้ค่าสินค้าเร็วขึ้น ซึ่งจะลดต้นทุนสินค้าคงเหลือ |
| ส่วนลดจ่าย (Sales Discount) | ส่วนลดเงินสดที่ผู้ขายให้แก่ผู้ซื้อจากการชำระหนี้ค่าสินค้าเร็วขึ้น ซึ่งจะลดรายได้จากการขาย |
| ค่าขนส่งเข้า (Freight-In) | ค่าใช้จ่ายในการขนส่งสินค้าที่ซื้อมา ซึ่งถือเป็นส่วนหนึ่งของต้นทุนสินค้า |
| ค่าขนส่งออก (Freight-Out) | ค่าใช้จ่ายในการขนส่งสินค้าที่ขายไปให้ลูกค้า ซึ่งถือเป็นค่าใช้จ่ายในการขาย |
| FOB Shipping Point | เงื่อนไขการส่งมอบที่ผู้ซื้อเป็นผู้รับผิดชอบค่าขนส่งและความเสี่ยงตั้งแต่จุดส่งสินค้า |
| FOB Destination | เงื่อนไขการส่งมอบที่ผู้ขายเป็นผู้รับผิดชอบค่าขนส่งและความเสี่ยงจนกระทั่งสินค้าถึงปลายทาง |
| รับคืนและส่วนลด (Sales Returns and Allowances) | บัญชีปรับลดรายได้จากการขายเมื่อลูกค้าส่งคืนสินค้าหรือได้รับส่วนลด |
| ส่งคืนสินค้า (Purchase Returns and Allowances) | การส่งคืนสินค้าที่ซื้อไปให้ผู้ขาย ซึ่งจะลดหนี้สินและสินค้าคงเหลือ |

## ตัวอย่างหรือขั้นตอน
ตัวอย่างการบันทึกบัญชีสำหรับเดือนตุลาคม 25x1 (บริษัทมีสินค้าคงเหลือต้นงวด 10,000 บาท):

*   **ต.ค. 3: ซื้อสินค้าจำนวน 30,000 บาท เงื่อนไข 2/10, n/30, FOB Shipping Point**
    *   บันทึก: เดบิต สินค้าคงเหลือ 30,000 บาท, เครดิต เจ้าหนี้ 30,000 บาท
    *   คำอธิบาย: สินค้าเพิ่มขึ้นจึงเดบิตสินค้าคงเหลือ และเป็นการซื้อเชื่อจึงเครดิตเจ้าหนี้ เงื่อนไข FOB Shipping Point หมายถึงผู้ซื้อ (เรา) เป็นผู้รับผิดชอบค่าขนส่ง

*   **ต.ค. 4: จ่ายค่าขนส่งสินค้าที่ซื้อเมื่อวันที่ 3 จำนวน 1,000 บาท เป็นเงินสด**
    *   บันทึก: เดบิต สินค้าคงเหลือ 1,000 บาท, เครดิต เงินสด 1,000 บาท
    *   คำอธิบาย: ค่าขนส่งเข้าถือเป็นส่วนหนึ่งของต้นทุนสินค้าที่ทำให้สินค้าพร้อมใช้งาน จึงเพิ่มมูลค่าสินค้าคงเหลือ

*   **ต.ค. 5: ส่งคืนสินค้าที่ซื้อเมื่อวันที่ 3 เนื่องจากชำรุด จำนวน 1,800 บาท**
    *   บันทึก: เดบิต เจ้าหนี้ 1,800 บาท, เครดิต สินค้าคงเหลือ 1,800 บาท
    *   คำอธิบาย: การส่งคืนสินค้าลดหนี้สินต่อเจ้าหนี้และลดมูลค่าสินค้าคงเหลือ

*   **ต.ค. 7: ขายสินค้าจำนวน 30,000 บาท โดยมีต้นทุนขาย 18,000 บาท เงื่อนไข 3/10, n/30, FOB Destination โดยผู้ซื้อแจ้งว่าได้จ่ายค่าขนส่งแทนไปจำนวน 500 บาท**
    *   บันทึกการขาย: เดบิต ลูกหนี้การค้า 30,000 บาท, เครดิต ขาย 30,000 บาท
    *   บันทึกต้นทุนขาย: เดบิต ต้นทุนขาย 18,000 บาท, เครดิต สินค้าคงเหลือ 18,000 บาท
    *   บันทึกค่าขนส่ง: เดบิต ค่าขนส่งออก 500 บาท, เครดิต ลูกหนี้การค้า 500 บาท
    *   คำอธิบาย: การขายเชื่อเพิ่มลูกหนี้และรายได้จากการขาย ต้นทุนขายและสินค้าคงเหลือจะถูกปรับลดทันทีตามวิธี Perpetual เงื่อนไข FOB Destination หมายถึงผู้ขาย (เรา) รับผิดชอบค่าขนส่ง แต่ผู้ซื้อจ่ายแทนไปก่อน จึงลดหนี้ที่ผู้ซื้อต้องชำระให้เรา ค่าขนส่งออกถือเป็นค่าใช้จ่ายในการขาย

*   **ต.ค. 9: ซื้อสินค้าจำนวน 15,625 บาท เป็นเงินสด โดยมีส่วนลดการค้า 4%**
    *   คำนวณ: ราคาซื้อสุทธิ = 15,625 บาท * (1 - 0.04) = 15,000 บาท
    *   บันทึก: เดบิต สินค้าคงเหลือ 15,000 บาท, เครดิต เงินสด 15,000 บาท
    *   คำอธิบาย: ส่วนลดการค้าเป็นการลดราคาทันที ไม่มีการบันทึกบัญชีส่วนลด แต่บันทึกสินค้าด้วยราคาสุทธิที่จ่ายจริง

*   **ต.ค. 10: ชำระค่าสินค้าที่ซื้อเมื่อวันที่ 3 เป็นเงินสด**
    *   คำนวณยอดหนี้: ซื้อ 30,000 บาท - ส่งคืน 1,800 บาท = 28,200 บาท
    *   เงื่อนไข: 2/10, n/30 ชำระภายใน 10 วัน (วันที่ 3-13) ได้รับส่วนลด 2%
    *   ส่วนลดรับ: 28,200 บาท * 0.02 = 564 บาท
    *   เงินสดที่จ่าย: 28,200 บาท - 564 บาท = 27,636 บาท
    *   บันทึก: เดบิต เจ้าหนี้ 28,200 บาท, เครดิต เงินสด 27,636 บาท, เครดิต สินค้าคงเหลือ 564 บาท
    *   คำอธิบาย: การชำระหนี้ลดเจ้าหนี้และเงินสด ส่วนลดรับลดต้นทุนสินค้าคงเหลือ

*   **ต.ค. 12: ส่งคืนสินค้าที่ซื้อเมื่อวันที่ 9 จำนวน 5,000 บาท (เป็นราคาต้นทุนก่อนหักส่วนลด)**
    *   คำนวณยอดคืน: ราคาป้าย 5,000 บาท * (1 - 0.04) = 4,800 บาท
    *   บันทึก: เดบิต เงินสด 4,800 บาท, เครดิต สินค้าคงเหลือ 4,800 บาท
    *   คำอธิบาย: การส่งคืนสินค้าที่ซื้อสดทำให้ได้รับเงินสดคืนและลดสินค้าคงเหลือ โดยคำนวณจากราคาหลังหักส่วนลดการค้า

*   **ต.ค. 13: รับคืนสินค้าที่ขายเมื่อวันที่ 7 จำนวน 2,000 บาท โดยมีต้นทุนขาย 1,200 บาท**
    *   บันทึกรับคืน: เดบิต รับคืนและส่วนลด 2,000 บาท, เครดิต ลูกหนี้การค้า 2,000 บาท
    *   บันทึกปรับปรุงต้นทุนขาย: เดบิต สินค้าคงเหลือ 1,200 บาท, เครดิต ต้นทุนขาย 1,200 บาท
    *   คำอธิบาย: การรับคืนสินค้าลดรายได้จากการขาย (ผ่านบัญชีรับคืนและส่วนลด) และลดลูกหนี้ สินค้าคงเหลือเพิ่มขึ้นและต้นทุนขายลดลง

*   **ต.ค. 14: ขายสินค้าจำนวน 40,000 บาท โดยมีส่วนลดการค้า 5% ต้นทุนขาย 23,280 บาท เงื่อนไข 2/10, n/30, FOB Shipping Point วันเดียวกันมีการจ่ายค่าขนส่งสินค้าเป็นเงินสด 1,000 บาท**
    *   คำนวณราคาขายสุทธิ: 40,000 บาท * (1 - 0.05) = 38,000 บาท
    *   บันทึกการขาย: เดบิต ลูกหนี้การค้า 38,000 บาท, เครดิต ขาย 38,000 บาท
    *   บันทึกต้นทุนขาย: เดบิต ต้นทุนขาย 23,280 บาท, เครดิต สินค้าคงเหลือ 23,280 บาท
    *   บันทึกค่าขนส่ง: เดบิต ลูกหนี้การค้า 1,000 บาท, เครดิต เงินสด 1,000 บาท
    *   คำอธิบาย: ส่วนลดการค้าไม่บันทึกบัญชี บันทึกการขายและต้นทุนขายตามปกติ เงื่อนไข FOB Shipping Point ผู้ซื้อรับผิดชอบค่าขนส่ง แต่เราจ่ายแทนไปก่อน จึงเพิ่มยอดลูกหนี้

*   **ต.ค. 17: รับชำระหนี้ค่าสินค้าที่ขายเมื่อวันที่ 7 เป็นเช็คแต่ยังไม่ได้นำฝากธนาคาร**
    *   คำนวณยอดลูกหนี้: ขาย 30,000 บาท - ค่าขนส่งที่ลูกค้าจ่ายแทน 500 บาท - รับคืน 2,000 บาท = 27,500 บาท
    *   เงื่อนไข: 3/10, n/30 ชำระภายใน 10 วัน (วันที่ 7-17) ได้รับส่วนลด 3%
    *   ส่วนลดจ่าย: (30,000 บาท - 2,000 บาท) * 0.03 = 28,000 บาท * 0.03 = 840 บาท (ส่วนลดคิดจากมูลค่าสินค้าเท่านั้น ไม่รวมค่าขนส่ง)
    *   เงินสดที่ได้รับ: 27,500 บาท - 840 บาท = 26,660 บาท
    *   บันทึก: เดบิต เงินสด 26,660 บาท, เดบิต ส่วนลดจ่าย 840 บาท, เครดิต ลูกหนี้การค้า 27,500 บาท
    *   คำอธิบาย: การรับชำระหนี้ลดลูกหนี้และเพิ่มเงินสด ส่วนลดจ่ายลดรายได้จากการขาย เช็คที่ยังไม่นำฝากถือเป็นเงินสด

*   **ต.ค. 20: รับคืนสินค้าที่ขายเมื่อวันที่ 14 จำนวน 2,000 บาท (เป็นราคาต้นทุนก่อนหักส่วนลด) โดยมีต้นทุนขาย 1,344 บาท**
    *   คำนวณยอดรับคืน: ราคาป้าย 2,000 บาท * (1 - 0.05) = 1,900 บาท
    *   บันทึกรับคืน: เดบิต รับคืนและส่วนลด 1,900 บาท, เครดิต ลูกหนี้การค้า 1,900 บาท
    *   บันทึกปรับปรุงต้นทุนขาย: เดบิต สินค้าคงเหลือ 1,344 บาท, เครดิต ต้นทุนขาย 1,344 บาท
    *   คำอธิบาย: การรับคืนสินค้าลดรายได้จากการขาย (ผ่านบัญชีรับคืนและส่วนลด) และลดลูกหนี้ โดยคำนวณจากราคาหลังหักส่วนลดการค้า สินค้าคงเหลือเพิ่มขึ้นและต้นทุนขายลดลง

*   **ต.ค. 24: รับชำระหนี้ค่าสินค้าที่ขายเมื่อวันที่ 14**
    *   คำนวณยอดลูกหนี้: ขาย 38,000 บาท + ค่าขนส่งที่เราจ่ายแทน 1,000 บาท - รับคืน 1,900 บาท = 37,100 บาท
    *   เงื่อนไข: 2/10, n/30 ชำระภายใน 10 วัน (วันที่ 14-24) ได้รับส่วนลด 2%
    *   ส่วนลดจ่าย: (38,000 บาท - 1,900 บาท) * 0.02 = 36,100 บาท * 0.02 = 722 บาท (ส่วนลดคิดจากมูลค่าสินค้าเท่านั้น ไม่รวมค่าขนส่ง)
    *   เงินสดที่ได้รับ: 37,100 บาท - 722 บาท = 36,378 บาท
    *   บันทึก: เดบิต เงินสด 36,378 บาท, เดบิต ส่วนลดจ่าย 722 บาท, เครดิต ลูกหนี้การค้า 37,100 บาท
    *   คำอธิบาย: การรับชำระหนี้ลดลูกหนี้และเพิ่มเงินสด ส่วนลดจ่ายลดรายได้จากการขาย

## สรุปท้ายบท
วิธี Perpetual Inventory Method มีข้อดีคือช่วยให้กิจการทราบยอดสินค้าคงเหลือและต้นทุนขายได้ตลอดเวลา ทำให้สามารถควบคุมและบริหารจัดการสินค้าคงเหลือได้อย่างมีประสิทธิภาพ โดยเฉพาะสินค้าที่มีมูลค่าสูง นอกจากนี้ยังช่วยให้สามารถวิเคราะห์ข้อมูลการขายและต้นทุนได้อย่างรวดเร็ว อย่างไรก็ตาม วิธีนี้ต้องการการบันทึกบัญชีที่ละเอียดและแม่นยำสำหรับทุกรายการที่เกี่ยวข้องกับสินค้าคงเหลือ และต้องมีการตรวจสอบยอดสินค้าคงเหลือจริงเป็นระยะเพื่อยืนยันความถูกต้อง

## คำถามทบทวน
1. อธิบายความแตกต่างระหว่างส่วนลดการค้าและส่วนลดเงินสดในการบันทึกบัญชีตามวิธี Perpetual
2. ภายใต้วิธี Perpetual การจ่ายค่าขนส่งเข้าและค่าขนส่งออกมีผลต่อบัญชีใดบ้างและบันทึกอย่างไร
3. หากมีการส่งคืนสินค้าที่ซื้อมาเป็นเงินเชื่อภายใต้เงื่อนไข FOB Shipping Point การบันทึกบัญชีจะแตกต่างจากการส่งคืนสินค้าที่ซื้อสดอย่างไร
4. การรับคืนสินค้าจากลูกค้าที่ขายเป็นเงินเชื่อมีผลต่อบัญชีสินค้าคงเหลือและต้นทุนขายอย่างไร
5. ประโยชน์หลักของการใช้วิธี Perpetual ในการบันทึกบัญชีสินค้าคงเหลือคืออะไร
